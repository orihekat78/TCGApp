# 2026-05-21-3 — Phase 7-3: AI Policy `chooseAtomTarget` 拡張

## 概要

Phase 7-2 (`3f50e99`) で BUG-035 の汎用 $pick substitution が完成し engine 側課題は完全消化したが、
候補選択は `cands[0]` (先頭採用) 固定で AI 戦略性は皆無。Phase 7-3 で AIPolicy に
`chooseAtomTarget` を追加し、verb 別ヒューリスティック (敵 highest AP / 自陣 lowest AP 等) で
意味的に正しい選択を実現する。

## アーキテクチャ

「最小修正 + 境界 hook」パターン (Phase 7-2 踏襲):

1. **`src/ai/policy.ts`** — `AIPolicy` interface に optional `chooseAtomTarget` 追加
2. **`src/engine/effect/resolve-picks.ts`** — `ResolveEffectPicksOpts.chooseAtomTarget` callback を pass-through
3. **`src/engine/listeners/triggered.ts`** — listener callback 内で `new HeuristicPolicy()` (cycle 回避)
4. **`src/ui/hooks/useEngineDispatch.ts:hiramekiResolve`** — 同上
5. **`src/ai/policies/heuristic.ts`** — verb 別 dispatch を実装

### Verb 別ヒューリスティック

| verb | 戦術 |
|------|------|
| `sceneRemove` | 敵 AP 最高 → 無ければ敵 LP 最高 |
| `sceneSetState sleep/stun` | 敵 active 最高 AP → 無ければ任意敵 |
| `sceneSetState active` | 自陣 sleep/stun 最高 AP → 無ければ任意自陣 |
| `charModifyAP +X` | 自陣 AP 最低 (伸び代) |
| `charModifyAP -X` | 敵 AP 最高 (脅威弱化) |
| `charModifyLP +X` | 自陣 LP 最高 (推理エース強化) |
| `charModifyLP -X` | 敵 LP 最高 (推理妨害) |
| その他 | null → caller 先頭採用 fallback |

## Circular import 解消

triggered.ts で `import HeuristicPolicy` した結果、
`triggered → heuristic → @/engine umbrella → listeners/triggered` の TDZ ループが発生。
heuristic.ts 側で `@/engine` umbrella import を `@/engine/cards/index.js` + `@/engine/read/index.js` の
直接 import に切替えて cycle を解消 (heuristic 内では `const engine = { cards, read }` facade で
既存 call site 無編集)。
