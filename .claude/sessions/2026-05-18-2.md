## 最大の root cause 発見

**B6 手札 scrollbar**: `.hand-zone[data-count] { overflow-x: hidden; overflow-y: visible }` の
組み合わせは **CSS 仕様上ブラウザが overflow-y を auto に強制変換** するため Y 軸に
scrollbar が残っていた。`overflow: hidden` 統一で解決。Playwright `getComputedStyle`
+ scrollHeight 検査で scrollable element 0 件確認済。

## engine 改修 (骨格凍結原則 §例外: バグ修正)

- `FileCard.card-back` 型に `cardId: string` 必須化
- `mutate.file.addFromDeckTop` で `deck.shift()` の cardId を保持
- `next-hint.ts` で `popped.cardId` を手札に push (旧: `FILE_CARD_BACK_PLACEHOLDER` = 'card-back' で UI 解決失敗)
