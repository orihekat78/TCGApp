# 2026-05-19-3 — Round 4g: BUG-030 engine 修正 (continuous modifier resolver)

## 概要

Round 4f Phase 2 (commit `4eb103a`) で発見した **BUG-030** (engine `read.char.keywords` が `continuousModifier.grantKeywords` を resolve しない、Phase 5 未実装) を本セッションで修正。骨格凍結原則 §例外 (engine 自体のバグ修正、rules/13/17 keyword 仕様実装) に該当。

## Phase 1-2: engine 修正

### `src/engine/read/char.ts` — `keywords()` 関数拡張

`evalCond` を import に追加し、`keywords()` 関数に continuous + grantKeywords resolver を組み込み:

```ts
// disabledOriginal=false 経路で:
//  1. scene 上の char の owner side を解決
//  2. cardDef.abilities を走査
//  3. type==='continuous' + continuousModifier.grantKeywords を持つもの
//  4. ability.condition を evalCond で評価 (true のみ通す)
//  5. grantKeywords(s, { uid }) の戻り値を結果に追加 (重複除去)
```

- rules/24 §常時有効型: 条件成立中は自動的に効果、条件外で即失効
- rules/19 §元の能力を無効にする: `disabledOriginal=true` で continuous も無効化
- 追加 LOC: 約 25 行

## Phase 2: unit test 追加 (5 件)

`tests/engine/read/char.test.ts` に `describe('continuous modifier resolver (BUG-030)', ...)` を追加:

1. continuous + condition true → grantKeywords 反映
2. continuous + condition false → 反映なし
3. `disabledOriginal=true` で continuous も無効
4. `partnerColor` 条件 (positive): partner が指定色なら grant
5. `partnerColor` 条件 (negative): partner が異なる色なら grant されない

## Phase 3: E2E spec 拡張

`tests/e2e/patterns/partner-color-keyword.spec.ts` の各 test に **4-layer assertion** を追加:

- 既存 3-layer (abilityExists / conditionMet / grantedKeywords) はそのまま保持
- 新 layer: `expectCharHasKeyword` / `expectCharNotHasKeyword` を使い `read.char.hasKeyword` 経由で keyword 付与を直接 assert

防御深度を 3 → 4 段階に強化。
