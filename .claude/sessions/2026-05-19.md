### 重要な実装上の発見

1. **modifier callback の closure 制限**: `page.evaluate` で関数を `toString()` 経由で渡すと外部スコープ参照が失われる。`buildGameState<T>(page, modifier, arg)` で第 3 引数経由で値を渡す設計に。
2. **action context の解放**: state-machine の `contact-end → action-end` 遷移で `_contexts.delete(id)` が呼ばれ、`_getContext(id)` は **`undefined`** を返す (null ではない)。`waitForActionEnd` は `ax == null || ax.phase === 'action-end'` の両判定が必要。
3. **driver auto-pass for opp side**: action-1 phase で `firstUid` が非 self の場合、engine/driver が自動 pass + advance するため phase が即 'action-2' に到達する。spec で action-1 を明示的に dispatch する必要なし。
4. **driver は contact picker modal-open 状態で blocked**: cutin dispatch 後の advance / judge は spec が手動で進める必要あり (driver は modal-driven、test は modal-bypass)。
