# blocked-ui-rule-mismatch 訂正

先の記録は撤回する。佐藤美和子はsleep候補ではなかった。公開UI上の相手事件エリアには case-area--candidate の強調とpointerがあり、これは唯一の合法対象 case:opp を表す。DOM snapshotがCSS候補強調を文字化しなかったため、候補なしと誤認した。

佐藤美和子へのクリックは候補外のため無反応であり、これはルールどおり。相手事件は公開UIで候補化されている。よって blocked-ui-rule-mismatch は成立しない。判断13は「対象候補の観察」としてのみ残し、対象選択の実行は相手事件へ改める。
