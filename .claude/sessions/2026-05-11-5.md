- **Event Registry**: モジュールレベル singleton (Immer の produce が state を毎回新規生成するため WeakMap 不可)
- **EffectStackEntry 拡張**: GameState.pendingEffects を `Effect[]` → `EffectStackEntry[]` に変更。骨格凍結原則は「カード効果対応のための骨格修正禁止」のため、骨格内部インフラ拡張は OK 判断

- **dyn**: 限定 path 評価 + 左結合算術。`eval()` / `new Function()` 不使用。`$pick` は targeting に委譲
- **viaCost flag**: cost.pay 内で `try/finally` で setting/restore。emit との wire-up は Phase 4 で
