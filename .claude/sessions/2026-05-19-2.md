### 検証層 (3 段階)

`__game.read.def.card(cardId).abilities` + `__game.cond.eval(state, condition, ctx)` で:

1. **abilityExists**: cardDef.abilities に `type:'continuous'` + `continuousModifier.grantKeywords` 持ち ability が存在
2. **conditionMet**: `cond.eval(state, ability.condition, { source: { player, uid } })` が期待値と一致
3. **grantedKeywords**: `continuousModifier.grantKeywords(state, uid)` が `[keyword]` を返す

### 重要な発見: BUG-030 登録

`read.char.keywords` は `cardDef.keywords + char.keywordOverrides.granted` のみで、**continuous ability の continuousModifier.grantKeywords を評価しない** (`src/engine/read/char.ts:61-74`、L70 コメント: `// Phase 5 で abilities から展開`)。

そのため `hasKeyword(state, uid, '突撃')` は false を返す。本 spec は engine の resolver 未実装をワークアラウンドし、cardDef 構造 + cond.eval で **engine が将来 resolve するための前提条件** を検証する設計に変更。

詳細: [.claude/bugs/BUG-030.md](../bugs/BUG-030.md)
