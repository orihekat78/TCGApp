### 新規 utility: `src/engine/effect/resolve-picks.ts` (~80 LOC)

```ts
export function resolveEffectPicks(state, effect, ctx): Effect {
  switch (effect.kind) {
    case 'atom': return substituteAtomPick(state, effect, ctx);
    case 'sequence' / 'parallel': // 各 step 再帰
    case 'choice': // 各 option 再帰
    case 'optional' / 'conditional' / 'forEach' / 'replace': // inner 再帰
    case 'negate' / 'custom': return effect; // skip
  }
}
```

`substituteAtomPick`: `args.uid === '$pick'` + `args.target.kind === 'pick'` を検出 → `engine.target.candidates` で列挙 → **先頭採用** → deep clone した atom で `args.uid = picked.uid` 置換 + `target` 削除。候補 0 件: 元 atom そのまま (rules/10 no-op fallback)。
