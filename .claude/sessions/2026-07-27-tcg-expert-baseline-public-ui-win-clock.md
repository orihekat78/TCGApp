# 公開UI baseline: 自分の証拠時計

記録日: 2026-07-27 JST  
範囲: 行026ではない。`#setup`から開始した YOU CT-D08 vs CPU CT-D11。  
目的: 公開UIだけで自分の即時勝利時計を確認する。

## 方法

- 実クリック、可視UI、表向きカード本文、公式規則だけを使用した。
- dispatch、state参照、非公開情報、裏向きカード識別は使わない。
- 表向きカードを使う判断の直前に、UI本文・公式カード本文・該当規則を照合した。

## 結論

- 7枚目はpartner推理で得た。公開UIのpartnerはスリープだった。
- `CONAN-VICTORY` は必要証拠と解決編に加え、アクティブなpartnerを要求する。従って「事件解決 ★勝利 / まだ」は規則どおりであり、UI/規則不一致ではない。
- end後、CPUが必要証拠数達成で勝利した。自分の「7/7かつpartner active」の即時解決は未検証である。
- 行026のGateは未解消。worklistは変更しない。
