## 設計判断

1. **useTargetPicker と同形の API**: subscribe-free 関数群を返し、
   component の再描画 subscribe は `useConfirmationStore((s) => s.current)` で別途。
   テスト容易性と consumer エルゴノミクスを両立。
2. **3 kind**: standard (推理/アクション/手札使用/ネクストヒント) /
   warning (アシスト強警告) / victory (事件解決勝利予告) — UI 装飾差別化用フラグのみ。
   ボタンラベルは label プロパティで個別カスタム可。
3. **並行 ask は旧 Promise を false resolve**: useTargetPicker と整合した挙動。
   UI フロー上、複数モーダル同時表示はしない前提。
