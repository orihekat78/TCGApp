### 検証戦略 (3-layer + condition resolve)

`partner-color-keyword.spec.ts` の `evalCondition` パターンを継承、`evalAbility` helper で:

1. **abilityExists**: cardDef.abilities に対象 ability あり
2. **descriptionHasCaseTraitPrefix**: description に `【事件婚活】` prefix (caseTraitConditioned 仕様)
3. **conditionShape**: `{ kind: 'caseTrait', trait: '婚活' }` or `{ kind: 'and', cs: [caseTrait...] }` の構造
4. **conditionMet**: `cond.eval` で婚活 case 持ち事件 (D11021) → true、別事件 (D08026) → false (negative)

## 重要な発見 → BUG-031 登録 + data fix

**実装中に発見**: `src/cards/ct-d11/D11021.ts` の `traits: []` 空配列。「婚活」trait なし。

- しかし D11021 の traits 配列に未設定

**修正**: [src/cards/ct-d11/D11021.ts](../../src/cards/ct-d11/D11021.ts) の 1 line data fix
```ts

```
