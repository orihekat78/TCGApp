# 2026-05-21-10 — BUG-037: Scene Card Sleep CSS lock 修正

## 概要

user_request `20260521_01.txt` #1 / #16 (重複): 「現場カードがアクションや推理してもスリープ
にならない (カードが縦から横に回転しない)」を BUG-037 として追跡し、CSS animation
`fill-mode` の transform lock が原因と特定 → 1 行修正で解決。

## RCA

`src/ui/components/SceneArea.css:128`:

```css
.scene-area .card {
  animation: scene-card-enter 280ms ease-out both;
}
```

`@keyframes scene-card-enter` 100% フレームに `transform: translateY(0) scale(1)` が定義され、
`animation-fill-mode: both` の `forwards` 側で animation 終了後も保持される。
CSS 仕様で animation の computed value は base style より優先されるため、後から付与される
`.card.sleep { transform: rotate(-90deg) }` を **animation 100% フレームが上書きして無効化**。

確認 (Playwright + chromium dev tools):
- `getAnimations()`: `name: scene-card-enter`, `playState: finished`, `currentTime: 280`
- 完了済 animation が transform を lock 続けていた

## 修正

`src/ui/components/SceneArea.css:128` の `animation: scene-card-enter 280ms ease-out both;`
→ `... backwards;` に変更。`backwards` なら animation 終了後は base style が transform を制御するため、
`.sleep` / `.stun` の rotate が正しく適用される。

## 水平展開

- **PartnerArea.css**: `.card.sleep` に rotate あり、ただし `scene-card-enter` 系の animation lock 無し → 影響なし
- **FileArea / HandZone / RemoveArea / LogPanel 等**: `animation: ... both` あるが `.sleep` 対象外 → 影響なし
- **CaseArea (case-stamp-flip)**: 100% で transform: rotate(...) するが事件カード専用、状態遷移なし → 影響なし

→ SceneArea のみが影響。他箇所への波及無し。
