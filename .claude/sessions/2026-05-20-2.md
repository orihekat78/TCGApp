## Phase 2: 修正

### BUG-032 fix (selfOnly 水平展開)
- 4 files に `trigger.selfOnly: true` 追加
- **追加発見**: `selfOnly: true` だけでは不十分。`selfOnlyMatches` の hand 経路が `payload.cardId === card.cardId` のみで player 比較なし → 両プレイヤー手札の同 cardId が match していた
- `selfOnlyMatches` を更新: `payload.cardId === card.cardId && source.player === card.player`
- これで selfOnly:true + player check で完全 player-filter

### BUG-033 fix (handleHook condition gate)
- `import { evalCond } from '../cond/eval.js';` 追加
- `handleHook` matcher check 直後に 6 stage 目 filter:
  ```ts
  if (ability.condition) {
    const ctx = { source: { cardId, uid, abilityId, player, area }, bindings: {} };
    if (!evalCond(state, ability.condition, ctx)) continue;
  }
  ```
