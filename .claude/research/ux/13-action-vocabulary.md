# 13. アクション語彙とログ表現

> 出典: B群対戦動画3本+P0公式動画の字幕で使われる用語をWebアプリの
> 「行動ボタン」「ログメッセージ」「ヘルプテキスト」に統一する語彙集。

## 公式・口語の対照表

| 概念 | 公式マニュアル用語 | 動画/対戦の口語 | アプリ採用 |
|------|------------------|---------------|-----------|
| アクション | アクション | 「アクション」「殴る」 | アクション |
| アクション[キャラ] | アクション［キャラ］ | 「○○にアクションで」 | アクション(対 キャラ) |
| アクション[事件] | アクション［事件］ | 「事件アクション」「事件殴る」 | アクション(対 事件) |
| ガード | ガード | 「ガードで」「ガードなし」 | ガード / ガードなし |
| コンタクト | コンタクト | 「コンタクト発生」 | コンタクト |
| カットイン | カットイン | 「カットイン+1000で○○使います」 | カットイン |
| 推理 | 推理 | 「推理して」 | 推理 |
| アシスト | アシスト | 「アシストして」 | アシスト |
| リムーブ | リムーブ | 「リムーブで」「リムって」 | リムーブ |
| ネクストヒント | ネクストヒント | 「ネクスト」「ネクストヒント」 | ネクストヒント |
| 事件解決 | 事件解決 | 「解決します」「事件解決します」 | 事件解決 |
| 痕跡発見済 | 痕跡［発見済み］ | 「発見済になりました」 | 痕跡発見済 |
| ターンエンド | ターンエンド | 「終わります」「終了です」 | ターンエンド |
| ドロー | カードを引く | 「ワンドロー」「ドローして」 | ドロー |

→ **UI採用方針**: 公式マニュアル用語を主、口語をツールチップで補足。

## イベントログのフォーマット

### 形式: `[時刻] <主体> <動詞> <目的語> [補足]`

```
[10:23] 自分:アシスト  パートナー → FILE  (FILE: 5→6枚)
[10:24] 自分:手札使用 服部平次(Lv5) → 現場 [名乗り]
[10:25] 自分:推理     江戸川コナン (LP1) → 証拠+1 (証拠: 3/7)
[10:25] 自分:ターンエンド
[10:26] 相手:オートフェイズ
[10:26] 相手:手札使用 怪盗キッド(Lv8) → 現場 [名乗り]
[10:27] 相手:アクション(対 事件) パートナーで攻撃
[10:27] 自分:ガード   毛利蘭(LP2/AP6000) でガード
[10:27] 🔥 コンタクト発生 (キッド AP7000 vs 蘭 AP6000)
[10:28] 自分:カットイン 灰原哀「+2000」 → 蘭 AP8000
[10:28] 🔥 蘭 (8000) > キッド (7000) → キッドリムーブ
```

### 配色ルール
- **赤**: 致命的・敗北直結（リフレッシュ・敗北）
- **オレンジ**: 攻撃・リムーブ系
- **青**: 防御・ガード系
- **緑**: ドロー・証拠獲得（自分にとって有利）
- **グレー**: ターン進行・自動処理

## ボタン名称ガイド

| ボタン位置 | 名称 | 表示条件 |
|----------|------|---------|
| 画面下中央 | 「ターンエンド」 | 自分のターン中、常時 |
| 手札カード上 | 「使用する」 | レベル≦FILE枚数 |
| パートナー上 | 「アシスト」 | アクティブ + 自分ターン |
| パートナー上 | 「推理」 | アクティブ + 自分ターン |
| パートナー上 | 「事件解決」 | 解決編 + 必要証拠数達成 |
| FILE上 | 「ネクストヒント」 | FILE≥1 + 自分ターン |
| 相手キャラ上 | 「アクション対象」 | スリープ or スタン |
| 相手事件上 | 「アクション対象」 | 証拠1枚以上 |
| 自キャラ上 | 「ガード」 | アクティブ + 相手アクション中 |

## 用語のローカライズ

将来 i18n を入れる場合の英訳メモ：
- アクション = Action / アクション[事件] = Action (Case)
- 推理 = Deduction / アシスト = Assist / コンタクト = Contact
- ガード = Guard / カットイン = Cut-in / リムーブ = Remove
- ネクストヒント = Next Hint / 事件解決 = Case Resolved
