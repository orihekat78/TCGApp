# 11. 物理プレイマットのデジタル化指針

> 出典: 公式チュートリアル動画(P0)+対戦動画(B群)で観察された物理マット使用法
> をWebアプリのプレイマット画面設計に落とし込む。

## 物理プレイマットの観察

公式の動画で繰り返し映る **「DETECTIVE CONAN」プレイマット** の特徴：

### レイアウト（プレイヤー目線）
```
┌────────────────────────────────────────────┐
│ [相手の領域 - 上下180度回転]               │
│ ┌──────┬──────────────────┬─────┬──────┐  │
│ │事件  │      現場(5枚)    │FILE │デッキ │  │
│ │      │                  │     │       │  │
│ ├──────┴──────────────────┴─────┴──────┤  │
│ │      パートナー   /   証拠           │  │
│ ├──────┬──────────────────┬─────┬──────┤  │
│ │事件  │      現場(5枚)    │FILE │デッキ │  │
│ │      │                  │     │       │  │
│ └──────┴──────────────────┴─────┴──────┘  │
│ [自分の領域]                              │
│                            [手札]         │
└────────────────────────────────────────────┘
```

中央の **鍵穴アイコン** はパートナーエリアと両プレイヤー区切りのシンボル。

### Webアプリでの転用方針
- **対称な縦長レイアウト**（相手は反転表示）
- 中央に鍵穴アイコン（ブランドアイデンティティ維持）
- カードは **クリックで詳細モーダル**、ドラッグで配置
- 手札は画面下部に **扇状** で表示（5-12枚想定）

## カードの状態表現

### 物理マットでの状態
| 状態 | 物理表現 | デジタル表現案 |
|------|----------|---------------|
| アクティブ | 縦向き | 標準表示 |
| スリープ | 横向き(90度回転) | 90度回転 + 半透明オーバーレイ |
| スタン | 上下逆向き(180度回転) | 180度回転 + 赤い枠 |
| 名乗り状態 | (区別なし) | カード上に「名乗り」バッジ |
| 解決編移行済 | マーカー裏返し | 事件カードに「解決編」アイコン |

→ アニメーション 0.3秒で回転。状態変化時は軽いハイライト点滅。

## カード重ね表示

### セットされたカード（[15-abilities-effects.md](../../rules/15-abilities-effects.md)）
- 物理: ベースカードの下に少しずらして配置
- デジタル: ベースカードに **左下にバッジ「+2セット」** 表示。タップで内訳ポップアップ

### 下に重ねるカード
- 物理: 完全に下に隠す（枚数のみ判別可）
- デジタル: ベースカードに **右上に枚数バッジ** のみ

## エリアごとの可視化

### 現場（最大5枚）
- 5枚スロットを常時表示（空きは点線枠）
- カード登場時は手札からスロットへ **0.4秒のスライドアニメ**

### FILEエリア
- 裏向きカードを **積み重ね**で表現
- 上のカードのみ「最新カード」として強調
- アシスト中のパートナーは **表向き** で混在

### 証拠エリア
- 裏向きカードを **斜めにずらして** 重ね、枚数を即座に把握できる
- 必要証拠数（先攻7/後攻6）に対する進捗バー併記

### リムーブエリア
- 表向きで山積み、最新リムーブのみ視認可
- クリックで全件一覧モーダル

### デッキ
- 残り枚数を裏向きカードの厚みで表現
- 残り3枚以下になったら警告色
