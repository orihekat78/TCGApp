# 10. 対戦UXのテンポ設計

> 出典: B群対戦動画3本（15ljHQuh7Hk / 2-tc_vfFhQQ / L_1DIgUH2uc）の字幕から
> 抽出した実プレイのテンポと、それをWebアプリで再現するための設計指針。

## 観察された対戦テンポ

### 1ターンの平均所要時間
- **短いターン（30秒以下）**: ターン序盤・ファイル増やすだけのオートフェイズ完了→ターンエンド
  - 例: 「アシストして1枚埋めます。終了です」
- **中ターン（30-90秒）**: アクション + コンタクト + ガード判定 1サイクル
  - 例: 「事件アクション → ガードなし → カットイン+1000 → リムーブ」
- **長考ターン（90秒以上）**: FILE+手札全件確認 + 効果連鎖（複数アクション+ヒラメキ+カットイン）
  - 例: ASOVIVA戦 06:30〜07:30で1ターン使用

### ゲーム全体長
- 短い決着: ~10分（弱い盤面状況だと早期終了、対戦動画2）
- 標準: ~20-25分（対戦動画3 / ASOVIVA戦）
- 長期戦: ~30分（リフレッシュを跨ぐ場合）

## Webアプリでのテンポ表現

### タイマー方針
- **ターンタイマー無し**（公式競技ルールにも持ち時間は無い）
- ただしCPU対戦時は思考時間 **0.5-2秒** で意図的に体感テンポを揃える
- 長時間放置時のみ「待機中…」インジケータ表示（10秒以降）

### CPUターンの可視化
人間プレイヤー側が「相手が今何をやったか」を理解できるよう、CPUの行動を **約0.6秒/アクション** でログに刻む：

```
[相手のターン]
🔄 オートフェイズ開始
   パートナー (江戸川コナン) アクティブ化
   現場キャラ全員アクティブ化
   デッキから1枚ドロー
   FILEに2枚追加 (現FILE: 5枚)
🎮 メインフェイズ
   アシスト (FILE → 6枚)
   手札使用: 服部平次 (Lv5) を現場に登場
   推理: 服部平次スリープ → 証拠+1 (現証拠: 3/6)
   ターンエンド
```

## ガード/カットイン UIの即応性

実対戦では **アクション宣言 → ガードするか即応** がテンポを決める：

- 「事件アクションです」「ガードなしで」「リムーブで○○」のフローが3秒以内に完了
- カットインも同様に「カットイン+1000で○○使います」が即応

### Webアプリ実装
- アクション宣言時は **モーダルで即時応答待ち**（5〜10秒のソフトタイムアウト）
- ガード可能なアクティブキャラがいない場合は **自動スキップ**（メッセージ「ガード可能なキャラなし、自動スキップ」）
- カットイン使用可能なカードがない場合も自動スキップ

## 効果スタック解決時の小休止

複数効果が連鎖する場面（ヒラメキ→ドロー→事件効果など）では、
プレイヤーが盤面を確認するために小休止する。

### 観察例
- 対戦動画2の04:48: 「えっと、なるほど。します」（数秒の確認）
- 対戦動画3の08:33: 「あ、これすね」（手札全件確認）

### Webアプリ実装
- 効果1つ解決ごとに **150ms のフェードアニメーション + 進捗ラベル更新**
- ユーザーが任意に「PAUSE」ボタンで盤面確認できるようにする
- 自動再生速度は 0.5x / 1x / 2x / 4x の4段階
