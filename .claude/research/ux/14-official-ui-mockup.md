# 14. 公式UIモックアップ観察（FIbGuJWdwNw 3D CG動画）

> 出典: P1動画 FIbGuJWdwNw（922フレーム取得・主要シーン読了）
> ★重要発見: この動画は **公式が作った3D CG UIモックアップ** で、Webアプリを設計する上で
> 「公式が考える理想UI」がそのまま参照できる。本プロジェクトはこのUIに準拠して実装する。

## 公式UIモックアップの構成要素

実物プレイマットではなく **CG レンダリング** で作られた仮想プレイマット上で、
2人のキャラ（先生役・学生役）が掛け合いしながらゲームを進める。

### 永続表示要素

| 位置 | 要素 | 例 |
|------|-----|----|
| 左上 | **章タグ** | 「対戦の準備」「先攻1ターン目」「後攻4ターン目」 |
| 左サイドバー | **3フェイズインジケータ** | オートフェイズ / メインフェイズ / エンドフェイズ（現在のフェイズが点灯） |
| 右サイドバー | **メインフェイズ6行動メニュー** | ①手札の使用 ②ネクストヒント ③パートナーの能力の使用 ④キャラの「宣言」能力の使用 ⑤推理 ⑥アクション |
| 右上 | **話者アバター** | 茶髪の女性ナレーターキャラ（先生役）の顔アイコン |
| 中央 | **3D CGプレイマット** | 自陣・相手陣の俯瞰、ネオン青枠でエリアハイライト |
| 下部左 | **学生キャラ吹き出し** | 「他にできることはありますか」など質問形式 |
| 下部 | **ナレーターメッセージ枠** | 黒背景の白テキスト、現在の操作説明 |

### 章タグの種類（観察）
- 「対戦の準備」
- 「先攻1ターン目」「先攻2ターン目」… 「先攻4ターン目」
- 「後攻1ターン目」… 「後攻3ターン目」

→ ターン番号が章タグとして可視化される。Webアプリでも同じ表示が望ましい。

### フェイズインジケータの状態
- 現在フェイズ: **青色塗り + 白文字**（点灯）
- それ以外: 青枠 + 半透明
- 順序は固定（オート→メイン→エンド）

### メインフェイズメニューのハイライト
- 現在実行中の行動: **緑色塗り + 白文字**（観察例: ⑥アクション、②ネクストヒント、④宣言能力）
- 候補：白枠+グレー塗り
- 不可：暗くフェード

→ Webアプリではメニュー項目の色変化で「いま何をしているか」を常時可視化。

### メインフェイズメニュー
- 6つの行動が **常時 番号付き縦リスト** で右サイドバーに固定表示
- ターンプレイヤーが行動可能なものだけハイライトされる
- 例: 名乗り状態キャラしかいない場合は ⑤推理 がグレーアウト

## 演出パターンの差分

短いP0動画（パートナー/フェイズ等）との違い：

| 観点 | P0 短編動画 | FIbGuJWdwNw 本編 |
|------|-----------|-------------------|
| 撮影 | 物理プレイマット俯瞰実写 | 3D CG プレイマット |
| 字幕 | 下部白枠+鍵穴 | 下部黒枠ナレーター + 上部キャラアバター対話 |
| 教える人 | テキストのみ | 学生キャラ + 先生キャラのキャラ対話 |
| ターン管理 | 表示なし | 左サイドバー固定 |
| 行動リスト | 説明時のみ表示 | 右サイドバー常時表示 |

→ **Webアプリは FIbGuJWdwNw の構成を踏襲** すべき。短編動画は概念導入のヒント源として使うが、ゲーム本体UIはこちらをベースにする。

## アクション対象選択UI（454s）

「『キャラ』と『事件』からアクションの対象を選ぶ!」
- 候補となる相手のスリープ/スタン状態キャラがハイライト
- 「※スタン状態の相手キャラも可能」と補足注釈
- 暗いオーバーレイで非対象を抑え、選択状態を明確化

→ **Webアプリ転用**: アクション宣言時にダーク半透明オーバーレイ、対象候補は青ハイライト + パルスアニメ。

## VS演出（594s）

「キャラ/事件に対するアクションを相手がガードしたとき」
→ 攻撃キャラ vs ガードキャラの **2カード並列大表示** + 中央に「VS」テキスト + AP表示
→ 「ガードした相手のキャラのAPのほうが大きかった場合、何も起こりません。」の注釈

→ **Webアプリ転用**: コンタクト演出は VS 大表示 + 両カードAPカウントアップ + 結果アニメ。

## JY5Ltx7fP-M（ふくらPスペシャル）で観察された追加UI規格

JY5Ltx7fP-M は **2人の解説者がリアルでステージ対戦している様子をライブ放送** する形式。
俯瞰盤面が上部、解説者カットインが画面下端、サイドバーにフェイズ/行動UIが常時表示される。
FIbGuJWdwNw のCG演出と異なる「実プレイ + UIオーバーレイ」スタイルだが、**UIの構成要素は共通**。

### 追加観察UI要素

| 要素 | 位置 | 表示例 |
|------|-----|--------|
| ターンインジケータ | 上部右枠 | 「▼平次ターン」「▼コナンターン」（パートナー名+「ターン」+▼） |
| 行動インジケータ | 上部右下 | 「推理」「ネクストヒント」「手札の使用『キャラカード』」「アクション: 相手の事件」 |
| 3フェイズインジケータ | 左右両サイド | 自分側左、相手側右に**鏡像配置**。現在フェイズは赤枠点灯（FIbGuJWdwNwは青塗り） |
| 解説者カットイン | 画面下左右 | 2人の解説者の上半身（小窓） |
| 字幕テロップ | 画面下中央 | 重要ポイント「相手のLPをマイナスすることができる」など |

### 行動インジケータの表記パターン
公式は **「行動カテゴリ + サブ情報」** を組み合わせた表記を使う：
- 「手札の使用『キャラカード』」「手札の使用『イベントカード』」（カテゴリ→対象種別）
- 「アクション: 相手の事件」「アクション: 相手のスリープしているキャラ」（カテゴリ→対象）
- 「推理」「ネクストヒント」「アシスト」（単一カテゴリ）

→ **Webアプリ転用**: 行動ログでも「カテゴリ + サブ情報」形式を踏襲する。
（[13-action-vocabulary.md](13-action-vocabulary.md) のログフォーマットと整合）

### フェイズインジケータの配色バリエーション

公式動画間で配色が異なる：
- **FIbGuJWdwNw**: 現在フェイズが青色塗り＋白文字
- **JY5Ltx7fP-M**: 現在フェイズが赤枠＋白文字

→ Webアプリでは **どちらか一方を採用**（青塗り推奨：可読性高い）

## 学生キャラの吹き出し活用（535s）

「本来なら『名乗り状態』ですが」（突撃の例外説明）のような **重要例外を学生役が口頭で再確認** する演出。
→ Webアプリ転用: チュートリアル中、特殊ルール発動時に「ヒント吹き出し」をポップで出して理解を補強。

## 勝利演出の背景（878s）

最終ターンでは **背景がセピア紙吹雪** に変わり、関連カード（パートナー・キャラ・事件）が画面に並ぶ。
コナンらしさを示す原作シーン（ピアノソナタ月光殺人事件）の挿絵も併用。
→ Webアプリ転用: 勝利時アニメで関連カード集合 + イラスト挿入。
