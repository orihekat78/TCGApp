# 03. 図解・アニメ・字幕の慣例（Webアプリ UI設計指針）

> 出典: P0スクショ 6本の視覚観察
> 公式動画で繰り返し使われる視覚パターンを抽出。Webアプリの演出/UI に踏襲推奨。

## 字幕テロップ枠

すべての解説動画で **画面下部に固定の白い字幕枠**：

- 左端: 鍵穴アイコン（探偵モチーフ）
- 中央: 解説テキスト（重要語は **赤色** ハイライト）
- 右端: 「DETECTIVE CONAN」ロゴ

**Webアプリ転用**: チュートリアル中の「解説バー」を画面下に固定。重要キーワードを `<strong class="key">` で赤強調。

## 章転換アニメ

新概念の章入りでは **大きな白いセリフ体テキスト** をフェードイン：
- 「オートフェイズ」（c1dkGthgkNY 10s）
- 「推理」（jIvnx9qREyM 16s）
- 「事件解決」（jIvnx9qREyM 50s）

背景は **プレイマット俯瞰 + 軽いブラー** で「これから扱う場面」を予示。

**Webアプリ転用**: レッスン開始時に画面中央に大文字を1〜2秒表示。背景は当該レッスンで使う盤面状態をぼかして表示。

## カード強調表示

### 単独大表示
キャラ説明や AP/LP 強調時はカード1枚を画面中央に大表示：
- 工藤新一(LP7000・事件レベル2)を中央に
- 服部平次のレベル/AP/特徴を強調
→ チュートリアル中は **1カード詳細モーダル** で同様の演出を。

### 並列比較表示
2枚のカードを並べてAP比較を可視化：
- 例: 工藤新一(7000) vs 服部平次(6000)
- AP値を **赤丸で囲んで強調**

**Webアプリ転用**: コンタクト演出は2カード並列 + AP値に赤い円アニメ。

### 5枚横並び
パートナーカード紹介時、代表5キャラを横一列で表示（安室/キッド/コナン/平次/赤井）。
→ パートナー選択画面のレイアウトに直接転用可。

## 漫画風吹き出し

要所で **黒枠の漫画風吹き出し** を使用：
- 「アクション」（Li8D1trbVV4 9s）
- 「アクションした側」（lVyM4mIvwxE 17s）
- 「真実はいつもひとつ!」（jIvnx9qREyM 64s・勝利演出）

**Webアプリ転用**: 行動宣言時とゲーム結果時に同様の吹き出しエフェクトを使うとブランド感が出る。

## ハンドジェスチャー（実演）

俯瞰プレイマット視点で人物の手が常に映り込む：
- カードを置く動作
- スリープへの回転動作
- 移動先を指差し

**Webアプリ転用**: チュートリアル中はカーソル/タップアニメで「ここを押す」を可視化。
プレイマット俯瞰 + ガイドの手 のメタファをそのまま採用するとUX一貫性が高い。

## 色コード

カードの色とキャラの色は厳密に一致：
- **青** (青背景) = 江戸川コナン陣営 / 工藤新一
- **緑** (緑背景) = 服部平次陣営
- **赤** (赤背景) = 赤井秀一
- **黄** (黄背景) = 安室透
- **白/モノクロ** = 怪盗キッド

色は **デッキ配色・字幕枠の左端ハイライト** に転用。コナン色 → 青、キッド色 → 白 を維持。

## 字幕レイアウトの典型サイズ

| 要素 | 観察値 | 推奨CSS |
|------|--------|---------|
| 字幕バー高さ | 動画の約12% | `height: 12vh` |
| キーワード強調色 | 赤 (#E62929 風) | `--key-color: #E62929` |
| 章転換大文字 | 動画幅の約30% | `font-size: 8vw` |
| カード単独表示 | 動画幅の約25-30% | カード詳細モーダル: `max-width: 30%` |

## 「※注意」赤枠ラベル

公式は **絶対に押さえてほしいルール** に **赤枠の「注意」ラベル** を付けて強調：

- パートナー動画69s: 「※注意 アシストしてるとそのターンは勝利できないよ!」
- 推理アクション動画68s: 「※注意『推理』と『アクション』はキャラが登場したターンはできないよ」

→ **Webアプリ転用**: チュートリアル中の「絶対覚えてほしいルール」は赤枠 + 「注意」アイコン + 必要なら「次に進む前に確認」のクイズ形式で出題。

## アンチパターン（やるべきでないこと）

公式が **避けている** 演出：
- カード/エリアの上に直接ARテキストを貼る → 見にくくなるため、字幕バーに分離
- 効果の数値変化を瞬間切替 → 必ず吹き出し or 補足テキストを伴う
- BGMを激しくする → ナレーション動画ではBGMは小さめ（情報優先）
