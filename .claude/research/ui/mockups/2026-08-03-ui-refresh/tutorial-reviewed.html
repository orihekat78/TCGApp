L1-2　デッキ構成

同じカードは最大 3 枚

デッキに入れられるのは、キャラとイベントです。カードの絵柄ではなく、カード ID が同じかどうかで枚数を数えます。

RULE 02
同じカード ID は最大 3 枚まで

絵柄が違っても ID が同じなら、同じカードとして扱います。
