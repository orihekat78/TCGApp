# 02. デジタルTCG UI慣例サーベイ

対象: Hearthstone (HS) / MTG Arena (MTGA) / Shadowverse (SV) / Pokemon TCG Live (PTCGL)
目的: コナンTCG Webアプリ実装時の参考となる「確立されたUI慣例」を抽出。

## 1. 手札表示

| アプリ | 配置 | ホバー挙動 |
|--------|------|-----------|
| HS | 中央寄せ扇形(card index で角度可変)、6枚超で重なり | 拡大プレビュー＋透明度で disabled 表現 |
| MTGA | 下端フラット並び、枚数増で重なり詰め | ホバーで上方向に拡大ポップ |
| SV | フラット並び＋微傾斜 | ホバーで上拡大 |
| PTCGL | フラット並び（ランドスケープでは下端整列） | タップ/ホバーで拡大 |

**示唆**: コナンは手札上限がゆるい(5枚開始＋ドロー＋ネクストヒント)ため、HS型の **扇形+重なり** が省スペース。ホバー拡大は必須慣例。

## 2. 対象選択UI（攻撃宣言→対象指定）

| アプリ | 表現 |
|--------|------|
| HS | ドラッグ＆ドロップ、ドラッグ中に発光する **矢印** が指先から target に伸びる |
| MTGA | クリックで攻撃宣言→矢印表示→ターゲットクリック確定。誤対象には警告ダイアログ(設定で有効化) |
| SV | ドラッグで攻撃線、有効ターゲットを発光、無効はグレー |
| PTCGL | タップ式（モバイル前提）、有効ターゲットのみ点滅 |

**示唆**: コナンの「アクション宣言→ガード判定→コンタクト」は **発光矢印＋有効ターゲット強調＋無効ダウン(半透明)** がデファクト。誤操作対策に **設定可能な確認ダイアログ** (MTGA 流) を持たせる価値あり。

## 3. 戦闘解決アニメーション

| アプリ | 演出 |
|--------|------|
| HS | 攻撃側が対象に物理的に体当たり→両者にAPダメージ数値ポップ |
| MTGA | カードが斜め前進、ダメージ数字オーバーレイ、地味めだが速い |
| SV | フルアニメ可。攻撃側が前進→斬撃エフェクト→数値表示。**設定でスキップ可** |
| PTCGL | エフェクトアニメ＋HPバー減少 |

**示唆**: コナンの **コンタクト(AP比べ)** は 「両者が中央に寄る→APを大きく数字表示→低い側がリムーブ」 が王道。**アニメスキップ設定** は SV/HS 共通の必須機能。

## 4. リソース可視化（コナンFILE相当）

| アプリ | 表示 | 「使用済/最大」表現 |
|--------|------|---------------------|
| HS | マナクリスタル横並び10個 | 使用済は割れた表示 |
| MTGA | 土地は専用列＋tap状態(横向き) | tap=横倒し |
| SV | PPゲージ＋クリスタルアイコン | 緑ゲージ減少 |
| PTCGL | エネルギーはカードに添付(可視) | 添付枚数で表示 |

**示唆**: コナンのFILEは「裏向き積み重ね+枚数バッジ」が物理同様。HS流クリスタル方式は不適合。**FILE 7枚閾値** は専用バー(プログレスバー)で別途可視化が必要。

## 5. フェイズ/ターン表示

| アプリ | 手法 |
|--------|------|
| HS | 中央 End Turn ボタンの色変化(黄→緑)、20秒で **燃える縄** で残り時間可視化 |
| MTGA | 画面右にフェイズステッパー(7フェイズを点で表示、現在ハイライト) |
| SV | 上部ターンインジケータ、フェイズ自動進行 |
| PTCGL | 上部バナーで自分/相手ターン明示 |

**示唆**: コナンは3フェイズだけなので **MTGA型のフェイズステッパー(オート→メイン→エンド)** が最適。自分ターンは盤面に色付きフチを付けるのも HS/SV 慣例。

## 6. 確認ダイアログ/モーダル

| アプリ | パターン |
|--------|---------|
| HS | モーダルを **極力避ける** ＝色変化＋ホバー矢印で代用 |
| MTGA | Gameplay Warnings 設定で誤操作確認モーダル(自陣ターゲットなど) |
| SV | カード詳細は別レイヤで拡大表示、半透明背景 |
| PTCGL | スタック相当の選択は明示プロンプト |

**示唆**: コナンの「アシスト宣言＝そのターン勝利不可」のような **不可逆操作** には MTGA型 opt-in 確認モーダル。カード詳細は右クリック/長押しで HS/SV 流のフルカード拡大ビュー。

## 7. デッキ/墓地/除外領域アクセス

| アプリ | 表現 |
|--------|------|
| HS | デッキ＝右側カード束(枚数バッジ)、墓地は基本非表示(履歴ログのみ) |
| MTGA | デッキ・墓地・追放領域がそれぞれ右側パネルのアイコン、クリックで展開 |
| SV | 同上、サイドアイコンから展開 |
| PTCGL | 各ゾーンがアイコン化、クリック展開 |

**示唆**: コナンの **FILE/証拠/リムーブ** の3領域は MTGA/SV 型 **右側アイコン群→クリック展開** がデファクト。FILE最上部はネクストヒント対象なので常時可視、他は隠して可。

## 主要な発見（要約）

- **手札=扇形ホバー拡大／攻撃=ドラッグ発光矢印／対象強調=ハイライト+無効半透明** は4アプリ横断のデファクト。
- **アニメスキップ設定** と **誤操作確認モーダル(opt-in)** はカジュアル長時間プレイの必須機能。
- **ゾーン領域は右側アイコン群+クリック展開** が MTGA/SV/PTCGL 共通慣例、コナンの3領域(FILE/証拠/リムーブ)にそのまま適用可能。
