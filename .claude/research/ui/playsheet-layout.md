# プレイシートUIレイアウト参照

公式プレイシート（[playsheet.pdf](.tmp/floor_rule/playsheet.pdf) → `.tmp/playsheet_png/page_01.png`）はUI設計の一次ソース。
タカラトミーが公式に提示する「プレイヤーのメンタルモデル」そのもの。

## 空間配置（横長プレイマット）

```
┌──────────────────────────────────────────────────┐
│ [事件 B]   現場（最大5人）           [デッキ C]  │
│                                                  │
│ [証拠]    パートナー(A)              [リムーブ]  │
│                                                  │
│           FILEエリア（横向き並べ）               │
└──────────────────────────────────────────────────┘
```

| 領域 | 位置 | 役割 |
|------|------|------|
| 現場 | 上中央 | キャラ最大5枚 |
| パートナー | 中央 | 配置マーカーA |
| 事件 | 左上 | 配置マーカーB（事件編/解決編） |
| デッキ | 右上 | 配置マーカーC |
| 証拠エリア | 左側 | 裏向きで重ねる |
| リムーブエリア | 右側 | リムーブされたカード |
| FILEエリア | 下中央 | 横向きで並べる、新しいものが上 |
| 手札 | プレイヤー手元 | 相手から不可視 |

## ビジュアルテーマ

- 黄色「KEEP OUT」テープ装飾（事件現場テーマ）
- 青いレンガ壁テクスチャ
- ダークネイビー基調（#0a1f2e〜#1a3a4f 想定）
- 各カード位置にターゲット/十字マーク

## UI転用要素

- **早見表のフローチャート** はそのまま操作ガイダンスUIに利用可能
  - 推理: スリープ→LP分の証拠
  - アクション: 対象選択→ガード判定→コンタクト→AP比較
- **配置マーカー(A/B/C)** はチュートリアルでのカード設置位置のヒント表示に使える
