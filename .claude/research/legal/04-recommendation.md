# 04. 本プロジェクトへの推奨スタンス

## 推奨運用：「完全ローカル限定 + 画像は同梱せず」

```
✓ 個人PC内で動作（localhost:3000 等）
✓ npm run dev で自分だけが起動
✓ カード画像は実行時に公式URLから都度フェッチ（IndexedDBにキャッシュ）
✓ カード効果テキスト・能力は要約・パラフレーズして実装
✓ ソースコードは GitHub プライベートリポジトリ（公開しない）
✗ 公開Webホスティング（Vercel等）はしない
✗ カード画像のリポジトリ同梱はしない
✗ npm に publish しない
```

これにより：
- 著作権法第30条「私的使用」の範囲内
- 他者への配布なし → 複製権・公衆送信権侵害なし
- 万一の警告にも個人PC内で停止すれば即対応可能

## 設計への影響（重要）

### A. カードデータの取得方式
- **「実行時の都度フェッチ + ローカルキャッシュ」** を前提に設計する
- 起動時に公式ページからメタ情報を取得 → IndexedDB / fs に保存
- 画像URLはホットリンクではなく一度ダウンロードして表示
- これにより **画像をリポジトリに含めない**

### B. カード効果の実装方式
- 効果テキストの **逐語コピーを避ける**
- 「効果の構造をTypeScriptで再現する」アプローチ
- カードファイルにはコード（処理）と最小限の参照情報のみ記載
- 公式テキストは別途 `cards/meta.json` 等にローカルキャッシュ（公開しない）

### C. リポジトリ運用
- `.gitignore` に以下を必ず含める:
  - `cards/images/` (取得した画像)
  - `cards/meta.json` (取得したメタ情報)
  - `*.cache` 等
- README に「個人利用限定・配布禁止」を明記
- LICENSE はソースコード部分のみ（カード関連は権利者表記）

### D. UI 上の表記
- 「This is an unofficial fan project for personal use only」
- 「© 青山剛昌／小学館 © TOMY」を起動画面に表記
- 「公式商品ではありません」を明示

## 公開を希望する場合の代替案

将来的に公開したくなった場合の選択肢：

| オプション | 内容 | 実現性 |
|-----------|------|--------|
| 1. 公式に許諾申請 | タカラトミーに正式に問い合わせ | ★ 個人だと回答困難 |
| 2. 公式と提携 | ライセンス契約（法人化必要） | ✕ 個人では不可 |
| 3. オリジナル化 | コナン要素を全て排除した独自TCGに改変 | ○ 最も安全だが趣旨が変わる |
| 4. 推奨運用維持 | 公開せず個人利用のみ | ✓ 最も現実的 |

## C&D を受けた場合の対応

万一権利者から停止要請を受けた場合は **即座に開発・利用を停止** する。
反論せず、リポジトリと配布物を全て削除する。これがファンメイド開発における最低限のマナー。

## 結論

**「完全ローカル限定・画像はリポジトリ同梱せず・実行時都度取得」** の運用方針で進める。
この前提が後続の調査（データ取得・アーキテクチャ・UI）の基盤となる。
