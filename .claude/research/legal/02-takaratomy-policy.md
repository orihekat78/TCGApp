# 02. タカラトミー / 名探偵コナンTCG 公式規約

## タカラトミーの一般サイトポリシー

### 著作権・商標権の帰属
> 「文章・画像・動画・ゲーム・商標・肖像等の著作権とその他の権利は、当社または原著作者のもの」

### コンテンツの二次利用
> 「ウェブデータは当社の許諾なく使用することは出来ません」

### 例外
> 「企業等が非営利目的で使用する場合、個人的な使用を目的とする場合、その他著作権法により認められている場合を除き」

→ **個人利用と非営利限定で一部例外あり**

## 名探偵コナンTCG 公式サイト

### 著作権表記
**© 青山剛昌／小学館 © TOMY**

### 利用規約抜粋
> 「本サイトに掲載されている、全ての画像及びテキストなどデータの **無断転載はお断り** します。」

→ カード画像・テキストのコピー&貼り付けは明確に禁止

### 二次創作・ファンメイドガイドライン
**記載なし**（本記事執筆時点）

## robots.txt

- `User-agent: *` / `Allow: /`
- Disallow なし
- Crawl-delay なし

→ クロール自体はBOTに対して許可されている。ただし **クロールできること** と **データを再配布できること** は別。

## 他タカラトミー製品の参考: デュエル・マスターズ プレイス

明示的な二次創作ガイドラインを持つ：

| 項目 | 規定 |
|------|------|
| 動画・スクリーンショット投稿 | ✓ 認める（YouTube/X等の認められたサービスに限定） |
| 動画の収益化 | ✓ 認める（権利者も収益化機能を利用する場合あり） |
| **ファンメイドゲーム・アプリ作成** | **記載なし** |
| 商業販売 | ✕ 禁止 |

→ デュエマでも「ファンメイドゲーム」は **想定外** 扱い。
コナンTCGでも同等の扱いと推測される。

## ホットリンク（公式画像URLを直接参照）の評価

- **複製権**: 自前でダウンロードしないので技術的には複製していない
- **公衆送信権**: 自分のサイトに表示することで再送信に該当する可能性
- **利用規約上**: 「無断転載はお断り」に該当する可能性高い
- **実害**: 公式サーバの帯域消費 + 著作権者の意図しない文脈での表示

→ **ホットリンクも安全とは言えない**。完全ローカル運用なら該当しない。
