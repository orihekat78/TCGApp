# UI 設計ブレインストーミング 議事録 (2026-05-11)

`superpowers:brainstorming` skill によるUI設計の決定事項。
このファイルから `specs/2026-05-11-ui-*.md` が派生する。

## 決定 Q1-Q10

| Q | 質問 | 決定 | 根拠 |
|---|------|-----|------|
| 1 | ターゲット環境 | Desktop only 1920×1080 (最低1280×720) | 実装シンプル化、ボード要素多 |
| 2 | 全体レイアウト | 公式プレイマット忠実 / サイドバーなし / 上端フェイズストリップ / 相手180°回転 / 中央 KEEP OUT 仕切り | [ux/14](../ux/14-official-ui-mockup.md), [ui/playsheet-layout](../ui/playsheet-layout.md) |
| 3 | カード上のオーバーレイ | 状態のみ (AP/LP/レベルはカード画像に任せる) | 公式カード画像尊重 |
| 4 | 手札表示 | 完全フラット (MTGA型) ホバーで上に浮く | [ui/02-industry-conventions](../ui/02-industry-conventions.md) |
| 5 | カード状態表現 | 回転(物理通り)+中央バッジ | 物理マット忠実 + 名乗り状態の判別容易 |
| 6 | 証拠展開UI | クリック展開、自分も裏向き表示、由来情報(ターン/推理元)のみ可視 | [rules/03,10,11](../../rules/03-field-areas.md) ルール厳守 |
| 7 | 対戦ログ | 下端折りたたみ | プレイマット占有最小化 |
| 8 | 対象選択 | クリック+確認 (MTGA型) | 不可逆操作の安全性 |
| 9 | 確認モーダル | 厳格モード (すべての行動で確認) | コナンの不可逆操作が多い |
| 10a | 視覚スタイル | プレイシート忠実 (ダークネイビー/レンガ壁/KEEP OUTテープ) | 公式テーマ最大化 |
| 10b | アニメーション | 標準 0.3-0.5秒 + 設定でスキップ可 | 業界慣例 (SV/HS) |

## ブレインストーミング中の重大修正

| # | 指摘 | 対応 |
