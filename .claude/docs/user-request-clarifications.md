## #5 アシスト時の解決編自動移行は「任意」ではない

### ユーザー指摘 (2026-05-21 user_request #5)

> 解決編に入るかは任意なので自動で入るのはおかしい

### 公式裁定

**公式マニュアル p.13 — 03.パートナーの能力の使用 / アシスト の Point:**

> ● 手順❷で条件を満たした場合は **必ず「事件」を解決編へ移行します。**
> （移行させないことはできません。）

**`.claude/rules/25-qa-effects-resolution.md` 末尾 Q&A 裁定:**

> Q: アシスト後、FILE7枚以上の条件を満たしたとき、解決編にしないことは可能?
> A: **不可。条件を満たした場合は必ず解決編へ移行する**

### 実装

`src/engine/mutate/partner.ts:57-59` の assist() が FILE ≥ 7 で必ず解決編へ
遷移する。**公式裁定通りであり修正不要**。

## #6 / #14 ネクストヒントは「手札使用回数を +1 する権利」ではない

### ユーザー指摘

- #6: ネクストヒントを宣言したのに、もう一枚手札から出せない (手札の使用
  回数が +1 しない)
- #14: ネクストヒントを行うと手札からカードが出せなくなる

### 公式裁定

**公式マニュアル p.12 — 02.ネクストヒント の Point:**

> ● ❷で使用できる手札は「ネクストヒント」1回につき1枚です。使用しないことも
>   選択できます。
> ● ❶〜❷までが「ネクストヒント」の範囲です。
>   ⇒❶と❷の間に他の行動 (アシスト など) を挟むことはできません。
>   ⇒**カードを使用する権利が増え、後で使えるわけではありません。**

**公式マニュアル p.10 (推測) / `.claude/rules/05-turn-phases.md` メインフェイズ表:**

> | 01 | 手札の使用 | 1ターン1回まで。**ネクストヒントを行ったターンは不可** |

### 仕様の整理

ネクストヒントは独立した別経路で、

1. NH 自体は同ターンに何度でも実行可 (制限なし)
2. NH 内 step ❷ で 1 枚使用可能 (NH 1 回につき 1 枚、選択しないことも可)
3. **NH を行ったターンは通常の「手札の使用」(メインフェイズ #01) は不可**
4. NH で出すカードは通常の hand-use カウンタを消費しない、後でも使えない

→ #14 の挙動 (NH 後に通常 hand-use 不可) は **仕様通り**。
→ #6 の期待 (NH で hand-use カウンタが +1) は **公式が明確に否定**:
   「カードを使用する権利が増え、後で使えるわけではありません」。

### 実装

- `src/engine/flow/main/next-hint.ts:68-74` は step ❷ で `nextHintUsed = true`
  をセット、handUseUsed カウンタは増やさない
- `src/engine/flow/main/hand-use-card.ts:116` の gate で `nextHintUsed` を
  チェックし通常 hand-use を reject

**公式裁定通りであり修正不要**。
