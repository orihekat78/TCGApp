# 23. Q&A: 変装 / カットイン の境界条件

公式投稿Q&A（事務局裁定）。変装は引継ぎ仕様が複雑なので特に注意。

> 出典: [公式投稿Q&A talk002](https://conan-tcg.commmune.com/view/box?boxId=talk002)

## 変装で引き継がれるもの（事務局裁定で明示）

| 項目 | 引き継がれる? |
|------|--------------|
| スリープ状態 | ✓ |
| 「コンタクトによってリムーブされない」効果 | ✓ |
| 「ターン終了時、このキャラをリムーブする」効果 | ✓ |
| カード名書き換え効果 | ✓ |
| 特徴の変更（特徴[警察]を失い、特徴[探偵]を持つ等） | ✓ |
| AP/LPの増減修正 | ✓ |
| 受けていた持続効果 | ✓ |

### 重要な注意点
- 元のカード自身の **カード名・色** は変装後のものに変わる（引き継がれない） <!-- qa-ref: qa-23-community-index -->
- 変装は **「登場」ではない** ため【登場時】能力は発動しない <!-- qa-ref: qa-23-community-index -->
- 変装したとき【変装時】能力は発動する <!-- qa-ref: qa-23-community-index -->
- 引き継いだ「ターン終了時にリムーブ」効果も、**現場を離れたら失われる** <!-- qa-ref: qa-23-community-index -->
  - 変装後のキャラがターン終了前に現場を離れた場合、ターン終了時のリムーブ効果は発動しない

## 変装時効果とコンタクト処理の順序

変装時効果は「〜してもよい」のため処理しない選択も可能。
処理する場合の順序：

```
変装宣言
  ↓
（元キャラをデッキ下へ、新キャラへ入替え）
  ↓
変装時効果の処理（任意）
  ↓
コンタクトのAP判定
```

## カットイン

### 制限
- **1コンタクトにつき1枚** だけ使用可 <!-- qa-ref: qa-23-community-index -->
- カットインを2つ以上持つカードを使う場合、**効果を1つ選んで使用** <!-- qa-ref: qa-23-community-index -->
- 自分の事件と同じ色を持たないカードでも使用可能（**色制限なし**） <!-- qa-ref: qa-23-community-index -->

### 効果範囲
- カットインによる効果は **コンタクト終了時に切れる** <!-- qa-ref: qa-23-community-index -->
- 使用したカードは **リムーブエリア** へ <!-- qa-ref: qa-23-community-index -->

### 「コンタクトによってリムーブされない」との関係
- カットインで「相手キャラをリムーブする」効果は、APではなく **直接リムーブ** なので、 <!-- qa-ref: qa-23-community-index -->
  「コンタクトによってリムーブされない」効果を貫通する

## 「現場リムーブ時」と コンタクト中の変装

- コンタクト中に変装で入れ替わった元キャラはデッキの下に行くため、 <!-- qa-ref: qa-23-community-index -->
  **「現場リムーブ時」効果は発動しない**（リムーブではないため）
