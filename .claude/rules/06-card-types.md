# 06. カード種別

名探偵コナンTCGは **4種類** のカードで構成される。

## パートナーカード

- デッキに **1枚のみ** 入れられる
- パートナーエリアに公開・アクティブで配置
- ゲームの中心となるカード
- 全パートナー共通の能力（アシスト・事件解決）を持つ
- **LP**（ロジックポイント）を持ち、推理時に証拠獲得枚数になる
- **自分のメインフェイズ中はいつでも行動可能**（推理 / アシスト / 事件解決）
  - 名乗り状態の概念は適用されない（ゲーム開始時から表向き・アクティブ）

### 表示情報
- カードの種類アイコン（"P"）
- カードの色 / カード名 / カードNo
- 能力 / レアリティ / ID
- LP値

## キャラカード

- 現場（自陣）に登場させて使用
- **AP**（アタックポイント）と **LP**（ロジックポイント）を持つ
- できる行動:
  - **推理**（スリープ化してLP分の証拠を集める）
  - **アクション**（攻撃 = 相手キャラのリムーブ・事件への攻撃）
- 個別の能力（カットイン、変装、ヒラメキ等）を持つ場合あり
- 同ターン内に登場したキャラは **名乗り状態** で推理・アクション不可
  - 例外: 迅速・突撃・疾風 持ちは登場ターンからアクション可

## イベントカード

- 使い切り（使用後 **リムーブエリア** に置く）
- 強力な単発効果を持つ
- 作中の状況・特定シーンを再現
- 左上のレベルが **FILEエリアの枚数以下** であれば手札から使用可能（[12-next-hint.md](12-next-hint.md) 参照）

## 事件カード

- 事件エリアに配置
- **事件レベル** が記載（必要証拠数に対応）
- 「事件編」「解決編」の状態を持つ
- アシストにより事件編→解決編へ変化
- **事件編／解決編マーカー** で現状態を物理的に示す
  - 状態移行時にマーカーを **裏返す**
  - 対戦型イベントでは使用が **義務**（フロアルール 3.2）
  - 配置方向（公式 p.5）:
    - **先攻** プレイヤー → **右下（後）の数字** を隠すように置く
    - **後攻** プレイヤー → **左下（先）の数字** を隠すように置く
