# 02. デッキ構築

## 必要カード（1人1セット）

| 種別 | 枚数 |
|------|------|
| パートナーカード | 1枚 |
| 事件カード | 1枚 |
| キャラ + イベント | 合計40枚 |
| **合計** | **42枚** |

## デッキ構築のルール（公式 p.7）

1. **デッキは40枚ちょうど** で構築する
2. キャラとイベントを入れられる（**パートナー、事件は入れられない**）
3. **同じカードは最大3枚まで**
   - 「同じカード」とは ID が同じカードのこと
   - 絵柄が違っても **ID が同じであれば同じカード** として扱う

## 色について

- デッキに入れるカードの **色に制限はない**
- ただしゲーム中に **「手札の使用」「ネクストヒント」** で使用する際は事件の色制限あり
  - 詳細: [20-color-and-switch.md](20-color-and-switch.md)
- パートナーは好きな色を使えるが、パートナーの色がカードの能力に影響することがある
  （[17-icons.md](17-icons.md) の【パートナー(色)】参照）
