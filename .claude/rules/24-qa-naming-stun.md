# 24. Q&A: 名乗り状態 / スタン状態 / 突撃・迅速

公式投稿Q&A（事務局裁定）。

> 出典: [公式投稿Q&A talk002](https://conan-tcg.commmune.com/view/box?boxId=talk002)

## 名乗り状態の正確な仕様

- 名乗り状態の制限は **「推理」と「アクション」が不可** の **2つだけ**
- これ以外の動作は名乗り状態でも可能：
  - 【宣言】能力の使用 ✓
  - ガード ✓
  - スイッチによるリムーブ ✓
  - カットイン使用 ✓
  - 変装使用 ✓

## 突撃で開始したアクション

### Q: 名乗り状態で突撃を持ったキャラがアクション、その後アクティブ化したら推理可？
**A: 不可**

> 「このターン中は名乗り状態であることは変わらないので、アクションはできますが（迅速を持っていなければ）推理はできません」

つまり：
- **アクティブ化 ≠ 名乗り状態の解除**
- 名乗り状態は **登場ターンが終わるまで維持**
- 突撃のみではアクションだけ可能、推理は迅速がないと不可

## 「〜の場合」型能力（常時有効）の挙動

### Q: 「APが6000以上の場合、突撃を持つ」のような能力は？
**A: 発動するものではなく、有効である限り自動的に効果を持つ**

- 条件を満たしている間 → 効果を持つ
- 条件を満たさなくなった瞬間 → **効果も失われる**
- これは【自分ターン中】や【相手ターン中】の常時系能力も同じ

### アクション継続性との関係

- **既に開始したアクションは、途中で条件を満たさなくなっても継続する**
  - 例: 突撃を失った状態でもコンタクト判定まで進む

## スタン状態の特殊挙動（再掲・要注意）

スタン状態は **3つ目の状態** で、特殊な挙動を持つ：

| 状況 | 挙動 |
|------|------|
| アクティブにする効果を受けた | **代わりにスリープ状態** になる（スタン解除されない） |
| スリープさせる効果を受けた | スタン状態のまま |
| スタンさせる効果を受けた | スタン状態のまま |

スタンの解除には **明示的なスタン解除効果** が必要。

## 同時発動と能力解決順

### Q: 同じカードが複数いて条件を満たしたとき
**A: すべて同時に発動。所有者が好きな順で解決**

- 条件を満たしたとき発動を **選択しないことは不可**（必ず発動）
- 効果は同時発動だが、解決は1つずつ順に

### Q: 効果が発動したが、内容が解決できなかった場合
**A: それでも「発動した」扱い**。【ターン1】等の回数制限カウントされる

- 例: 「相手の現場のレベル7以下を1枚引く」で対象がいない場合でも、
  能力そのものは発動済みで、このターン中は再発動不可
