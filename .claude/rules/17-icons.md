# 17. アイコン

カードテキスト内の各種アイコンの意味。
（他のページで詳細説明のあるものは省略）

## 能力が発動するタイミング

| アイコン | 意味 |
|---------|------|
| 【登場時】 | キャラが現場に登場したときに発動。能力/効果による登場でも発動 |
| 【現場リムーブ時】 | 現場からリムーブされたときに発動。リムーブ方法は問わない |
| 【変装時】 | 変装で現場に現れたときに発動 |
| 【疾風 N】 | 自分の現場にこのターン **N番目** に登場したときに発動 |

### 【疾風 N】の補足
- 能力や効果による登場でも条件を満たしていれば発動
- 相手のターン中に登場しても、条件を満たせば発動
- 同時に2枚以上登場、条件を満たせばすべて発動

## 能力/効果が有効となる条件

| アイコン | 意味 |
|---------|------|
| 【自分ターン中】 | 自分のターン中である |
| 【相手ターン中】 | 相手のターン中である |
| 【パートナー(色)】 | 自分のパートナーが指定の色を持つ |
| 【事件(色)】 | 自分の「事件」が指定の色/特徴を持つ |
| 【FILE(X)】 | 自分のFILEエリアのカードが指定の枚数以上 |
| 【事件編】 | 自分の「事件」が事件編である |
| 【解決編】 | 自分の「事件」が解決編である |
| 【絆 (カード名)】 | 自分の「現場」に指定の[カード名]のキャラがいる |

### 補足
- **【事件(色)】**: 「事件」が2色以上ある場合でも、指定色を持っていれば有効
- **【事件(色1)&(色2)】**: 「&」で2色以上指定 → **すべての色を持つ必要あり**
- **【FILE(X)】**: アシストしているパートナーも枚数に数える
- **【絆】**: パートナーでは条件を満たさない

### Point: 条件を満たしていない場合

これらのアイコンの条件を満たしていない場合、
**その能力／効果のテキストは有効でない**：

- 「〜したとき」などの条件を満たしても発動しない
- 宣言能力であれば使用できない
- イベント／カットイン／ヒラメキは使用・発動できるが、何も起こらない
- アイコン自体は有効でないテキストからも参照できる。テキストを参照する効果とは区別する

### Q&A: 「〜の能力を持つ」参照は印字で判定 (2026-06-12 収載)

> 出典: cards-data TSV qAndA (B08082/B08094/B09104/B09073/B09090/B07102/B07100/B08078)

- 他のカードが「**【現場リムーブ時】/【疾風】/【カットイン】等を持つ** キャラ/カード」を参照する場合、
  **テキストに印字されているか (静的)** で判定し、上記 Point の条件アイコン充足は **問わない**
  （例:【相手ターン中】【現場リムーブ時】持ちは自分ターン中でも「持つ」に該当）
- 上記 Point の無効化は、その能力 **テキスト** の発動/使用/効果にのみ及ぶ
- 効果で **付与** された能力も「持つ」に該当する（B07100 裁定）
- テキスト中の **言及** のみでは所持にならない（B02044 裁定）

## 能力の使用/発動の回数制限

| アイコン | 意味 |
|---------|------|
| 【ターン①】 | 各ターンに1回だけ発動（宣言能力なら1回だけ使用可） |
| 【ターン②】 | 各ターンに2回まで発動 |
