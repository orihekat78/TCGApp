# 26. Q&A: リフレッシュ / デッキ操作 / 痕跡

公式投稿Q&A（事務局裁定）。

> 出典: [公式投稿Q&A talk002](https://conan-tcg.commmune.com/view/box?boxId=talk002)

## 「上から○枚リムーブ」効果でデッキ不足

### 裁定
- デッキが○枚未満なら、**可能な限りの枚数をリムーブ**
- その後 **リフレッシュ** を行う
- リフレッシュ後に **残り枚数分は追加でリムーブしない**
- 効果に「カードを1枚引く」等が続く場合、リフレッシュ後にその部分を解決

### 例
- 「上から3枚リムーブし、カードを1枚引く」効果
- デッキ残り1枚 → 1枚リムーブ → リフレッシュ → 1枚引く

## 「上から○枚見る/公開」効果中のリフレッシュ判定

### 裁定
- 見ている / 公開している間は **「デッキにあるカード」扱い**
- 「残りをリムーブエリアに移す」など最終操作まで完了したところで **デッキ0枚** と認識される
- そのタイミングでリフレッシュ発生

### 例
- 「上から3枚見て、条件を満たすカードを手札に加え、残りはリムーブ」
- → 3枚を「見ている」間はリフレッシュしない
- → 残りをリムーブエリアに移した瞬間にデッキ0枚 → リフレッシュ

## リフレッシュとリムーブエリアの遷移

### イベント / ヒラメキ（解決中）
- 効果を解決し終えるまで、そのカードは **まだリムーブエリアに置かれていない**
- リフレッシュ時のシャッフル対象に **含まれない**

### カットイン / 現場リムーブ時
- リムーブエリアに置かれた状態で効果解決
- リフレッシュ時のシャッフル対象に **含まれる**

## デッキ切れによる敗北

- リフレッシュを行う際、**リムーブエリアが0枚** だった場合 → そのプレイヤーは **敗北**

## 痕跡の判定

### 状態
- 痕跡 [未発見]: 初期状態
- 痕跡 [発見済み]: 相手がリフレッシュした時点でこちらが移行
- 一度 [発見済み] になると **このゲーム中ずっと維持**

### 重要な裁定
- **自分のリフレッシュでは痕跡を発見できない**（相手のリフレッシュのみがトリガー）
- 痕跡 [未発見] 状態でも痕跡関連の選択肢を **選ぶことは可能**（何も起こらないだけ）

## 宣言能力のコストとデッキ不足

- コストで「○枚リムーブ」が指定されているとき、デッキが○枚未満なら **能力使用不可**
- コストは「すべて行う」必要があり、一部でも行えなければ使用できない

## deck-look の取得選択 (カード個別 公式Q&A、2026-06-12 収載)

> 出典: cards-data TSV qAndA (B08020/B01048/B01050/B04023/B07089/B05017/B05094/B06010/PR117)。
> BUG-132 GAP-1 の一次根拠。

- **「N枚見て…1枚まで…手札に加え」型** (B08020 等): 条件を満たすカードがあっても
  **加えないことを選択可** (「まで」=0枚可、rules/15)。加えなければ後続の「加えた場合〜」も不成立
- **「N枚見て…1枚手札に加え」型** (B01048): 「1枚まで」ではないので**必ず1枚加える**
- **「公開したカードが〜の場合、手札に加える」型** (B01050/B04023/B07089): **必ず加える**
  (デッキ下に移す選択は不可)
- **「〜が出るまで1枚ずつ公開し、それを手札に加える」型** (B05017/B05094/B06010/PR117/PR118):
  **必ずそれ (条件に合うカードで最初に公開されたもの) を加える**。全公開で不在なら何も加えず
  全部デッキに戻してシャッフル
- デッキが N 枚ない場合: 残り全部を見て解決。見ている間はまだデッキ扱いで、**加えた時点**で
  デッキ0ならリフレッシュ (本ファイル上段の reveal 中判定と整合)
