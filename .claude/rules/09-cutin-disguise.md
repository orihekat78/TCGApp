# 09. コンタクト中の行動: カットイン / 変装

コンタクト中、各プレイヤーが選べる行動は以下2種類（または パス）。
**1コンタクトにつき1回（1枚）まで**。

## カットイン

### 効果
手札からカットイン能力を持つカードを使い、コンタクトを支援する。

### 処理
1. 手札のカットイン持ちカードを選ぶ
2. 効果を解決
3. 使用したカードは **リムーブエリア** へ

### 例
「カットイン AP+2000」 — コンタクト中のキャラをAP+2000する

### 効果の持続
- カットインによる効果は **コンタクト終了時に切れる**

### 制限・補足
- カットインは1回につき **1枚だけ** 使用可（2枚以上は不可）
- カットインを2つ以上持つカードを使う場合、**効果を1つ選んで** 使用（複数同時は不可）
- 自分の事件と同じ色を持たないカードでも使用可能

---

## 変装

### 効果
手札から **変装** を持つキャラカードを、コンタクト中のキャラと **入れ替える**。

### 処理
1. 手札の変装持ちキャラカードを選択
2. コンタクト中の自分のキャラと入れ替える
3. 元のキャラは **裏向きでデッキの下** に移す
4. 入れ替わったキャラがコンタクト中の状態になる

### 引き継がれるもの

| 項目 | 引き継ぎ |
|------|----------|
| スリープ状態 | ○ |
| 他のカードに与えられた能力・効果 | ○ |
| セットされている / 重なっているカード | ○ |
| カード名・色などの自身の情報 | ✕（変装後のものに変わる） |

### 重要な注意点

- 変装は **「登場」ではない**
  - 「登場時」やキャラの登場で発動する能力は **発動しない**
- 変装したとき、そのキャラの **「変装時」能力** が発動する
