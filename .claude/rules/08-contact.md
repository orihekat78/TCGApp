# 08. コンタクト処理

「コンタクト」はアクション[キャラ]がガードされた／されなかった場合、
攻撃キャラと対象キャラ（またはガードキャラ）の間で発生するAP比べ。

## 発生条件

- **アクション[キャラ]がガードされなかった場合**: 攻撃キャラ vs 対象キャラ
- **アクションがガードされた場合**: 攻撃キャラ vs ガードキャラ

## 処理手順

### 1. 行動順の確認

- コンタクト中のキャラのAPを比べる
- **APが低いほうのプレイヤーが1番目**
- **APが高いほうのプレイヤーが2番目**
- APが同じ場合は **アクションされた側（=非ターンプレイヤー）が1番目**

### 2. 1番目の行動

- 行動オプション: **カットイン** / **変装** / **パス**
- 1コンタクトにつき **1回（1枚）まで**
- 詳細: [09-cutin-disguise.md](09-cutin-disguise.md)

### 3. 2番目の行動

- 同じく カットイン / 変装 / パス を選択
- 1コンタクトにつき1回まで

### 4. 1番目の再行動（条件付き）

- **1番目がパスし、2番目が行動していた場合のみ**、1番目が再度行動できる

### 5. APの判定

| 条件 | 結果 |
|------|------|
| アクションキャラのAP **≧** 相手キャラのAP | 相手キャラを **リムーブ** |
| アクションキャラのAP **<** 相手キャラのAP | 何も起こらない |

- **APが同じでもリムーブ**する
- AP不足でも **アクションしたキャラはリムーブされない**

### 6. コンタクトの終了

- カットインによるAP+ などコンタクト中の効果が切れる
- ※ コンタクト中にいずれかのキャラが現場を離れた場合、その時点でここまで進める
- 「コンタクトを発生させる」効果によるコンタクトはここで終了する

### 7. アクションの終了

- アクション終了時の能力が発動し、効果を解決
- アクション中の効果が切れる
