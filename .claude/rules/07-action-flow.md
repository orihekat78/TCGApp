# 07. アクション全体フロー

「アクション」は相手の現場のキャラを減らしたり、相手の証拠を減らして自分の証拠を増やす行動。

## 実行条件

- 自分の **現場** にいる **アクティブ状態** のキャラが行うアクション
- パートナーカードもアクション可能（アクティブ状態であれば）
- **名乗り状態** のキャラはアクション不可（迅速・突撃・疾風 持ちは例外）
- キャラごとに1ターン中の回数制限はない（再アクティブ化されれば再アクション可）

## 対象

| 対象 | 制限 |
|------|------|
| 相手の現場のキャラ（**スリープ または スタン状態**） | アクティブ状態の相手キャラは対象不可 |
| 相手の事件 | **証拠が1つもない事件** は対象不可 |

## 全体フロー

1. **アクションの宣言** — 対象を指定し、アクションするキャラをスリープさせる
2. **ガード判定** — 相手は現場のアクティブ状態のキャラ1枚でガード可
   - 名乗り状態のキャラでもガード可能
   - AP条件なし
   - ガードしたキャラはスリープになる
3. 分岐:
   - **アクション[キャラ]がガードされた** → コンタクト発生（攻撃キャラ vs ガードキャラ）
   - **アクション[キャラ]がガードされなかった** → コンタクト発生（攻撃キャラ vs 対象キャラ）
   - **アクション[事件]がガードされなかった** → 証拠リムーブ + 自証拠獲得
4. **コンタクト処理** または **証拠処理** を実行
5. **アクション終了** — 終了時能力が発動 → アクション中の効果が切れる

## 補足

- ガードまでにアクションキャラ or 対象キャラが現場を離れた場合、
  アクションはその時点で終了する
