# 11. 推理

## 概要

アクティブなパートナーまたはキャラをスリープ化し、
そのカードの **LP値** 分だけデッキ上から証拠を追加する。
証拠を集める主要な手段。

## 処理手順

1. アクティブな自キャラ（or パートナー）を1体選択
2. 選択したカードを **スリープ化**
3. デッキ最上部から **LP枚数分** を **裏向き** で証拠エリアに追加

## 制限

- **同ターン内に登場したキャラ（名乗り状態）は推理不可**
- スリープ状態のキャラ・パートナーは推理不可（既にスリープ）

## 開始可能タイミング（公式 p.15）

- 推理は **先攻プレイヤーの1ターン目から行える**
- パートナー・キャラごとの1ターン中の回数制限なし
  - アクティブ状態に戻れば再度推理可能

## ⚠ LP 0以下の場合（公式 p.15）

- 推理対象の **LPが0以下** の場合、**証拠を1つも得ない**
- 例: ミスリード等で LP が下がった結果 0 以下になっていた場合
- 推理自体は実行（スリープ化）されるが、得られる証拠は0枚

## アクションとの違い

| 観点 | 推理 | アクション[事件] |
|------|------|------------------|
| 証拠の増え方 | +LP枚 | +1枚（固定） |
| 相手への影響 | なし | 相手証拠 -1 |
| カード状態 | スリープ化 | スリープ化 |
| 制限 | 名乗り状態は不可 | 名乗り状態は不可 |
| 妨害 | なし | ガード可能 |

## 戦略上の役割

- LPの高いキャラ・パートナー → 推理で大量加点が有効
- APの高いキャラ → アクション（破壊・事件攻撃）で盤面・証拠への影響
