# B07033 FILE6 Disguise omission

## Expected

- B07033/P/P2はFILE6で通常の変装を使用できる。
- 変装後、印字された変装時能力が発動する。

## Actual

- `disguise:into` observerだけ存在し、`icon-disguise`能力が無かった。
- 実contactの`canDisguise`がfalseとなり、後段能力へ到達不能だった。

## Root cause and fix

- カード出荷時に変装後段だけを実装し、アイコン能力列を取り込まなかった。
- 既存a0/a1/a2を維持し、FILE6条件の`a3`を末尾追加した。

## Horizontal investigation and prevention

- Base/P/P2、両owner、実contact、FILE6、PA9枚目追加をpublic test化。
- ability indexはappend-only。旧save/replayのa0/a1/a2を保持する。
- `lint:icon-abilities`に加え、実`canDisguise`経路を完了条件とする。
