# B05092 zero-selection shuffle

## Expected

- 手札から0枚を選んでもデッキをshuffleする。
- B05092使用後に他の手札が0枚でも同じ。
- 移動数0なのでカードは引かない。

## Actual

- `pickedUid:null`は通常pick辞退としてatom全体を破棄した。
- 候補0ではhandlerが再pickを試みて終わり、shuffleへ到達しなかった。

## Root cause and fix

- B05092に0枚をatomの空解決として扱うauthorityが無かった。
- descriptorへ`skipResolvesAtom:true`を追加した。
- `handToDeckBottom`はopt-in時だけ辞退/空手札を`hdMove([])`へ渡し、
  `shuffleThenDrawMoved`のshuffleを実行する。

## Horizontal investigation

- `shuffleThenDrawMoved` consumerはB05092だけ。
- 他の`skipResolvesAtom` consumerは別verbで、既存空解決契約を維持する。
- 候補ありの0枚選択と候補0を両ownerで確認した。

## Prevention

- 「N枚まで」の後に必須処理が続くatomは、0枚をskipと同一視しない。
- voluntary zeroとzero candidateを別fixtureで固定する。
