## ユーザー指摘

> #11: リムーブエリアのカードを個別で選択した際に、カードを拡大できない。

## 期待動作

`CardListModal` (リムーブ / FILE / 証拠 エリアの内容確認 modal) で表示中の
個別カードをクリックすると `CardExpandModal` が開く。

## 修正

### `src/ui/components/CardListModal.tsx`

- props に optional `onExpand?: (cardId: CardId) => void` を追加
- 各カード item を、`onExpand` 指定時は `<button>` (クリック可能)、未指定なら
  従来 `<div>` で render する条件分岐
- aria-label + data-testid 完備

### `src/ui/components/CardListModal.css`

- `.card-list-item--clickable` セレクタ追加: cursor pointer / hover で scale +
  border highlight / focus-visible outline

### `src/ui/components/Playmat.tsx`

- `CardListModal` 呼出時に `onExpand={(cardId) => expandModal.open(cardId)}` 配線
- 既存 `expandModal` (useCardExpandModal) を再利用 (右側に既に
  `<CardExpandModal cardId={expandModal.expandedCard} ...>` がある)

## 検証

- vitest UI 379 PASS / 1 skipped
- typecheck clean
- 既存 CardListModal を他で使用している場合の backwards compat: `onExpand`
  指定なしなら従来通り静的 div で描画
