# B06027 direct-invoke full-scene switch

## Expected

- 現場5枚でも、所有者が自分のキャラを正確に選んでスイッチできる。
- 選択後、B06027は証拠からスリープ状態で登場する。

## Actual

- 通常actionヒラメキは事前`switchRemoveUid`を注入した。
- B06023の直接invokeはその経路を通らず、満員時に登場をskipした。

## Root cause and fix

- B06027の`sceneEnter`に第二決定のauthority指定がなかった。
- `deferSceneSwitchChoice: true`を追加し、既存state-owned pickerを再利用。
- 選択後も元のevidence occurrence witnessを再検証してから消費する。

## Horizontal investigation

- `$occurrence.cardId`自己登場はB06025/B06027だけ。
- B06025は先行sceneRemove成功時だけ登場するため必ず空きを作る。
- 汎用deferred switchのsave/hydration回帰は既存suiteで維持。
