## Expected

If `partner.cardId` is empty, UI enumeration and public dispatch must reject both common partner actions. Both actions require an unfinished game, the acting player's own main phase, an active partner in `partner-area`, and compatibility with optional fields omitted by old saves. `canWin` remains a state-query and must not inherit action-only terminal/turn/phase gates.

## Actual

`createEmptyGameState()` defaults the partner state to active / partner-area. Assist therefore accepts no-card state. If case/evidence prerequisites are supplied, solveCase accepts no-card state or `mr-removed`. Both actions were also exposed in auto/end, out-of-turn, and terminal states. The initial QA fixture used `auto`, which could mask inactive-partner negatives.

## RCA

UI、public dispatch、AIが別々に同じ条件を再実装していた。assistはidentity/turn/phaseを、solveCaseはidentity/location/turn/phaseを欠落。common reader化の初版は`gameResult`を欠落し、さらに`canWin`がaction readerを呼んでstate-queryへ手番/phase/identity gateを混入させた。

## Prevention

Common partner actionは必ず`read.game`のreaderを通す。terminal、no-card、手番/phase、非partner-area、正常partner-area、旧保存をUI・public dispatch・AIで回帰する。state query (`canWin`) と実行可能action eligibilityを混ぜない。
