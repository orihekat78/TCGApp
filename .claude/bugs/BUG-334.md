# deck-window public continuation loss

## 期待動作

0枚までのdeck-window選択を辞退しても、選択atomを0枚解決し、保存された
sequence remainderを同じbindings/source authorityで続ける。ターン終了中も
remainder完了前にturn transitionを進めない。

## 修正前

- B09078の`handAddFromDeck cardIds:'$pick.cardIds'`を辞退すると同じpickを再queueした。
- B10097のpartner-area end trigger辞退では、sourceがpartner areaを離れてから
  remainderへ進み、`boundToRemove`が実行されずdeckが残った。

## RCAと修正

- `handAddFromDeck`のmulti-pick carrierに`__declined`空解決が無かった。
- `deferRefresh`中でもpre-take empty guardがrefreshしていた。
- `applyPickSkipAndContinuation`がpure binding atom `deckRevealUntil`の直後に
  `runAllUntilEmpty`し、held continuationよりturn transitionを先行させた。
- declineは空bindingを書いて終了。deferred pre-refreshを抑止。
- `deckRevealUntil`はheld remainderへ直行し、continuation完了後にresolverをdrain。
