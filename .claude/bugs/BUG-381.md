# revealFromHand public occurrence missing

## Expected

- 人間は複数の適格な手札occurrenceから、公開コストに使う札を明示選択する。
- 選択札だけを双方へ公開し、コスト完了後、効果解決開始前に再秘匿する。
- 手札自体は移動せず、不正・重複indexは原子的に拒否する。

## Actual

- `revealFromHand`は適格候補の先頭へfallbackし、人間の選択経路がなかった。
- `hand:reveal` hookは出たが、公開presentation stateが存在しなかった。

## Root cause and fix

- `AbilityCostParams`とactions panelに`revealFromHand` witnessが未配線だった。
- 既存hand cost pickerをrange対応で再利用し、exact indicesをengineへ渡す。
- payment完了時に`pendingPublicHandReveal`をpresentation lifetimeでqueueする。
- rollback時はactivation前のpending runtime snapshotを復元する。

## Horizontal investigation and prevention

- 全`revealFromHand` CardDef、AI/legacy fallback、duplicate/ineligible indexを走査した。
- B08093の両owner公開窓とB09004/B10006 observerを実dispatchで固定した。
