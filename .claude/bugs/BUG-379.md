# B08034 reasoning timing hook mismatch

## Expected

- B08034の推理反応は、推理キャラをスリープした直後に発動する。
- ミスリードと証拠獲得より前に、全コピーを所有者順で解決する。

## Actual

- CardDefが`reasoning:end`を購読していた。
- 証拠獲得後に反応がqueueされ、公式Q&Aの解決窓より遅かった。

## Root cause and fix

- 「推理したとき」を完了後hookへ機械対応し、個別Q&Aの中間窓を落としていた。
- B08034 a2だけを`reasoning:after-sleep`へ変更した。
- B08034Pはbase CardDef継承のため同時に修正される。

## Horizontal investigation and prevention

- `reasoning:end` CardDef consumerを全走査した。
- B01017/B01074/B05011/B05039には本個別Q&Aを一般化せず、別authorityで再裁定する。
- 両owner、証拠0のorder境界、継続token、2コピー逆順、各set removal/draw、
  最後の証拠獲得を公開dispatchで固定した。
