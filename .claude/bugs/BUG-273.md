# 攻撃対象がないアクション元を選べて操作不能になる

## 再現

1. YOU-vs-CPU row 024 で、相手のスリープ/スタンキャラも事件攻撃可能条件もない盤面にする。
2. 「アクション」を押し、表示された自分のアクション元を選ぶ。
3. 相手側の候補が0枚のまま対象選択になり、全操作とターン終了がロックされる。

## 期待 / 実際

- 期待: 合法対象を持つアクション元だけを提示する。存在しなければ picker を開かない。
- 実際: 元の候補だけを列挙したため、空の target picker が未解決で残った。

## 修正 / 検証

- `runActionFlow` で、各元に `enumActionTargetCandidates` が1件以上あることを確認してから picker を開く。
- `useActionsPanelFlow.action` に、対象なしでは source picker を開かない回帰を追加。
- 横断: 同じ flow は partner と scene の両方を同じ filter で扱う。
