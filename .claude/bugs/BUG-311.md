# 強制公開サーチの不要な順序選択

## 期待動作

B02058、B02058P、B03019、B05021、B05094は、一致カードを強制的に手札へ加え、
残りをデッキ下へ移した後、デッキ全体をシャッフルする。印字にない順序選択を要求しない。

## 実動作（修正前）

`deckToBottomBound`の既定`arbitrary`により、人間所有者かつ残り2枚以上で
`pendingDeckReorder`が発生した。直後に全デッキをシャッフルするため、選択は不要かつ無意味だった。

## RCAと修正

4つの実カード定義とB02058Pで`order:'preserve'`が未指定だった。全対象へ明示し、
公開leave経路で強制取得、no-match、no-reorder、shuffle、負例、重複、refreshを固定する。

## 横断調査と予防

同じ`deckRevealUntil -> deckToBottomBound -> deckShuffle`形を横断確認する。
印字に順序選択がない同型32定義が残るため、本BUGは全件の公式印字確認と明示order化まで閉じない。
各public human testで`pendingDeckReorder === null`を検証する。
