## Expected

CT-P10 B10098's selector accepts a character whose printed 【突撃】 is enabled
by its own condition icon, but rejects a character given 【突撃】 by an ordinary
ability. When the icon condition is unmet, that character is not selectable.

## Actual

`keyword` reads all effective keywords. It therefore accepts both the allowed
condition-icon path and the prohibited ordinary ability-grant path.

## RCA

The keyword reader merges three semantically different sources: printed text,
the card's own condition-icon keyword, and external keyword grants. No filter
preserves the first two while excluding the third.

## Related files

- `src/engine/types/effect.ts`
- `src/engine/target/candidates.ts`

## Horizontal investigation

The future reader must be evaluated across remove/deck, scene, and bound paths,
and must not reclassify ordinary continuous `grantKeywords` as condition icons.

## Prevention

Add a dedicated source-aware keyword reader. Test icon enabled, icon unmet,
ordinary grant, printed keyword, deck/remove, and bound resolution.
