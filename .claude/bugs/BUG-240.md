## RCA

The fixed HUD sat at z-index 9100 and only passed pointer input through below 640px; 851px landscape therefore let its empty section intercept CardList controls.

## Evidence

- `src/ui/components/SpectatorHUD.css`
- `src/ui/components/CardListModal.css`
- `tests/e2e/user-bug-wave-ui.spec.ts`

## Verification

RED `elementFromPoint` failed at 851x393; GREEN uses a real close click, a HUD pause click, button-gap coordinates, and a console-zero assertion. `dfbde24d` strengthens gap coverage.

## Horizontal investigation

RecentActionToast, OppTurnOverlay, RefreshOverlay, TutorialOverlay, and EffectStackPanel already use pass-through layout surfaces.

## Prevention

Every non-modal overlay above ordinary modals passes pointer input through all layout-only wrappers and tests real overlap coordinates.
