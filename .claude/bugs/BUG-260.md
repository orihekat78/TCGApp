## Expected

B04030 and B04030P resolve their action-end choice after the opposing character
leaves. A source-name eligible card can be selected; selecting its enter branch
consumes that deck entry and removes only the original source.

## Actual

The initial fix added the source name and deck source zone, but a full human
scene had no switch victim on the choice-to-`sceneEnter` bridge. Entry skipped
and the following `sceneRemove` still removed the original source.

## Evidence

- QA identities: `26ec92247fc4dcab111b11e369bcad77f0deafd06bf0be0904b6e0dc6fd32e48`,
  `fad7853757782721d17f1370836629352da55429c16b98e21d24597cd3d92889`,
  `fea86e813ffc71be74d68515b98d60749c639a2b001343462c0406961b3b900f`.
- Rules: `.claude/rules/07-action-flow.md`,
  `.claude/rules/15-abilities-effects.md`,
  `.claude/rules/22-qa-action-contact.md`.
- Regression: `tests/cards/official-qa/B04030.test.ts`.

## Fix

- Add `黒羽快斗` to the eligible card-name alternatives.
- Use `target.query.area:'deck'` for the enter branch on both printings.

## Horizontal investigation

`B04030P` was updated in lockstep. Existing `$matched.cardId` deck-enter cards
use `target.query.area:'deck'`; no additional copy of this defect was found.

## Prevention

For deck-look enter branches, test accepted enter, decline, zero candidates,
source-name eligibility, and source-zone consumption through the resolver.

## Full-scene correction

- The choice-to-`sceneEnter` bridge now carries the victim selected by the
  existing switch picker.
- `sceneRemove` runs only when `sceneEnter` binds a successful entry. A
  cancelled full-scene switch keeps both the original source and deck card.
- Human `deckRevealUntil chooseMatch:'upTo'` with zero matches retains the
  standard empty picker confirmation before deck-bottom handling.

## Full-scene UI blocker

- While B04030's selected enter option waits for a switch victim, its original
  choice overlay is suspended. The existing Playmat switch surface therefore
  receives victim and explicit-cancel clicks at desktop and `851x393`.
- The suspension is limited to B04030/B04030P's concrete enter option; generic
  nested `sceneEnter` choice metadata still resolves card choice before any
  switch prompt.
