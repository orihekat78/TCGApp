# BUG-355: exact case-feature identity was shortened

## Expected

- The case-condition icon is enabled only when the player's case has the exact
  `婚活パーティー` feature.
- The public card catalog exposes that same identity.

## Actual

- D11003, D11005, and D11021 used the private alias `婚活`.
- The paired alias made D11021 appear functional while rejecting an exact
  authority-shaped case and publishing shortened text.

## Root cause

An early card-analysis note inferred a shorter internal label. CardDefs, unit
tests, E2E, and generated catalog then copied that inference instead of the
official Q&A identity.

## Fix

- Use `婚活パーティー` in D11003, D11005, and both D11021 trait fields.
- Regenerate the public card catalog.
- Prove exact-feature acceptance and shortened/unrelated-feature rejection
  through public declared and character-entry dispatch paths.

## Horizontal investigation

- All shipped `婚活` references were inspected.
- Generic factory/condition tests may keep arbitrary fixture labels; every
  D11021-specific source and public expectation uses the exact identity.

- `tests/e2e/patterns/case-trait-conditioned.spec.ts`
