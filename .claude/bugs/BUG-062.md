## 期待動作

1. CPU が連続で move したとき、各 move を全て順次表示 (上書きされない)
2. CPU 側 (player='opp') の toast は赤系の border + 🤖 badge で強調
3. 表示時間は連続 CPU move でも視認可能な短さ (1500ms)
4. target が cardId なら cardName に解決

## 実動作 (修正前)

`src/ui/components/RecentActionToast.tsx` (41 行):
- `state.log` 末尾 1 件のみ 2.2 秒表示
- 新 log entry が来ると即時切替 → 連続 CPU move で前の表示が消える
- CPU/Human 区別は「相手」「自分」の text のみで視覚的差異なし
- target は cardId 直出し

## 修正 (案 1 採用)

### `src/ui/components/RecentActionToast.tsx`

queue ベース表示にリファクタ:
- `queueRef`: 新規 log entry を FIFO 末尾に enqueue
- `lastSeenLenRef`: log.length 追跡、新規分のみ slice して enqueue
- `visible` state: 現在表示中の entry
- `visible` 変化時の `useEffect` で 1500ms 後に queue から dequeue
- 空の queue でも `visible=null` で非表示
- log 短縮時 (新規ゲーム) は queue + lastSeen reset
- BUG-060 と同 pattern で target を `cardIdToDisplayName` で解決

CPU 強調表示:
- `data-player` attribute 付与 (E2E test 可能化)
- `is-opp` / `is-self` className
- CPU の場合 🤖 badge を toast 先頭に prepend

### `src/ui/components/RecentActionToast.css`

`.recent-action-toast.is-opp` セレクタ追加:
- border: 赤系 `rgba(255, 100, 100, 0.7)`
- box-shadow: 赤 glow
- background: 暗赤グラデーション
- `.toast-who`: 赤系 highlight
- `.toast-cpu-badge`: 🤖 emoji styling
