# Browser timer handler type confusion

## Expected

Browser timers accept only handler expressions proven callable by the source and
generated-bundle boundary audit.

## Actual

String, union, `any`, and imported `unknown` parameters could reach browser timer
calls. Function reassignment, spoofed bundle hooks, and timer `call`/`apply`/`bind`
wrappers also bypassed callable proof.

## RCA

The audit initially rejected only known strings, then trusted function declarations
after reassignment and any bundle `useCallback` owner. Timer wrapper calls were not
normalized to their real handler position.

## Fix

Require static callable proof across direct and wrapped timer calls. Reassignment
must remain callable, and bundle React hooks require trusted vendor provenance.

## Prevention

Focused regressions cover unsafe types, wrappers, reassignment, spoofed hooks, and
accepted direct, declared, bound, and genuine React callable forms.
