# Browser timer handler type confusion

## Expected

Browser timers accept only handler expressions proven callable by the source and
generated-bundle boundary audit.

## Actual

String, union, `any`, and imported `unknown` parameters could reach browser timer
calls without being classified as dynamic code execution.

## RCA

The audit rejected only handlers that resolved to a known static string. It did
not fail closed when the handler could not be proven callable.

## Fix

Require static callable proof for browser timer handlers, including function
bindings and genuine React `useCallback` results.

## Prevention

Focused regressions cover unsafe parameter types and accepted callable forms.
