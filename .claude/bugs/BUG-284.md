# Browser timer handler type confusion

## Expected

Browser timers accept only handler expressions proven callable by the source and
generated-bundle boundary audit.

## Actual

String, union, `any`, and imported `unknown` parameters could reach browser timer
calls. Timer aliases or nested wrappers, non-simple callable writes, and spoofed or
mutated React hook namespaces also bypassed callable proof.

## RCA

The audit did not fail closed when a timer reference appeared through an unnormalized
call shape. Callable writes and generated hook provenance also covered too few forms.

## Fix

Require static callable proof for normalized timer calls and reject other timer-derived
invocations. Track all callable writes and immutable, trusted hook provenance.

## Prevention

Focused regressions cover unsafe types, wrappers, reassignment, spoofed hooks, and
accepted direct, declared, bound, and genuine React callable forms.
