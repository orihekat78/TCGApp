## 概要

非MVP 全パッケージのカットインのみカード実装 (193 枚) のうち、**5 種 (distinct cardId)** は
既存 engine primitive では表現できないため `abilities:[]` の vanilla キャラ stub として生成し、
カットイン効果のみ未実装とした。カード自体は通常キャラとして登場・推理・アクション・ガード可能。

生成元: `scripts/gen-cards/gen-complex-cutins.cjs` の PLAN で `pattern:'deferred'`。

## 根本原因 (RCA)

1. **set-card 操作の verb 欠落** (0291/0296): `charSetCard` は書き換え、`charStackCard` は重ね。
   「デッキ上カードを裏向きでセット」「セット済カードを個別リムーブ」(rules/16) に対応する atom が無い。
2. **discard した札の属性を参照する dyn root 欠落** (0544/0893): `dyn/eval.ts` の root は
   `$self / $contact / $cost / $dyn` のみ。effect 内 `discard` の結果カードを束縛して level/ap を読む手段が無い
   (`$cost` は宣言能力コスト専用。カットインは triggered で cost を持たない)。
3. **複数カットイン択一の未対応** (0671): `listeners/triggered.ts` の `effect:declared` は
   payload.abilityId を見ず、card の triggered cutin ability を**全件**発火する。
   「2 つのカットインから 1 つを選んで使用」(rules/09) を半正確に実装すると両方発火する恐れ。
