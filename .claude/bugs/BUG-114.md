## 概要

非MVP 全パッケージのカットインのみカード実装 (193 枚) のうち、**5 種 (distinct cardId)** は
既存 engine primitive では表現できないため `abilities:[]` の vanilla キャラ stub として生成し、
カットイン効果のみ未実装とした。カード自体は通常キャラとして登場・推理・アクション・ガード可能。

生成元: `scripts/gen-cards/gen-complex-cutins.cjs` の PLAN で `pattern:'deferred'`。

## 該当カード (cardId / 代表 cardNum)

| cardId | cardNum | カード名 | engine gap |
|--------|---------|---------|-----------|
| 0291 | B03034 | 稲尾一久 | 相手デッキ上のカードを相手キャラに**裏向きセット**する verb 不在 (rules/16) |
| 0296 | B03039 | 長島茂雄 | キャラの**裏向きセットカードを個別選択リムーブ**する verb 不在 (rules/16) |
| 0544 | B05040 | ロバート・テイラー | リムーブした手札カードの**レベルで AP スケール**する dyn root 不在 |
| 0893 | B08055 (+B08055P) | 本堂瑛海 | リムーブした手札キャラの **AP で AP スケール**する dyn root 不在 |
| 0671 | B06050 (+B06050P) | 宮本武蔵 | **1 カードに複数カットイン (択一)** を engine が個別解決できない (effect:declared listener が全 cutin ability を発火) |

## 根本原因 (RCA)

1. **set-card 操作の verb 欠落** (0291/0296): `charSetCard` は書き換え、`charStackCard` は重ね。
   「デッキ上カードを裏向きでセット」「セット済カードを個別リムーブ」(rules/16) に対応する atom が無い。
2. **discard した札の属性を参照する dyn root 欠落** (0544/0893): `dyn/eval.ts` の root は
   `$self / $contact / $cost / $dyn` のみ。effect 内 `discard` の結果カードを束縛して level/ap を読む手段が無い
   (`$cost` は宣言能力コスト専用。カットインは triggered で cost を持たない)。
3. **複数カットイン択一の未対応** (0671): `listeners/triggered.ts` の `effect:declared` は
   payload.abilityId を見ず、card の triggered cutin ability を**全件**発火する。
   「2 つのカットインから 1 つを選んで使用」(rules/09) を半正確に実装すると両方発火する恐れ。

## 恒久対応案 (DEFERRED)

- 0291/0296: `sceneSetCardFromDeck` / `sceneRemoveSetCard` 相当の atom + mutate primitive を追加 (rules/16)。
- 0544/0893: effect 内 discard の被選択カードを `$dyn.<key>` に束縛する仕組み (pick → bind → dyn root) を追加。
- 0671: 1 カード複数カットインを「カットイン使用時に ability を 1 つ選ぶ」UI/解決経路に拡張
  (effect:declared に abilityId を載せ、listener が一致 ability のみ発火)。

いずれも骨格 (engine) 拡張を要するため、骨格凍結原則に従い MVP スコープ外として DEFERRED。
カード stub は将来の engine 拡張時に PLAN を `pattern` 切替 → 再生成で対応可能。

## 検証
- 5 種 stub は `abilities:[]` で validate 通過 (validateAll 0 invalid)。
- DEFERRED コメントを各カードファイル冒頭に明記 (silent partial 回避)。
