## RCA

The non-interactive toast container accepted pointer events, so it blocked controls beneath it during its timeout.

## Evidence

- `src/ui/components/RecentActionToast.tsx`
- `src/ui/components/RecentActionToast.css`
- `tests/e2e/user-bug-wave-ui.spec.ts`

## Verification

Landscape Playwright exercises the visible toast while clicking the underlying modal control; `e240931b` adds child-control pass-through coverage.

## Horizontal investigation

Checked HUD, opponent turn, refresh, tutorial, and effect-stack overlays; interactive children opt in while layout surfaces pass through.

## Prevention

Overlay layout wrappers use `pointer-events: none`; only named controls restore pointer input.
