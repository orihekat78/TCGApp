# B09063 blocked draw skips trigger use

## Expected

- 自分のレベル8キャラ登場で能力は発動する。
- 相手現場にレベル7キャラがいる場合は引かないが、【ターン1】は消費する。
- 同じターンに再び条件を満たしても再発動しない。

## Actual

- 相手レベル7不在条件を`ability.condition`で発動前に評価していた。
- レベル7がいるとqueueも使用回数記録も行われず、次の登場で再発動できた。

## Root cause and fix

- trigger条件と効果解決時の「場合」条件を同じ発動前gateに置いていた。
- `ability.condition`は自分ターンだけに限定した。
- 相手レベル7不在判定をeffect内の`conditional`へ移し、発動回数を先に記録する。

## Horizontal investigation and prevention

- pinned Q&A本文を横断検索し、この不成立時発動済み裁定はB09063固有と確認した。
- 同型の【ターン1】任意・0枚選択は既存queue時count経路で処理済み。
- self/opp ownerで阻止時の無draw、count 1、次回不発を公開経路試験化した。
