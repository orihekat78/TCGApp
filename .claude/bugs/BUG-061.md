## ユーザー指摘 (再掲)

> #12: 十五の受難を使用したときに登場するカードが？？？になっている。効果が
> 正常に行われていないし、**デッキの上からカードを順にめっくていく演出が
> 入っていない**。

BUG-052 で engine 側の `$matched.cardId/uid` bind ref 未解決 (?? 表示) は
修正済。本 BUG は **後者 UI 演出** 部分を実装する follow-up。

## 期待動作

`deckRevealUntil` atom 実行時、デッキ上から公開した順番でカードを順次
表示する overlay UI が出る。最終 matched カード (登場対象) は強調表示。

## 修正 (side-channel-pattern.md 4 点 checklist 準拠)

### 1. engine 側 side-channel

`src/engine/effect/atom-handlers.ts`:
- `PendingDeckRevealSide` 型 + globalThis `__pendingDeckRevealSide` declare
- `_drainPendingDeckRevealSide()` export
- `deckRevealUntil` handler 末尾で `revealed[]` + `matched` を set

### 2. UI 側 store

`src/ui/state/store.ts`:
- `pendingDeckReveal: PendingDeckReveal | null` field + setter

### 3. dispatch drain

`src/ui/hooks/useEngineDispatch.ts`:
- import `_drainPendingDeckRevealSide`
- post-dispatch で drain → `store.setPendingDeckReveal(...)`

### 4. UI overlay

`src/ui/components/DeckRevealOverlay.tsx` (新規):
- `pendingDeckReveal` subscribe
- `revealed.map` で各カードを `animation-delay: calc(var(--reveal-index) * 0.5s)`
  で順次フェード in
- `matched` 末尾を `is-matched` highlight (薄紫光彩 + 「登場!」バッジ)
- `revealed.length * 500ms + 800ms` 後に auto-dismiss (setTimeout)
- data-testid: `deck-reveal-overlay` / `deck-reveal-card-${idx}`

`DeckRevealOverlay.css`:
- z-index 9050 (ContactFlash 9000 と EffectPickerModal 9700 の間)
- pointer-events: none (操作を block しない)
- `@keyframes deck-reveal-flip`: translateY + rotateX で 0.5 秒

### 5. App mount

`src/App.tsx` で `<DeckRevealOverlay />` を import + 配置。
