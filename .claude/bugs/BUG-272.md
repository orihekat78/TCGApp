# 宣言能力の選択中に別行動を開始できる

## 再現

1. YOU-vs-CPU row 024 で「宣言能力」を押し、使用カードの選択状態にする。
2. 選択を完了せず「ネクストヒント」を押す。
3. 手札/FILE が変化した後、宣言能力の選択表示だけが残る。

## 期待 / 実際

- 期待: 未解決の使用カード選択中は、別アクションとターン終了を操作できない。
- 実際: 別アクションが picker の cancel と次の flow を競合させ、候補なしの選択状態になり終了不能になる。

## RCA

`Playmat` は effect 解決中だけ `interactionLocked` にしていた。`useTargetPicker` の
`picking` は未解決の人間選択なのに、ActionsPanel とハンドラの両方で操作可能だった。

## 修正

- picker が idle 以外なら ActionsPanel と終了ボタンをロックする。
- ハンドラにも同じガードを置き、プログラム経由の二重 flow を防ぐ。

## 横断調査 / 検証

- reasoning/action/assist/next-hint/declared-ability は共通 ActionsPanel 経路で同時に保護される。
- `Playmat.b10094-mixed-source` に picker 中の全8アクション・終了ボタンのロックを追加。
- `npx vitest run tests/ui/components/ActionsPanel.lock.test.tsx tests/ui/components/Playmat.b10094-mixed-source.test.tsx` : 2 files / 6 tests passed.
