## 仕様 (D11005 公式テキスト、rules/07)
「【宣言】【スリープ】相手のターン終了時まで、このキャラは『相手の現場のキャラがアクションするとき、
**このキャラを指定できる場合、必ず指定する**』を持つ」(挑発)。

## 実動作 (バグ、3点)
1. **G1 (dead-code)**: a2 は `args:{ ..., value:true }` だが handler (atom-handlers.ts:658) は `a.val` を読む
   → `mustBeTargeted=undefined` (apDelta=BUG-095 と同型の key 不一致)。挑発が完全 dead。
2. **G2 (scope 未配線)**: `scope:'opp-turn'` を handler が無視 + clearTurnEffects が mustBeTargeted を消さない
   → set できても永続化。
3. **G3 (enumerator 未対応・回帰で発覚)**: G1 修正で mustBeTargeted が live になると、targeting 強制
   (state-machine.ts:152-162) が throw するが、AI move enumerator (canActionAgainstChar) が mustBeTargeted を
   考慮せず違法手を出す → invariant-fail (smoke 29/100)。加えて「指定できる場合」= 強制対象は legal target
   (sleep/stun) の場合のみ、という nuance が未実装。

## 修正
- **G1**: D11005 a2 を `val:true` に修正 (handler の読む key に一致)。
- **G2**: `clearTurnEffects(s, uid, 'turn'|'opp-turn')` に拡張 ('opp-turn' で mustBeTargeted delete) +
  endTurn(p) で相手 (非p=設定者) scene の opp-turn 効果を清掃 (「相手のターン終了時まで」を正確に表現)。
- **G3**: `mustTargetCandidates` を legal `candidates()` と intersect (active な挑発キャラは強制対象外=
  「指定できる場合」nuance) + `canActionAgainstChar` に mustBeTargeted gate を追加 (enumerator/UI が
  違法手を出さない)。state-machine enforce と整合。

## 水平展開
charSetTurnEffect の `val` 規約は他に MVP 使用なし。mustBeTargeted / 'opp-turn' scope は D11005 のみ。
targeting 強制基盤 (G28) は target-expander.ts / state-machine.ts に実装済 (set さえ正しければ機能)。

## 検証
tsc / vitest **1671** (behavioral: val set / sleep強制・active非強制 / endTurn 解除) /
smoke 1000 例外0 (回帰 29/100 → 0、500/500) / 既存 target-expander test を「指定できる場合」semantics に更新。
