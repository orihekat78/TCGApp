## 期待動作

「【X】以外の色を持つキャラ」= **X以外の色を1つ以上持つ** (some説)。公式 B08079 ピンガ qa が確定:

> Q「事件が《裏切りの街角》(黒+他2色) の場合、【黒】以外の色を持つ条件で宣言できますか」
> A「はい。**【黒】を含む2色以上の事件でも条件を満たします**」

⇒ 2色{X,Y} カードは「【X】以外の色を持つ」を満たす (Y を持つため)。mono-X のみ除外。

## 実動作

B02010 (灰原哀, 出荷済) は a1「【青】以外の色を持つキャラを1枚まで選び AP+2000」を **custom closure** で実装:

```ts
filter: { custom: (_s, cand) => { const def = engine.cards.get(cand.cardId);
  return !!def && !def.colors.includes('青'); } }   // ← none説 (青を1つでも持てば除外)
```

`!colors.includes('青')` = **none説** → 2色{青,赤} カードを **誤除外** (公式 some説では該当すべき)。
著者 note も「青を含まないキャラに限定」と none説で解釈 (公式 Q&A 未参照と推測)。

## 影響範囲 / 顕在化条件

- **2色 (dual-color) のキャラを対象にする時のみ** 分岐 (単色対象では some説=none説 で結果一致)。
- 2色キャラは MR / 一部 dual-color のみ → 実戦頻度低 ⇒ severity 低。
- smoke (winsA=498) は色構成が単色中心のため未検出。

## 水平展開 audit (2026-06-27 実施)

shipped カードの「以外の色を持つ」実装を全数分類:
- **B02010**: custom closure `!colors.includes('青')` = **none説 (本 bug)**
- **B08090** (出荷済): `filter:{color:['青','赤','黄','緑','白']}` (complement-enum) = **some説 (公式正)**
- caseColor 系 (B08079/PR274/275/cutin 群): 事件条件、別 path (本 bug 非該当)
- ※ `!...colors.includes` を持つ B07016/B08020 は「【緑】イベント」positive check で「以外の色」非該当 (誤検出排除済)

⇒ 同一文言が出荷済で **3手法バラバラ・B02010 のみ公式違反**。

## 修正 (2026-06-27 実施)

B02010 a1 `filter:{custom: !colors.includes('青')}` → **`filter:{colorNot:'青'}`** に置換 (some説、公式準拠)。
不要 import (GameState/Candidate/engine) 除去。

- 回帰検証: card test `tests/cards/bug159-b02010-colornot-2026-06-27.test.ts` 4 pass
  (出荷 filter 値を matchOneFilter で評価: mono-青除外 / mono-赤該当 / **2色{青,赤}該当=fix の核心**)。
- gate: tsc0 / smoke winsA=498 不変 ex0 (2色対象は smoke デッキに非出現) / 8 lint + eslint 0。

**残**: B08090 の complement-enum (`color:[他5色]`、some説で正だが脆い) も colorNot へ統一推奨 (別途、振る舞い不変)。

## 防止策

- colorNot (公式準拠 some説 declarative 形) を「以外の色を持つ」の正準表現に。custom closure / complement-enum 禁止。
- card-addition-checklist に「色 NEGATION は colorNot を使う (custom closure の none説は公式違反)」追記候補。
