## 仕様
D11019 a1: デッキ上から黄 lv4 以下キャラを公開し、マッチしたら**それを登場させる** (デッキ→現場へ移動)。

## 実動作 (バグ)
a1 の sceneEnter step (D11019.ts:33) は args に source pick-query (target) を持たず、
atom-handlers sceneEnter:405-407 の sourceArea が undefined → deck-splice 分岐 (421-426) が走らない。
mutate.scene.enter は push のみ。$revealed (deckToBottomBound 対象) は matched を除外して構築されるため
matched はデッキに残る → **現場+デッキで複製** (デッキに同名コピーが増殖)。

## 修正
D11019.ts:33 の sceneEnter args に `target: { query: { area: 'deck', side: 'self' } }` を追加。
sourceArea='deck' になり既存 splice 分岐 (atom-handlers:421-426) が cardId をデッキから1枚除去。
cardId は '$matched.cardId' で resolveBindRef 済 (BUG-091 fix)、'$pick.cardId' でないため
awaiting-pick 分岐 (385) には入らず直接 splice→enter。engine 無改修 (カード DSL のみ)。

## 水平展開
deckRevealUntil→sceneEnter($matched) パターンは D11019 のみ。他 sceneEnter は target 指定済 or
remove/hand source。

tsc / vitest **1674** (behavioral: 登場後デッキに matched 無し + 総枚数保存) / smoke 1000 例外0 (500/500)。
