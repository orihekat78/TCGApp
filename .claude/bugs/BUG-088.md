## 仕様

replay (リプレイ再生) 中は記録済みの試合を再生するだけで、**live CPU を制御する SpectatorHUD は無意味**。
replay 中は ReplayPanel のみが上部に出るべき。

## 期待動作

replay 再生中、ReplayPanel の close (✕) ボタンが常にクリックでき、replay を閉じられる。

## 実動作

ReplayPanel の close ボタンが **SpectatorHUD に pointer events を intercept されてクリックできない**
(replay-ui.spec.ts:98 が timeout)。実ユーザーも replay を閉じられない。

## RCA

- commit `99f6c0c` (BUG-063) が SpectatorHUD のゲートを `if (!spectatorMode) return null` →
  `if (gameState === null) return null` に変更。replay は `setGameState(computeStateAt(...))` で
  gameState を set するため、**replay 中も HUD が常時表示**されるようになった。
- `.replay-panel` (fixed; top:12px; left:50%中央; **z-index:9100**; min-width:540px) と
  `.spectator-hud` (fixed; top:12px; right:12px; **z-index:9100 同値**) が同じ上端・同 z-index で重なる。
  BUG-058/063 で HUD が横に広がり、中央 ReplayPanel の右端 (close ボタン) と overlap。
- App.tsx / RealMatchView は `<ReplayPanel>` の **後に** `<SpectatorHUD>` を描画 → 同 z-index では
  DOM 後出が前面 → HUD が close を覆う。

## 修正

App.tsx (src) + RealMatchView (meta-app) で SpectatorHUD の描画を replay 状態で gate:
`{replayDriver.state.log === null && <SpectatorHUD />}`。
- SpectatorHUD 内で判定不可 (replayDriver は App ローカル hook で Zustand 非経由) のため**親側で gate**。
- BUG-063 の通常時挙動 (人間vsCPU で HUD 表示) は `log===null` で従来通り維持 → 回帰なし。

## 水平展開

- `<ReplayPanel>` + `<SpectatorHUD>` を兄弟描画する箇所 = `src/App.tsx:138-141` と
  `meta-app/src/screens/RealMatchView.tsx:127-130` の 2 箇所 → **両方修正**。
- z-index で replay-panel を上げる案 (Option 1) は両者とも「速度コントロール」を持つため二重表示が残り不採用。
