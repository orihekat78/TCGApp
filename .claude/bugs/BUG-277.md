# Pending runtime inherited-global isolation

## Expected

Snapshot, hydration, and marker operations use own global properties only.
Inherited getters, setters, or values must not execute or represent live state.

## Actual

Snapshot read a value even when the key was not own. Marker access used ordinary
property reads and writes. Inherited accessors could throw or suppress hydration.

## RCA

The access table checked ownership separately but its value getter and setter used
ordinary property syntax. Snapshot ignored the ownership result before reading.

## Fix

- Read own data descriptors only and skip absent values.
- Define own writable data properties to bypass inherited setters.
- Route marker reads and writes through the same validated facade.

## Horizontal investigation

All transactional pending keys share the facade, so the correction covers every
pending queue, side, continuation, binding, guard, and marker.

## Prevention

Adversarial tests install inherited throwing getters and a matching forged marker.
