# Qualified Reflect.apply timer invocation

## Expected

String timer handlers are rejected through `globalThis.Reflect.apply` and
equivalent computed access.

## Actual

Only the bare `Reflect` namespace was recognized, so qualified calls passed.

## Related files

- `scripts/private-hosted/audit-runtime-boundary.ts`
- `tests/release/private-hosted-runtime-boundary.test.ts`

## RCA and fix

Browser-property projection discarded intrinsic `Reflect` identity. Preserve
that sentinel and accept browser-qualified Reflect namespaces during invocation
resolution.

## Horizontal investigation and prevention

Source and bundle regressions cover direct, computed, aliased, destructured,
projected, call, and bind forms.
