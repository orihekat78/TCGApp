# BUG-177: 「〜のキャラに【カットイン】した/する場合」の参照方向が公式Q&Aと逆 (共通クラス水平展開 13 printings)

## 期待動作

「〚X〛のキャラに【カットイン】した/する場合」= **コンタクト中の自分のキャラ** (カットインで支援する側)
が X に一致するかで判定する。

一次根拠 = B02006 仮面ヤイバー 公式Q&A:
> Q: レベル5以下の特徴［少年探偵団］のキャラが相手のアクションで指定され、レベル5以下の特徴［少年探偵団］
> ではないキャラでガードしました。そのコンタクトでこのカードの【カットイン】を使い、AP＋3000できますか？
> A: いいえ。**コンタクト中の自分のキャラ**がレベル5以下の特徴［少年探偵団］の場合にAP＋3000できるので、
> この場合はAP＋1000します。

= ガード成立後のコンタクト参加者 (自分側=ガードキャラ) を見る。相手側キャラは無関係。

## 実動作 (修正前)

`cards/_shared/contactTargetMatches.ts` (custom closure) と D11013 inline custom が
`ctx.contact.targetUid` = **相手コンタクトキャラ** (buildContactBindings p-相対) を読んでいた。
→ 「相手が X のとき発火 / 自分のキャラが X でも不発」= 公式裁定と正反対。

影響カード (全て同構文、共通クラス経由 11 + inline 1 + spread 1):
B04025 / B04060 / B06041 / B06092 / B06101 / B07009 / B07050 / B08071 / B08086 / D10011 / PR087 /
**D11013** (inline) / **PR287** (D11013 spread)。うち D11013・D10011 は MVP デッキ = 実プレイ影響。

## RCA

- BUG-104 (2026-05-27) 時点で「targetUid = コンタクト相手」解釈で D11013 を実装、その後
  共通クラス化 (contactTargetMatches) で同解釈が 11 枚へ水平展開された。

  未実装 (hybrid DEFER) のため grounding で参照されなかった。

  (AP+ が $contact.byUid = 自キャラに乗る) と条件参照方向の不一致に気づく検査が無かった。
