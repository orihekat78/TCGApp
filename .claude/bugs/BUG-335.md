# effect-entry source omissions

## 期待動作

- B06047はYAIBA set時、removeのlevel 5以下YAIBAをsleepで登場。
- B08083は宣言costでsleepし、handのlevel 5以下・現場リムーブ時持ちを登場。
- B09007/Pは登場時に任意でself removeし、handのlevel 8以下ラムを登場。
- いずれのeffect entrantも通常のenter能力を発動する。

## 修正前

- B06047.a2は印字と無関係なdrawだった。
- B08083.a2とB09007/P.a1はDEFERコメントだけでCardDefに無かった。
- B06047.a1はcross-hand event auraをself hand-level減算として誤実装した。

## RCAと修正

- 旧deferred CardDefをprimitive出荷後に公式TSVへ再照合していなかった。
- 既存sceneEnter、keyword presence、optional chainだけで3能力を追加/修正。
- B09007/Pは旧a2 index 0を守り、新a1を末尾index 1へ追加。
- B06047.a1はcross-hand aura未対応。誤self減算を除去し、同じa1 slotを
  inert/deferredとして保持。a2 indexは不変。

## 回帰

- public event-set、case declared、normal hand-use/optionalを実行。
- typed valid/decoy候補、sleep/active entry、source removal、P parityを確認。
- entered fixture自身のenter-drawがsceneEnter後に1回解決する。
- B06047 turn1、裏向きset/non-YAIBA/opponent-turn negativeを確認。
- B08083は無効中の印字leave能力参照、満杯switch、wrong-color拒否、
  forged occurrence、候補0辞退を確認。
- B09007Pは実public declineと旧`a2` physical index 0を確認。
