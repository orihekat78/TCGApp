## ユーザー指摘

> #3: 相手ターン中のコンタクトの処理が行われない。コンタクトがないから
> カットインもできない。

## 期待動作

人間 vs CPU で opp が self キャラに actionAgainstChar したとき:
- GuardPickerModal が開いて self プレイヤーが guard 選択できる
- continue cutin/disguise の選択肢も適切に表示される
- OppTurnOverlay で「何が起きているか」がユーザーから見て明確

## 実動作 (調査結果)

Playwright headed + vitest で verify した結果、**driver / modal infrastructure
は完全に動作している** ことを確定:

- `useContactFlowDriver.ts:152` `defender==='self' && !spectatorMode` →
  GuardPickerModal open は正常
- `useContactFlowDriver.ts:200` `decider==='self' && !spectatorMode` →
  CutInDisguisePickerModal open も正常
- `useOppTurnDriver.ts:52-67` で opp action move → pause → contact 駆動委譲も
  正常

ただし以下の **UX gap** が判明:

1. `OppTurnOverlay` が generic「相手のターン処理中」「アクション解決中」のみで、
   attacker / target / phase が表示されない
2. 通常モード (人間 vs CPU) で「opp が self に攻撃して self が defender」の
   E2E test が **未整備** — BUG-045 (`9169af4`) は spectator mode 専用

ユーザーから見ると:
- AI が attack しても「アクション解決中…」表示で何が起きているか分からない
- BUG-044 (AI が attack しなかった、`5ffed7c`) 修正前は実際に attack せず、
  「contact が起きない」体感の主因だった

## RCA (Root Cause Analysis)

複合原因:
1. **BUG-044 (修正済)**: heuristic で AI が actionAgainstChar / Case を選ばず
   reasoning のみ → contact が発生しない体感
2. **BUG-045 (修正済)**: spectator mode で contact hang → 観戦試行が止まる
3. **本 BUG**: 上記が解決された後も、generic な overlay 表示と E2E test 不在
   で UX が「動いてるかどうか不明」

つまり #3 ユーザー報告は実質 3 つの層が重なっていた。BUG-044/045 で基盤が動く
ようになり、本 BUG で表示と回帰防止を整える。

## 修正

### Fix 1: OppTurnOverlay の specific status text (`cc3a605`)

- `activeActionId` が set されている時、`flow.action._getContext` で
  ActionContext を取得
- `readDef.card` で attacker / target の名前を解決
- `phaseLabel()` ヘルパで phase ごとの説明を生成
  ('ガード判定中' / 'コンタクト処理中' / 'コンタクト (1番目)' / 'AP 判定中' 等)
- 表示形式: `[attacker name] → [target name] ([phase label])`
- target.kind === 'case' は target = '事件'

### Fix 2: E2E spec `opp-turn-contact.spec.ts` (`98efb82`)

3 シナリオ:
1. opp → self キャラ actionAgainstChar → GuardPickerModal 表示確認
2. GuardPickerModal skip → CutInDisguisePickerModal が出れば pass、出なけれ
   ば auto-pass で action 完了
3. action[case]: OppTurnOverlay status に "事件" が表示される
