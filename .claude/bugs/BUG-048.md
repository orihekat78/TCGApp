## RCA (Root Cause Analysis)

ユーザー報告 #18 は umbrella (集約) 形式で、具体カード特定無しの「個別実装
が機能していない」表現だった。実体としては:

1. **BUG-040** (`d823f7f`): `declaredTargetCount` ハードコード → 宣言能力
   持ち全カードが UI で対象選択不可
2. **BUG-041** (`a96f900`): `canUse` switch fallback → scene 5 埋まり時に
   登場時効果カードが手札使用不可
3. **BUG-045** (`9169af4`): `deckRevealUntil` filter object / `discard`
   pick query → contact 中 effect カードで TypeError

これら 3 件で「個別実装が機能していない」と感じられる主要 path はカバー
されており、49 枚 audit で追加の動かないカードは検出されなかった。

## 修正

修正コードなし (audit のみ)。`AUDIT-USER-REQUEST-18.md` に分類表 + 検証ログ
+ 結論を記録。

## 水平展開

P4 (no-test) 13 枚は **絵柄違い variant** で他カードの def を spread 継承
する設計 (例: `D08004.ts` は `...D08003` + image 差替えのみ)。これらは元
カードのテストで自動カバーされる。

## 防止策

- 今後、umbrella 系のユーザー報告は「BUG pattern による分類 + 既知 BUG fix
  への突き合わせ」を最初に実施 (本 audit のフロー)
- 新規カード追加時は [card-addition-checklist.md] を通すことで「kind 分岐
  網羅 / hook listener 配線 / resolver dispatch」を確認 — これが Tier 1
  カードの保証になる
