# B02061 optional evidence transfer

## 期待動作

- B02061登場時は任意確認を行う。
- 承諾時だけ、相手デッキ上1枚を裏向きの証拠として移動する。
- その後、別の赤キャラを最大1枚選び、ターン中の突撃[事件]を与える。

## 修正前

- a1はouter optionalを持たない`chain`だった。
- `evidenceGain`へ`max:1`を渡したが、handlerは`n`だけを読む。
- public経路は任意確認を出さず、証拠0枚のまま後段選択へ進んだ。

## RCAと修正

- 初期CardDefがpick atom用の`max`を非pick atomへ誤適用していた。
- B01065/B01069と同じ`optional(sequence(...))`へ変更した。
- `evidenceGain`は`n:1`とし、任意性をouter optionalへ移した。

## 回帰と水平確認

- RED: B02061 public entry後の`pendingEffectOptional`が存在しなかった。
- GREEN: self/opp accept/decline、hidden evidence、後段keyword、save、CPU、
  exact-one deck-out、Hiramekiをcard-boundで確認した。
- shipped CardDefの`evidenceGain` 39箇所を走査し、修正後は全件`n`を持つ。
