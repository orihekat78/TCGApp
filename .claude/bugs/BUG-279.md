# Browser navigation sink detection

## Expected

The production graph rejects every runtime navigation surface, including global
navigation, anchors, forms, JSX props, DOM attributes, and reflected writes.

## Actual

Global navigation and several DOM/JSX forms produced no finding. Dynamic props,
attributes, and reflected writes could navigate outside the protected application.

## RCA

The scanner omitted global navigation names and modeled only direct properties.
It did not identify navigation elements or fail closed on dynamic DOM mutations.

## Fix

- Classify `open` and `location` as network-capable browser properties.
- Detect anchor/form props, JSX spreads, element factories, attributes, clicks,
  reflected writes, and bulk/dynamic mutation of known navigation elements.

## Horizontal investigation

Source and generated-bundle paths were checked independently. Official card image
loading remains allowed by design and constrained by CSP.

## Prevention

Focused regressions cover direct, spread, factory, reflected, namespaced, bulk,
dynamic-key, source, and generated-bundle forms.
