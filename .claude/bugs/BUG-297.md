# Projected React default aliases

## Expected

Aliases of an interop namespace's `.default` projection retain namespace
identity through declarations, destructuring, array projection, and assignment.

## Actual

Only direct `.default` mutation mapped back to the owning namespace. Local and
destructured aliases were absent from the namespace alias graph.

## Related files

- `scripts/private-hosted/audit-runtime-boundary.ts`
- `tests/release/private-hosted-runtime-boundary.test.ts`

## RCA and fix

Callable-source collection recorded identifier declarations only. Project static
default and array sources through binding and assignment patterns.

## Horizontal investigation and prevention

Regressions cover direct, local, destructured, array-projected, assignment, and
opaque-call mutation paths across sibling interop namespaces.
