# B03102 reasoning reaction timing

## Expected

- レベル4以下の自分の警察キャラが推理を宣言してスリープした直後に発動する。
- 発動はMisreadの選択と証拠獲得より前。
- LP0でも発動し、再アクティブ化後の2回目にも再発動する。

## Actual

- B03102だけが`reasoning:end`を購読していた。
- Misread待機中はAP+1000が未適用だった。
- 公式Q&Aが要求する発動窓より後、証拠獲得後まで遅延した。

## Root cause and fix

- 初期reasoning-hook実装時の旧hookがカード定義に残っていた。
- 既存の`reasoning:after-sleep`へ置換し、エンジン変更なしで正しい窓へ移した。
- 公開dispatchでsleep済み、Misread未解決、証拠0の同一stateを直接固定した。

## Horizontal investigation

- `reasoning:after-sleep`の出荷consumer 10件と`reasoning:end`のカードconsumerを全件検索した。
- B03040の証拠獲得observerはpost-evidence用途で`reasoning:end`が必要。
- B01017/B01074/B05011/B05039/B08034は個別grounding前のため一括変更せず、残QAで裁定する。

## Prevention

- 「推理したとき」はsleep直後とpost-evidenceを別の公開stateで検証する。
- Misread候補と証拠枚数を同時にassertし、遅延hookをfalse-greenにしない。
