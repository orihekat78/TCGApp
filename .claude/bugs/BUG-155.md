## 発見契機

B06100 wave の敵対 faithfulness verify (7 reps + 2 filter-lens) で、候補に含まれた **PR241 (メアリー)**
が `verdict='mismatch' (MAJOR, high confidence)` と判定された。PR241 は `{...PR235}` spread 再利用で
実 DSL は `PR235.ts` にある。

## 期待動作

公式テキスト「【登場時】手札から【赤】の〚特徴［赤井家］〛の**キャラ**を1枚リムーブしてもよい。そうした場合、カードを2枚引く。」
は、リムーブ対象を **キャラに限定** (種別明示)。よって discard filter は `kind:'character'` を含むべき。

## 実動作 (修正前)

`PR235.ts` a1 の discard filter は `{ color:'赤', trait:'赤井家' }` のみで `kind:'character'` を欠く。
engine の `matchOneFilter` (BUG-118 修正済) は `filter.kind` を実 enforce するため、本来書くべき種別制約が
DSL に写されていない **under-constrained** 状態。color=赤 AND trait=赤井家 を満たせば理論上キャラ以外
(イベント) も候補化し得る。

- **実害は latent**: 現行カードプールに 赤×〚赤井家〛のイベントは 0 件 (grep 確認)。誤対象は発生しない。
- ただし公式テキストの「キャラ」という filter 条件が DSL に反映されていない **条件欠落** (faithfulness gap)。

## 関連ファイル

- `src/cards/pr-01/PR235.ts` (a1 discard filter に kind:'character' 欠落 — 修正本体)
- `src/cards/pr-01/PR241.ts` (`{...PR235}` spread のため PR235 修正で連動)

## 修正方針 (未着手)

PR235.ts a1 step1 の filter に `kind:'character'` を追加 (engine変更0、PR241 は spread で連動)。

## ⚠ 水平展開 (完全 sweep が必要 — 未実施)

同型の「種別明示なのに kind 欠落」は **PR235/PR241 に限らない可能性が高い**。heuristic grep
(単一行 filter 前提) では B02068 / B05083 等が候補に挙がるが、codegen 出力の **複数行 filter object**
を取りこぼすため grep は信頼できない。**正確な棚卸には AST/パーサベースの sweep が必須**:

- 全カードファイルの `discard` / `sceneRemove` / `sceneToHand` / `handAddFromX` 等 pick系 atom の filter を parse
- 各 filter に `trait` or `color` があり `kind` 不在のものを抽出
- そのカードの公式テキストが「キャラ」(or「イベント」) と種別明示しているか突合
- 明示あり ∧ kind 欠落 = 本 BUG の同型インスタンス

→ B06100 wave commit には含めず、**専用 sweep を別途起票** (速度<精度: 部分 grep 修正で「完了」偽装しない)。

## 防止策

- card-addition-checklist §7 に「テキストが種別 (キャラ/イベント) を明示する pick filter は kind:'character'|'event' を必須化」を追記検討
- codegen 側で「テキストに『キャラ』を含むのに filter.kind 不在」を warn する lint 追加検討 (enforcement)

## 備考 (B06100 wave 本体は問題なし)

本 wave で新規出荷した **B06100/B06100P (ベルモット)** は公式テキストが「【カットイン】を持つ【黒】の**カード**」
= 種別非限定のため、filter に kind を入れない方が正しい (敵対 verify で faithful 確認済)。本 BUG は
候補列挙中に派生発見した **既出荷カードの pre-existing gap** であり、B06100 の faithfulness とは独立。
