# BUG-181: resolve-picks pre-walk の owner-relative 化漏れ (PB 短縮形)

## 期待動作
opp 所有カードの `handAddFromRemove{player:'self',...}` 等 PB 短縮形 pick は、
owner 相対で opp 自身の remove/hand を候補列挙する (a1 の PA 短縮形は正しく相対解決される)。

## 実動作
resolve-picks.ts:310 pre-walk が `const p = (args.player as Player) ?? 'self'` を
**絶対 side** で解決 (resolvePlayer 未経由)。opp 所有 B05087 a2 が **相手 (self) の
リムーブエリア** を候補列挙し、自分の remove の長野県警を回収できない。
production AI 経路 (drainAiEffectPicks) でも同様。

## 再現
tests/cards/m1-megasweep/B05087.manual.test.ts S8 (現状挙動を lock する documentation test。
engine 修正時に落ちて正 assert へ反転させる)。

## RCA
pre-walk の player 解決だけ owner-relative 規約 (resolvePlayer) を経由していない。
runtime atom-handler 側 (PA 短縮形) は resolvePlayer 済で非対称。

## 修正案
resolve-picks.ts:310 を `resolvePlayer(args.player, ctx)` に。
