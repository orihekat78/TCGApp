# 複数パートナー能力の選択が盤面で停止する

## Expected

複数の使用可能なパートナー能力は、能力説明を含む公開選択UIで選べ、取消できる。
盤面だけの対象選択は Escape で取消でき、HOMEへ遷移しない。

## Actual

`runPartnerAbilityFlow` は能力ID (`a1`/`a2`) を盤面用 `TargetPicker` に渡していた。
盤面には能力IDに対応するクリック面がないため、pickerが永久に残った。
また、現場だけのsource pickerには公開取消経路がなかった。

## RCA and fix

- 複数能力は既存 `ChoicePickerModal` に統一し、能力説明を選択肢として表示する。
- `Playmat` は非idleの `TargetPicker` 中に Escape を `cancelTarget()` へ接続する。
- 現場直接クリックの任意 `pendingEffectPick` は `TargetPicker` を経由しないため、
  Escape を可視の「選ばない」と同じ `effectPickResolve(null)` へ接続する。
  必須選択と `forcedUids` がある選択には接続しない。
- BUG-272 のACTIONS再入防止、BUG-273 の対象ゼロsource除外と組み合わせ、無入力停止を防ぐ。
