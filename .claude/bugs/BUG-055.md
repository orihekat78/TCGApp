## ユーザー指摘

> #7: カットインの有無画面で一番目と記載していますが、カード名を入れて
> わかるようにしてほしい

## 期待動作

`CutInDisguisePickerModal` のサブヘッダで「1番目」「2番目」のみだったところを
「1番目 (江戸川コナン)」のように **actor のカード名を併記** する。

## 修正

### `src/ui/hooks/useContactModalStore.ts`

`CutInDisguisePickerOpen` に optional `actorName: string` 追加。

### `src/ui/hooks/useContactFlowDriver.ts`

`runOneStep` の `action-1/2/redo` case で `_setCutInDisguise` 呼出時に
`actorUid` (firstUid / secondUid) を `readApLp` で名前解決して `actorName`
を渡す。

```ts
const actorUid = ax.phase === 'action-2' ? ax.secondUid : ax.firstUid;
const actorName = actorUid ? readApLp(state, actorUid).name : undefined;
```

### `src/ui/components/CutInDisguisePickerModal.tsx`

props に `actorName?: string` 追加。`actorLabel` と結合した `actorDisplay` を
sub-header に表示:

```tsx
const actorDisplay = actorName ? `${actorLabel} (${actorName})` : actorLabel;
<p className="cid-sub" data-testid="cid-actor-label">
  {`${actorDisplay}: カットイン / 変装 を選択`}
</p>
```

### `src/ui/components/Playmat.tsx`

`PlaymatCutInDisguisePickerModal` wrapper で `actorName={current.actorName}` 配線。

## 検証

- vitest UI 379 PASS / 1 skipped (regression なし)

- backwards compat: actorName が undefined なら従来通り actorLabel のみ表示

## 防止策

- modal の text 部分は data-testid 付与済 (回帰防止 E2E test 追加し易い)
- 「N 番目」表記は ActionContext.phase 派生だが、user-facing には素性
  (カード名 / 色 等) を併記する pattern を default 化
