  (デッキ下移動) を続行。AI は従来 path (先頭 match 自動取得 = 合法手内固定戦略) — smoke baseline
  完全一致 (469/531, 10.86) を確認
- **付与**: 公式文「1枚まで」の 38枚 (TSV 全文分類) + B08020/P a1。forced 10枚は公式 Q&A

## GAP-2: effect:declared 反応の解決順序 → 修正済

- **設計裁定** (敵対レビュー rules lens): emit 後置は rules/15 §発動済 (離場でも無効化されない)
  と衝突 → 発動検出/limit/entry 構築は宣言時のまま、**(a) batch gate + (b) pick 解決時確定**のみ変更
- **(a)**: emit 毎の declaredBatch + 非 own (selfOnly 以外) に declaredReaction。stack.next() は
  「同 batch own pending / own 由来の未解決 pick・choice・optional channel / own 由来 follow-up entry」
  の間、反応を選択不可 (pairwise gate — ownerChosenOrder の所有者任意順 rules/15 §未解決 は不変)
- **(b)**: declaredReaction は raw queue し stack.runOne() で遅延 substitute (resolver は
  listener 層から注入 — stack コアに AI 依存なし)。候補がイベント解決後盤面で確定
- **victim**: B07016 (177枚中 selfOnly 無し唯一) + 再採用 B08020 a2
