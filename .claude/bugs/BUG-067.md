## 発見契機

2026-05-23 全 BUG audit (audit agent 4) で発見。BUG-051 「事件カードの能力 発動不可」の 残課題セクションに以下が記述されていたが、follow-up BUG が起票されていなかった:

> 事件カード declared ability の `limit: { kind: 'turn', n: 1 }` 制約が `incrDeclaredUseCount` (scene 限定) で enforce されない。case には `declaredUseCount` field がない。turn 上限管理の case 対応は別 BUG で扱う

## 期待動作

事件カードの【宣言】能力 (例: `caseDeclaredEvidenceFlip`) に `limit: { kind: 'turn', n: 1 }` が指定された場合、1 ターン中に 1 回しか起動できない (rules/17 【ターン①】)。

## 実動作

- `src/engine/types/game-state.ts:40` で `declaredUseCount` は `SceneCharacter` 型にのみ存在、`Case` 型には不在
- 結果: 事件カードの declared ability の `limit: { kind: 'turn', n: 1 }` は enforcement されず、1 ターン中に何度も起動可能
- rules/17 違反: 【ターン①】アイコンが事件カード上で機能しない

## 関連ファイル

- `src/engine/types/game-state.ts:40` (Case 型に `declaredUseCount` 追加が必要)
- `src/engine/flow/declared-ability.ts` (incrDeclaredUseCount 呼び出し、case 分岐追加が必要)
- `src/cards/_shared/caseDeclaredEvidenceFlip.ts` (該当する shared class)
- `src/engine/mutate/case.ts` (case state mutation、turn 開始時 reset 追加が必要)

## 想定修正

1. `Case` 型に `declaredUseCount: Record<string, number>` 追加
2. `incrDeclaredUseCount` を case にも対応 (cardLocation で分岐)
3. ターン開始時の reset (`resetTurnFlags` あたり) で case の `declaredUseCount` もクリア
4. test 追加: case declared ability の turn limit が enforce されることを assert
