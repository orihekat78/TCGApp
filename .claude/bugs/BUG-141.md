## 概要

「アクション[キャラ/事件]したとき」(action:declare hook) で発火する trigger 効果は、公式裁定で
**ガード判定より前に発動・解決される** (rules/22 R1)。一次根拠 = B08048 qAndA「ガードされた場合でも、
アクションで指定したキャラがレベル－1されています」/ B01036 qAndA「(対象指定後の) スリープ時点で発動」。
ブレット付与 (B01068/B02068) は当該アクションをガード不能にするため (rules/13)、宣言→ガード窓の間に
解決が完了している必要がある。

現行 engine には 2 つの逸脱があった:
1. **CPU 経路** (`src/ai/action-resolution.ts`): `resolveActionAgainstChar/Case` は declare 直後に drain せず、
   `chooseGuard` の **後** に `runAllUntilEmpty` していた。B01036 (ガード候補をスリープで奪う) が CPU 戦で逆順。
2. **human 経路** (`src/ui/hooks/useContactFlowDriver.ts`): 進行 gate が `pendingEffectPick` のみを見ており、
   `pendingEffectOptional` / `pendingEffectChoice` modal の解決を待たずに guard-window へ進んでいた
   (B02068 granted optional「手札1リムーブ→ブレット」が反映されない)。

## 影響範囲

- 出荷済 action:declare trigger 19 ファイルのうち、ガード判定に影響する効果 (AP/状態変更) を持つもの。
  smoke デッキ内該当 = D08021 (selfOnly draw/evidenceGain — ガード非依存) / D11015 (AP+1000 pick)。
  X14 適用後も smoke baseline は byte 一致 (現 smoke デッキでは順序差が結果を変えない = 回帰証跡)。
- 実戦では B01036/B08048/B02068 等の宣言時効果がガード判定/コンタクト AP 判定に反映されなかった。

## 期待動作 / 実動作

- 期待: declare → (宣言時 trigger 発火 + 効果解決) → ガード判定 → コンタクト
- 実動作 (修正前): declare → ガード判定 → (効果解決) → コンタクト (CPU) / optional modal を待たず guard 進行 (human)

## 修正

- X14: `action-resolution.ts` に `drainDeclareTriggers` (runAllUntilEmpty + drainAiEffectPicks + runAllUntilEmpty)
  を declare 直後・chooseGuard 前に挿入 (char/case 両経路)。
- X16: `useContactFlowDriver.ts` の pause gate に `pendingEffectOptional` / `pendingEffectChoice` を追加
  (D11007 a3 fix と同型)。
- pin: tests/engine/effect/wave2-cluster3-action-triggers.test.ts §X14 (chooseGuard 時点で draw 解決済)。

## 水平展開

- case アクション自体の guard 窓が `passGuard` 固定で、アクション[事件] もガード可能 (rules/07-08) という
  既存ギャップは別 → **BUG-144 起票** (cluster3 範囲外、declare-drain のみ本 commit で実施)。
- contact:start / reasoning:end など他 hook の pick gate は既に pendingEffectPick 待ち済 (D11007 a3)。
  optional/choice の追加は本 commit で全 hook 横断的に効く。

## 防止策

- 「ガード判定前に解決」を要する宣言時 trigger は CPU/human 双方で drain ポイントを declare 直後に置く。
- contact driver の進行 gate は pick/optional/choice の 3 side-channel すべてを待つ (BUG-141 教訓)。
