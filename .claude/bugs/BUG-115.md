## 概要

cards-data の `features`(特徴) 列と `color` 列は弾により区切り文字が **`|`(pipe) と `,`(comma) で混在** する
(features: pipe 585 行 / comma 118 行 / 両方 4 行、color: 多色 48 行で comma と区切り無し連結が混在)。

generator (`gen-simple-cards.cjs` / `gen-complex-cutins.cjs`) の `traitsArr` は `split('|')` のみ、
colors は `[rec.color]` で 1 要素化していたため、comma 区切りパッケージ (ct-d01〜05 / ct-p01〜09 / pr-01 の一部) の
カードで `traits: ['探偵,高校生,赤井家']` のように **comma 込み 1 要素に潰れて破損**していた。

## 影響 (高)

traits は engine が **完全一致 includes** で照合する load-bearing データ:
- `cond/eval.ts` 【絆】/特徴フィルタ (`traits.includes(trait)`)
- `dyn/eval.ts` `$self.sceneTrait.<trait>` (特徴スケーリングカットイン D08007 型)
- `target/candidates.ts` / `atom-handlers.ts` 特徴ターゲティング

破損カードは `['探偵','高校生','赤井家']` の各特徴クエリに**一切ヒットしなくなる** (silent fail)。
tsc / validateAll / smoke は全て通過するため検知できなかった (CardDef としては valid)。

### 検出方法
敵対的検証ワークフロー (rule-translation verification) の simple cut-in audit dimension が
公式 TSV と生成 DSL を全 157 枚突合し発見。9 件 confirmed (B01019/B01073/B01056/D05010/D05008/D05013/D04006/D03008 等)、
実際の blast radius は comma パッケージ全体 + その絵柄違い spread。

## 修正

両 generator を修正 (2026-06-04):
- `traitsArr`: `split('|')` → `split(/[|,]/)` (pipe / comma 両対応)。
- colors: `[rec.color]` → 色文字抽出 `[...new Set(color.match(/[青赤黄緑白黒]/g))]`
  (comma 区切り `緑,白` も 区切り無し連結 `青緑` も正しく分割)。

再生成後: traits 正常 (`['探偵','高校生','赤井家']`)、spread 継承先 (D10018/D10019 等) も base 修正で連動回復。
tsc clean / validateAll 0 invalid / 全テスト 1713 pass / smoke 0 例外 baseline 不変。

## 水平展開 / 残課題

- engine 正準ローダ `src/engine/cards/tsv-loader.ts` の `parseTraits` も `split('|')` のみ
  (現状 MVP=CT-D08/D11 は pipe 区切りのため実害なし)。将来 comma パッケージを TSV ローダ経由で
  読む場合に再発するため、同様に `/[|,]/` 化が望ましい (本 BUG では generator のみ修正、ローダは別管理)。
- 恒久対応: cards-data の features/color 列を pipe に正規化する regen スクリプト (`_regen_all.cjs`) 修正も検討。

## 教訓
- 量産 generator は「データの区切り文字がパッケージ間で不統一」を前提に防御的にパースする。
- tsc/validate/smoke を通っても **trait/color の意味的破損は検知できない** → 敵対的検証 (公式テキスト突合) が有効。
