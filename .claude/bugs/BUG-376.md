# Granted hand Cut-In filter omission

## Expected

- B07003などの手札auraでCut-Inを得たカードは、B07100の
  「Cut-Inを持つカード」候補に含まれる。
- 条件不成立の印字Cut-Inも、公式Q&Aどおり所持判定には含まれる。

## Actual

- contact使用可否は`effectiveCutinAbilities`で手札auraを認識した。
- `TargetFilter.keyword`はoff-scene CardDefへfallbackし、付与Cut-Inを見なかった。

## Root cause and fix

- 手札Cut-Inの有効集合と汎用keyword候補列挙が別readerだった。
- off-scene handのCut-In判定を`effectiveCutinAbilities`へ統一した。
- CardDef、GameState、pending schemaは変更していない。

## Horizontal investigation and prevention

- handCutinAura consumerはB06020とB07003。contact経路とfilter経路を共有した。
- recursion guardを維持し、hand以外の外部付与を誤って認識しない。

- `tests/cards/official-qa/B07100-B08003-completion-public-wave174.test.ts`
- `tests/cards/s3-hand-cutin-aura.test.ts`
