## 期待動作

B03104「自分のリムーブエリアにカードが15枚以上」は使用中の自身を数えない。
他 15 枚で成立、他 14 枚で不成立。D11019 の色計数も同様。

## 実動作

event を効果解決前に remove へ移すため、他 14 枚 + 自身 = 15 で誤成立する。

## RCA

event lifecycle の先行 remove 移動。初回修正 `46d7b73d` は source の
`CardDef.kind === 'event'` のみで解決中と推測。カットインと無関係な event source まで計数から -1 する過修正となった。

## 修正方針

- `EffectCtx.source.resolutionKind` で実際の解決種別を明示。
- `normal-event` / `hirameki` の解決中枚 1 枚だけ count/color から除外。
- `cutin` と marker 無し event source は数える。
- human choice/pick/optional 再開後にも marker を保持。

## 水平調査

- `removeCountAtLeast` / `removeColorAtLeast` の共通 remove reader。
- B03104 / D11019 の境界値。
- source writer、event normalization、stack serialization、human decision resume。
- 第三者 reaction は declaration source の lifecycle marker を継承しない。

## 再発防止

- 四種 provenance × count/color の境界 probe を共通回帰にする。
- カード種別からライフサイクルを推測しない。
