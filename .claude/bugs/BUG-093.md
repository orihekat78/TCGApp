## 仕様 (rules/06, 17, 11)

「同ターン内に登場したキャラは名乗り状態で推理・アクション不可」。
**能力/効果による登場でも「登場」**であり、同ターン登場 = 名乗り状態になる (rules/17 §【登場時】)。
名乗り例外は 迅速 / 突撃 / 突撃[キャラ] / 突撃[事件] / 疾風 のみ (rules/13)。

## 期待動作

`sceneEnter` (効果登場) / `sceneSwitch` (スイッチ登場) で登場したキャラは名乗り状態 (isNamed=true)。
突撃等を持たない限り、その登場ターンは推理・アクション不可。

## 実動作

**効果登場キャラが名乗りにならない** (isNamed=false)。
- D11019 a1 で登場した黄キャラが、リムーブ黄20枚 (突撃[事件] 付与条件) 未達でも action[事件] できた
  (= 名乗り制限を受けていない)。

## RCA

- `atom-handlers.ts` の `sceneEnter` / `sceneSwitch` は `named: (a.named ?? false)` を
  `mutate.scene.enter/switchEnter` に渡していた (既定 **false** = 名乗りでない)。
- 通常登場 (`handUseCard`) は `named: true` を渡しており、効果登場だけが非名乗りになっていた。
- 影響: D11019 / D08024 (リムーブから登場) / D11014 (疾風) — いずれも `named` 未指定で効果登場が非名乗り。

## 修正

- `atom-handlers.ts` sceneEnter / sceneSwitch の既定を `named: (a.named ?? true)` に変更。
  効果/能力による登場も「同ターン登場 = 名乗り」とする (明示 `named:false` を渡せば非名乗りも可)。

## 水平展開

- sceneEnter / sceneSwitch を使う全カード (D11019 / D08024 / D11014) が効果登場で名乗りになる。
- BUG-092 (突撃 grant の読取) と組合せで D11019 が正しく動作:
  黄<20 → 名乗りのまま action[事件] 不可 / 黄>=20 → 突撃[事件] で action[事件] 可。
