# Wave107 cut-in declared-name authority

## Expected

- B09052/Pはカットイン時に登録済みカード名を1つ指定できる。
- 複数名カードの完全名指定は、その完全名を持つカードだけを数える。
- humanとAIは同じdomainを使い、cancelは手札とcontactを変えない。

## Actual

- カットインの`ContactChoice`に宣言名がなく、`declareName`は常に空文字で解決した。
- B09112/Pもlegacy `unrestricted` domainのままで、旧saveの証拠コストdyn形状が移行対象外だった。
- B09052/PとB09112/Pの既存QA証拠は、別能力または構造だけを検証していた。

## Root cause and fix

- `ContactChoice.cutin`に`declaredName`を追加し、active cut-inのdomainでdispatch前検証する。
- humanは既存`DeclareCardNameModal`、AIは公開現場の登録名を決定的に供給する。
- own cut-in entryのみに宣言名dynを渡し、第三者反応には泄らさない。
- B09112/Pは`registered-card-name`へ移行。旧saveは支払済み証拠2枚と完全一致する
  `flipFaceUpEvidence.indices`形状だけ許可する。
