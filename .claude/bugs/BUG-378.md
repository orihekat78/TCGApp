# B08022 handAddFromRemove owner omission

## Expected

- B08022が手札からマロちゃんをリムーブした場合、そのカードを回収候補にできる。
- 中間のAP8000以下リムーブを辞退しても、マロちゃん回収は続行する。

## Actual

- `handAddFromRemove`の明示targetに`player`が無かった。
- 中間pick辞退後のcontinuationでhandlerがownerを解決できず、`engine-error`になった。

## Root cause and fix

- CardDefがtarget queryの`side:'self'`だけでzone ownerも推論されると誤認していた。
- handler契約どおり`player:'self'`を追加した。engineやschemaは変更していない。

## Horizontal investigation and prevention

- 明示target付き`handAddFromRemove`で`player`を欠くconsumerを全CardDef走査した。
- 該当はB08022のみ。両owner、直前discard、scene removal辞退を公開dispatchで固定した。
