## 期待動作

事件編/解決編タグを「事件エリア」と「証拠エリア」の間に隙間ゼロで配置。

## 実動作

Round 3a で edition タグを左カラムに独立配置 (`8161efb`) したが、`.left-col` の grid gap が残存し隙間が見える。

## 関連ファイル

- [src/ui/components/Playmat.css](../../src/ui/components/Playmat.css) (L186-215)

## RCA

`.left-col { grid-template-rows: 1.4fr auto 1fr; gap: 6px; }` の `gap: 6px` + 子要素の padding が重なって隙間発生。

## 水平展開

left-col 縦方向余白を持つ他要素 (CaseArea / EvidenceArea の padding) も同様の影響。

## 防止策

grid gap=0 + 子 padding 調整 + edition tag を marign-collapse 利用で隙間なくする。
