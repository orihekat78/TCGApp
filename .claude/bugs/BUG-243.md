## RCA

Internal occurrence identity was kept in keys and callbacks but was never converted into a public, assistive-technology label.

## Evidence

- `src/ui/components/SelectableCardTile.tsx`
- `src/ui/components/CardListModal.tsx`
- `tests/ui/components/SelectableCardTile.test.tsx`
- `tests/e2e/card-choice-details-real-flow.spec.ts`

## Verification

Focused duplicate-name tests and real-flow browser coverage verify unique selection/detail labels without exposing instance IDs; `2bbae5c6` and `a75ffaae` strengthen the regression cases.

## Horizontal investigation

Hand discard, guard, reorder/place, replacement, Souza, CardList, and revealed evidence detail can render public duplicate cards and use the same ordinal rule.

## Prevention

Add a public ordinal only for duplicate rendered card IDs; pass it to selection and detail names, never derive it from an internal instance ID.
