# BUG-184: B05045 cutin observer selfOnly 欠落

## 期待動作
【カットイン】AP+2000 の on-hand `effect:declared` observer は自分自身のカットイン宣言でのみ発火
(shipped majority idiom = `trigger:{hook:'effect:declared', optional:true, selfOnly:true}`、BUG-032 系)。

## 実動作
B05045 (+ spread B05045P) のみ selfOnly 無し — 他カードの effect:declared でも trigger 候補になる。

## 検出経路 (新規)
手動レビューではなく **compiler G1 回帰 gate** が検出: mined 文法 (majority = selfOnly 有り) が
B05045 の shipped DSL を再現できず mismatch。「文法と実装の発散 = 意図的アラーム」設計が機能した初事例。

## 修正
B05045.ts a3 trigger に selfOnly:true 追加 (B05045P は spread 継承)。

## 水平展開
同 G1 実行で同時検出・同 commit 是正: B02047 icon-disguise の未使用 scope / B02076+P/PR133 の
冗長 filter{kind:character} (意味不変の正規化) / B05056 a2 partial 実装の完成。

発散したら CI red — 例外は exceptions.json (mine.cjs 生成) 経由のみ。
