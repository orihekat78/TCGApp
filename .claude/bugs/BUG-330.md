# main actionのturn/phase admission欠落

## 期待動作

手札使用、ネクストヒント、宣言、推理、アクション、partner actionは、
そのplayerのmain phaseだけ開始できる。end phaseでactiveになっても、次の
自分main phaseまでは推理・アクションできない。

## 実動作（修正前）

`canReason`、`_canAction`、`handUseGateCommon`、`canStartNextHint`、
`canPartnerAbility`はactor/playerの状態・個別条件だけを検査し、turn ownerと
phaseを見なかった。
相手main phaseでも前ターン側の公開actionが成功し、stateを変更した。

## RCAと修正

- main action flowごとにadmissionが分散し、宣言能力だけが
  `turn.player`と`phase === main`を検査していた。
- `isMainActionWindow`を単一正本として追加。
- reasoning、action、hand use、next hint、declared、partner abilityへ同じgateを適用。
- UI/AI列挙と直接engine callerは既存`can*`経由で同時に修正される。

## 回帰と水平展開

- Wave46の12 end-turnカードを実`endTurn`と公開decisionで解決。
- 相手turn中はreasoning/actionを拒否し、次self mainでは両方を許可。
- hand use/next hint/partner abilityも相手turnで拒否。
- end-phase optional未解決中の全main action拒否を確認。
- 既存reasoning/action/hand-use/next-hint/partner unit fixtureへmain前提を明示。
