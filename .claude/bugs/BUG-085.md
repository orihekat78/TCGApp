## 仕様 (rules/21, 17, 19, 01)

事件カード D08026/D11021 の【解決編】【宣言】【ターン①】〚裏向きの証拠を1つ以上表向きにする〛:
少年探偵団キャラを AP±1000/枚 (表向きにした枚数ぶん)。D08005 も同コスト (n:1)。コストは使用者が選ぶ。

## 実動作 (修正前) — 2 層のバグ

- **Layer 1 (UI cost picker 欠落)**: `cost.pay` の flipFaceUpEvidence は
  `ctx.dyn.costParams.flipFaceUpEvidence.indices` を要求するが、runDeclaredAbilityFlow が証拠を
  選ばせず空 indices で dispatch → `pay()` が throw → produce 全体 rollback → 「OK 後に何も起きない」。
- **Layer 2 (dyn count 未配線・過去一度も動作せず)**: 効果 delta `{ dyn:'cost.flipFaceUpEvidence.count*1000' }`
  が評価されない (evalDyn は dead code / `$` 接頭辞欠落 / costPaid が effect ctx に未引き継ぎ) → AP が NaN 化。

## 修正内容

1. caseDeclaredEvidenceFlip.ts — descriptor を `$cost.flipFaceUpEvidence.count*<delta>` ($ 接頭辞)。
2. resolve-picks.ts — `resolveDynArgs`: pick 解決時 (human-pick 境界の前) に `{dyn}` arg を evalDyn で
   literal 化。pending push / Pattern A・B 戻り の 3 箇所に適用 (dyn 無し args は同一参照 = 他カード影響ゼロ)。
3. declared-ability.ts — `useDeclaredAbility` が渡された ctx の costPaid/dyn を resolveCtx に引き継ぐ。
4. useEngineDispatch.ts / policy.ts — cost.pay 済み ctx を useDeclaredAbility に渡す (UI/AI 双方)。
5. useEvidenceFlipPicker.ts (新規 Promise picker store) + useActionsPanelFlow.ts (`findFlipFaceUpCost` +
   確認 OK 後に証拠 picker を await → 選択 index を ctx.dyn.costParams に積んで dispatch)。
6. CardListModal.tsx (裏向きセル multi-select + nMax=Infinity banner) + Playmat.tsx
   (PlaymatEvidenceFlipPickerModal: 証拠エリア拡大表示を pick mode で流用)。
7. read/char.ts — `declaredUseCount` を optional chaining 化 (BUG-084 の case 列挙が declaredUseCount
   未定義 fixture で throw する防御)。+ 該当 fixture (setupMidGame) を型整合修正。
8. (追加報告) CardListModal が証拠を常に「非公開」バック描画していた → `faceUpEvidence` prop 追加で
   表向き証拠を公開カード (CardArt+名) 表示。Playmat の証拠 viewer / flip picker 双方に配線
   (faceDownCount=全枚数で絶対 index 整合を維持、表向き cell のみ公開化)。表向き証拠は公開情報
   (D08005 a1 等が参照) のため隠してはならない。

## RCA

- Layer1: cost UI 化 (Phase 8.8c) で sleep/discard は整備したが flipFaceUpEvidence の選択 UI が未実装のまま。
- Layer2: Effect DSL の `{dyn}` 評価系 (evalDyn) が実装されたが配線されず、唯一の利用カードが
  end-to-end テストを持たなかったため silent NaN を長期検知できず。

## 水平展開

- flipFaceUpEvidence 利用は D08026/D11021 (case)・D08005 (char) のみ。全て runDeclaredAbilityFlow 経由。
- `{dyn}` arg 利用は caseDeclaredEvidenceFlip のみ (grep)。resolveDynArgs の影響範囲限定。
- 既存単一 onPick の evidence pick (evidenceToHand 等) は nMax=1 で従来挙動維持。
- case literal で declaredUseCount を欠く fixture が複数 (defensive read で一括防御)。
