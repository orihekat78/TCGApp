## 概要

CPU ターン中、`playTurn` の per-move `drainAiEffectPicks` が `__pendingEffectPickQueue` を
**所有者無関係に** heuristic で解決していた。CPU の効果で human の【相手ターン中】【現場リムーブ時】
持ちキャラがリムーブされる等で human 所有の triggered pick が queue に積まれると、human の選択なしに
CPU の heuristic が確定 (横取り)。rules/15 (未解決効果は所有者が解決) / rules/05 (効果解決中は次の
行動に移れない) 違反。dispatch 経由 (アクション由来) は useEffectPickFlowDriver が正規 routing 済で、
playTurn drain 経路のみの gap。

## 影響範囲

human vs CPU で、相手ターン中に発火する human 所有 triggered pick/optional/choice を持つ出荷済カード
(D05007/D01012 等の【相手ターン中】【現場リムーブ時】族)。CPU vs CPU (smoke) と観戦モードは
`__humanPlayerSide=null` のため影響なし — baseline 不変。

## 修正 (X8)

1. `drainAiEffectPicks`: `__humanPlayerSide` 所有の pending を skip (queue に温存)。null なら従来挙動 byte-equal
2. `hasPendingHumanPick()`: pick queue + optional/choice side-channel の human 所有分を検知
3. `playTurn`: move 選択前に human 未解決 decision があれば `paused:{humanPick:true}` で停止
4. `useOppTurnDriver`: humanPick pause で `surfacePendingSideChannels()` → modal 解決後の re-fire で再開。
   surfaced modal open 中は entry guard で再入禁止
5. テスト代行用に `_drainAllEffectPicksForTest` を新設 (旧挙動が必要な human modal 代行テスト 3 箇所を移行)
