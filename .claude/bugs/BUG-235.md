## Expected behavior

Every public card choice shows artwork and opens its card detail without changing the pending decision identity.

## RCA

Choice hosts rendered text-only rows and duplicated selection markup, so visual detail and occurrence identity had no shared contract.

## Evidence

- `src/ui/components/SelectableCardTile.tsx`
- `src/ui/components/DeckReorderModalHost.tsx`
- `tests/ui/components/SelectableCardTile.test.tsx`
- `tests/e2e/card-choice-details-real-flow.spec.ts`

## Verification

Focused tile and real-flow desktop/mobile tests cover public, hidden, and duplicate cards; follow-up commits `6a6f284f`, `99fed261`, and `a75ffaae` extended host coverage.

## Horizontal investigation

Checked reorder/place, intercept, replacement, guard, CardList, and effect pickers; all use the shared tile or the matching detail contract.

## Prevention

New card-choice UI must use the shared tile, keep callback identity separate from display identity, and test detail-close then exact pending resolution.
