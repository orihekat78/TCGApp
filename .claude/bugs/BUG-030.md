## 修正 (Round 4g、commit 待ち)

`src/engine/read/char.ts` の `keywords()` 関数を拡張:
- scene 上の char の cardDef.abilities を走査
- `type === 'continuous'` + `continuousModifier.grantKeywords` を持つ ability で
- `evalCond(state, ability.condition, ctx)` が true なら grantKeywords を結果に追加
- `disabledOriginal: true` の場合は continuous も無効 (rules/19 §元の能力)

unit tests 5 件追加 (tests/engine/read/char.test.ts):
- continuous + condition true → grant 反映
- continuous + condition false → grant 無し
- disabledOriginal → continuous も無効
- partnerColor 条件 (positive / negative)

E2E spec 拡張 (tests/e2e/patterns/partner-color-keyword.spec.ts):
- 既存 3-layer (abilityExists / conditionMet / grantedKeywords) に
- 4-layer 目: `expectCharHasKeyword` / `expectCharNotHasKeyword` を追加

smoke baseline 微シフト: 524/476 → **525/475** (avg turns 10.35 → 9.85)。
AI が 突撃 / 迅速 を最適活用するようになった positive 変化。0 例外 / 0 timeout 維持。

## 期待動作

`read.char.keywords(state, uid)` が char に effective に付与されている全 keyword を返す。これには:
- cardDef.keywords (static)
- char.keywordOverrides.granted (明示 grant)
- **continuousModifier.grantKeywords を持つ scene 上の active abilities** (例: `partnerColorKeyword`)

を含むべき (rules/13-keywords.md, rules/17-icons.md, rules/24-qa-naming-stun.md §常時有効型)。

## 実動作

[src/engine/read/char.ts:61-74](../../src/engine/read/char.ts) `keywords()` は `cardDef.keywords + granted` のみ。`abilities` から continuousModifier 評価は **未実装** (L70 コメント: `// Phase 5 で abilities から展開`)。

結果: D08009 / D08022 / D11007 / D11009 / D11011 が scene に居て partner 色が一致しても、`hasKeyword(state, uid, '突撃' / '迅速' / '突撃[キャラ]')` は **false**。

## 影響範囲

- **AI policy**: 突撃 / 迅速 持ちキャラの「名乗りターン中 action / 推理」判定が effective には機能していない可能性 (smoke 524-476 baseline は維持なので致命的ではないが、最適性は損なわれる)
- **UI**: 名乗り中アクション可否の表示で keyword 反映なし
- **rules/17 §名乗り例外 (迅速 / 突撃 / 疾風)** が正しく実装されない

## 修正方針 (別 Round で実装予定)

1. `read.char.keywords` を拡張: scene 上の全 char の cardDef.abilities を走査
2. 各 ability の `type === 'continuous'` かつ `continuousModifier.grantKeywords` を持つもの
3. `cond.eval(state, ability.condition, { source: { player, uid } })` で condition 評価
4. true なら grantKeywords を返り値に追加 (Set で重複除去)
5. smoke 1000 戦で baseline (524/476) shift があれば AI の挙動変化として承認
