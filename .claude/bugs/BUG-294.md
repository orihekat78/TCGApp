# Duplicate vendor import identity

## Expected

Any exposure of the pinned vendor export revokes React trust, regardless of the
local import name or import form.

## Actual

Exposure was tracked by local binding. A duplicate named import or namespace
import could mutate the same cached export while another binding stayed trusted.

## Related files

- `scripts/private-hosted/audit-runtime-boundary.ts`
- `tests/release/private-hosted-runtime-boundary.test.ts`

## RCA and fix

Local bindings were treated as vendor identities. Track the canonical module and
export pair across duplicate named imports and namespace projections.

## Horizontal investigation and prevention

Regressions cover split duplicate imports, namespace imports, aliases, direct
exposure, and exact unexposed interop acceptance.
