# Direct invoked Hirameki evidence movement

## Expected

- B06023が別カードのヒラメキ効果を発動した場合、効果全体を解決する。
- 自己登場は選ばれた正確な証拠occurrenceを現場へ移す。
- 証拠から現場への直接移動は`evidence:removed`を発火しない。

## Actual

- `sceneEnter`はaction-heldヒラメキだけを証拠sourceとして認識した。
- B06025の対象除去後、証拠sourceを消費できず登場しなかった。
- 初期修正は直接移動でもremove observerを誤発火した。

## Root cause and fix

- B06023の`$occurrence` authorityを`sceneEnter`が読んでいなかった。
- invoked payload、source、owner、index、UID、epoch witnessを再検証するclaimを追加。
- exact occurrenceだけを証拠からspliceし、evidence→scene causal moveを記録する。
- remove areaを経由しないため`evidence:removed`はemitしない。
