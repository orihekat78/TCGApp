## 発見契機

2026-05-23 全 BUG audit (audit agent 4) で発見。BUG-060 「ログに cardId のみ表示」の 補足セクションに以下が記述されていたが、follow-up BUG が起票されていなかった:

> target が SceneCharacter uid (e.g., `self-1`) の場合は cardId pattern にマッチしないため素通しになり、後続改善で uid → cardId → name 解決を検討可能

## 期待動作

LogPanel に表示されるログで、SceneCharacter uid (`self-1`, `opp-2` 等) が出現する場合、それを uid → cardId → カード名 の順で解決して表示する (例: `self-1` → `江戸川コナン`)。

## 実動作

`src/ui/components/LogPanel.tsx:20-25` の `formatTarget` は cardId pattern (`/D\d{2}\d{3}/`) のみ resolve、scene uid (`self-N` / `opp-N`) は素通し。

例: 「self-1 がアクション宣言」のようなログが mid-game で頻発し、誰が何をしたか分かりづらい。

## 関連ファイル

- `src/ui/components/LogPanel.tsx:20-25` (formatTarget、cardId 限定)
- `src/ui/services/uidNames.ts` (既存の uid → カード名 resolution helper、これを使えば実装可能)

## 想定修正

1. `formatTarget` に uid pattern (`/^(self|opp)-\d+$/`) の分岐を追加
2. uidNames.ts の `uidToDisplayName` を call して cardId/name を解決
3. fallback として現状の uid 表示は維持 (resolution 失敗時)
4. test 追加: LogPanel snapshot test に uid 含むケース追加
