# Atomic qualification report publication

## Expected

The final report is either absent or complete after interruption or write failure.

## Actual

The report was written directly to its final path. An interrupted write could
leave a partial file that appeared to be final evidence.

## RCA

Exclusive creation prevented overwrite but did not make publication atomic.

## Fix

Write and sync an exclusive same-directory temporary file, publish it with an
exclusive atomic hard link, then remove the temporary name in `finally`.

## Prevention

Injected write and publish failures prove no final report and no temporary file
remain after failure.
