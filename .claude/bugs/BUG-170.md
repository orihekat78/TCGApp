# BUG-170: turn-end 履歴 flag の清掃境界 race

## 期待動作
- B08014「ターン終了時、このターン中にこのキャラが自分のMRの能力によって選ばれていなかった場合、手札に移す」
  — MR に選ばれていたら現場に残る。
- B09070 a3「自分のターン終了時、このターン中に【疾風】を発動していたすべてのキャラをアクティブにする」
  — 疾風発動キャラがアクティブ化される。

## 実動作 (修正前)
`flow/turn.ts endTurn` は phase:end:start を emit (turn-end trigger を pendingEffects へ **queue**) した後、
同一呼出内で `clearTurnEffects('turn')` を同期実行し `selectedByOwnMr` / `shippuFiredCharThisTurn` を削除。
queue された効果の conditional / forEach 列挙は **caller の runAllUntilEmpty (= 清掃の後)** で解決される
(rules/25 「〜の場合」は解決時参照) ため、flag は常に消えた後に読まれる:
- B08014 = 「選ばれていなかった」が常に成立 → MR に選ばれていても必ず手札へ戻る (印字と矛盾)
- B09070 a3 = forEach 候補が常に 0 → 無発動 (印字と矛盾)

mutate/char.ts の旧コメント「評価は本清掃より前に走る (turn.ts: trigger queue → clearTurnEffects の順)」は
**queue 時点と解決時点の混同**による誤り。W6a step6/step4 の engine probe は evalCond / forEach を
単体で検証しており endTurn 通し経路を踏んでいなかった — first-consumer card probe (endTurn e2e) が検出。

## 修正
「このターン中に〜した」系 per-char 履歴 flag の清掃を **次 startTurn 境界** へ移動
(endTurn 後〜次 startTurn 間の未解決効果は当該ターンの一部として flag を読める):
- `src/engine/flow/turn.ts startTurn`: 両 side scene の `selectedByOwnMr` / `shippuFiredCharThisTurn` を delete
- `src/engine/mutate/char.ts clearTurnEffects('turn')`: 両 key の delete を撤去 (警告コメント収録)
- pin 更新: tests/cards/engine-mega-w6.test.ts (step4/step6 の清掃 pin を新境界へ)
- e2e pin: tests/cards/step12-batch1.test.ts B08014 (tag→残留 / 未tag→手札) + B09070 (疾風→turn-end activate)

## 水平展開
clearTurnEffects('turn') の delete list を全数監査 (2026-07-04):
- `actedCharThisTurn` — turn-end 読者なし (B08049 は sceneHas 即時読み)。現状維持、同型 consumer 出荷時に要再訪。
- `wasGuardedThisTurn` / `cannotReason` / `nameOverride` / `grantedKeywords` / `revokedKeywords` /
  ap/lp/lvlMod — 「ターン終了時まで」効果 = turn-end で切れるのが正 (rules/05 ②効果切れ)。移動しない。
- `noAutoActivateBySourceUid` — 既に非対称清掃 (list 外、W6 step5)。
- 区別基準: **「〜まで」持続効果 = endTurn 清掃が正** / **「このターン中に〜した」履歴 flag = startTurn 清掃が正**。
  新 key 追加時はこの基準で清掃先を選ぶ (LESSONS-LEARNED 追記)。

## 防止策
- turn-end queue から読まれる flag の probe は evalCond 単体でなく **endTurn→runAllUntilEmpty e2e** で書く
- first-consumer card 出荷時の第2gate 再certify (今回検出経路) を維持
