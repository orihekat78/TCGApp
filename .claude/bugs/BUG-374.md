# B07043 semantic choice labels

## Expected

- B07043の所有者は黒羽盗一・黒羽快斗・怪盗キッドを区別して指定できる。
- triggeredとdeclaredの両choice UIが同じ意味ラベルを表示する。

## Actual

- nested sequence optionはverbを持たず、UIが「効果 1/2/3」と表示した。
- 名前を識別できないため、正しい検索分岐を意図して選べなかった。

## Root cause and fix

- `Effect.choice`にsemantic labelの運搬契約が無かった。
- JSON-safeなoptional `labels`を追加し、resolver、pre-walk、declared flowへ伝播。
- B07043は3つの印字名を明示する。labels不在の既存fallbackは維持する。

## Horizontal investigation and prevention

- runtime pendingとdeclared pre-dispatchの両consumerを検証した。
- desktop/mobileで3名称表示と黒羽快斗分岐を実クリックした。
- malformed label配列はeffect validationで拒否する。
