# Indirect React namespace mutation

## Expected

React hook provenance is revoked when an alias, projection, or opaque callable
can replace the trusted namespace's `useCallback` export.

## Actual

Revocation recognized only a fixed set of direct `Object` and `Reflect` calls.

## Related files

- `scripts/private-hosted/audit-runtime-boundary.ts`
- `tests/release/private-hosted-runtime-boundary.test.ts`

## RCA and fix

Mutation analysis depended on callee spelling. Treat namespace arguments to
unclassified callables as opaque mutation and add direct `Reflect.defineProperty`.

## Horizontal investigation and prevention

The mutation matrix covers direct, aliased, destructured, projected, computed,
bulk, prototype, and opaque-call paths.
