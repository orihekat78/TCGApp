## ユーザー指摘

> 場に出すと 1 ドロー実行はされましたが、手札 +1、ログにドロー記録はされませんでした

(2026-05-23 9:31 検証、BUG-071 commit `37ffb3a` 適用後)

## 期待動作

D08015 a1 (`sequence([draw, choice([discard])])`) 発動時、ログに以下が時系列で記録される:

1. `効果: ドロー` (step 1)
2. `効果: 手札選択待ち` または同等 (step 2 で human pick 待ち)
3. `効果: 手札リムーブ` (modal で選択後)

これによりユーザーが「何が起きたか」を log で追跡できる。

## 実動作

- step 1 (draw) は機能 (手札 +1) するが、**ログに記録なし**
- step 2 (discard) は `discard:skip-unresolved-pick` という英語 identifier のみ表示、ユーザーには「何を待っているのか」不明
- modal で選択 → discard 実行されるが、それも **ログに記録なし**

ログには「手札の使用」(D08015 を出した) のみ表示、a1 の動作が不可視。

## RCA

- `src/engine/effect/atom-handlers.ts:129-133` の `draw` atom は `mutate.deck.draw` のみ呼び出し、log 追加なし
- `src/engine/effect/atom-handlers.ts:148-149` の `discard` atom success path も log 追加なし
- 例外として `discard:skip-unresolved-pick` (atom-handlers.ts:141-145) は BUG-045 で導入された skip log のみ
- LogPanel.tsx の `ACTION_LABEL` mapping にも effect 系 action 名 (`effect:draw` 等) が無いため、追加しても日本語化されない

設計上、auto-phase / NH の draw は別経路で log されない方針 (頻度が高くノイズ) だが、**effect (ability の能動的な動作) は log すべき** だった。

## 関連ファイル

- `src/engine/effect/atom-handlers.ts:129-133` (draw atom、log 追加対象)
- `src/engine/effect/atom-handlers.ts:134-151` (discard atom、success + skip 両 path に log 追加)
- `src/ui/components/LogPanel.tsx:43-70` (ACTION_LABEL mapping、追加対象)

## 修正

1. atom-handlers.ts の `draw` atom に `mutate.log.append` 追加 (action: `effect:draw`)
2. atom-handlers.ts の `discard` atom success path に log 追加 (action: `effect:discard`)
3. atom-handlers.ts の `discard` skip path の action 名を `discard:skip-unresolved-pick` → `effect:discard:awaiting-pick` に変更 (ユーザー向け意味のある名前)
4. LogPanel.tsx の `ACTION_LABEL` に 3 件追加:
   - `effect:draw` → `効果: ドロー`
   - `effect:discard` → `効果: 手札リムーブ`
   - `effect:discard:awaiting-pick` → `効果: 手札選択待ち`
