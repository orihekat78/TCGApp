## Expected

B03032/B03032P may declare an action against an opponent active character when that character has a card set on it. The targeted character itself cannot guard that action; another legal active character may guard.

## Actual

The ordinary action target candidate reader excludes every active opponent character. B03032 only implements its partner-gated Charge and enter-time face-down set effect, so its printed target exception cannot be declared.

## RCA

The declarative action-target reader had no set-card predicate. B03032/B03032P were partially shipped with the exception deferred in `DEFERRED-INDEX.md`.

## Horizontal investigation

Search of the deferred index identifies B03032 as the registered active-target exception. Ordinary active-target rejection remains correct for all other cards.

`expandActionTargets` callers without `hasSetCards` retain their prior state/level-only behavior.

## Prevention

Add a declarative action-target exception with set-state predicate, then test target selection, self-guard rejection, alternate guard acceptance, no-set rejection, and print parity.
