# BUG-216: カード表示カタログの欠落

## 期待値

登録済みカードIDは、手札・現場・詳細表示で公式の名前、種類、レベル、AP/LP、カード画像を表示する。使用可否判定と表示値は同じCardDefに基づく。

## 実際値

`TEST-無制限0627`の実戦手札で`D07019`、`D07014`、`D07023`、`D07004`、`PR164`が、全て`??? / キャラ / Lv0 / AP— / LP0`として表示された。一方タイトルの使用可否は実レベル4/5/8を用いており、`data-card-id`も正しい。プレイヤーはカード本文・ステータスを確認できない。

`PR164`（黒の「犯人」）も同じ fallback に入り、実カード色と無関係に青枠（`color-blue`）で表示された。色条件の選択枠ではないため、黒カードを青対象であるかのように誤認させる。

横展開として、`黒赤デッキ`対`少年探偵団・標準`でも `B09092P`、`B09095`、`B09110P`、`B06099`、`B09102` がすべて `??? / Lv0 / AP— / LP0 / color-blue` になった。ツールチップだけは実レベル8/7/9/8/3を判定している。D07・PR164固有ではなく、カスタムデッキのUIカード解決経路全体の不具合である。

`黒赤デッキ`対`警察・標準`では、カスタムパートナー `B03107P` も `??? / 青 / LP0` で表示され、アクション元候補に出るがクリックしても選択状態が進まず、睡眠中の相手キャラへの対象選択候補も生成されない。表示だけでなく、誤った操作候補を出して行動を停止させる。

## 追加の画面証跡（2026-07-16）

ユーザー操作中、黒カードであるにもかかわらずカード枠が青で表示された。`??? / Lv0 / AP— / LP0 / color-blue` の fallback 表示と同じ再現群であり、色だけの CSS 不具合ではない。CardDef 解決失敗時に既定の青色へ落ちるため、色条件・盤面判断・ログ読解を誤らせる。

期待値: 黒カードは黒の枠・色アイコン・カード種別情報で表示する。

実際値: 黒カードが青枠で表示される。

## RCA

ゲームエンジンの実カードIDと、Meta UIのカード表示用カタログまたは画像/属性解決の登録範囲が分離している。存在しない表示CardDefへfallbackしている可能性が高い。
