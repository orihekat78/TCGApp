# Declared callable timer overwrite

## Expected

A timer alias definitely overwritten with a local function declaration is not
reported as dynamic code execution.

## Actual

Function expressions carried local-callable identity, but declarations did not.
Invocation resolution fell back to stale timer provenance.

## Related files

- `scripts/private-hosted/audit-runtime-boundary.ts`
- `tests/release/private-hosted-runtime-boundary.test.ts`

## RCA and fix

Flow entry did not seed hoisted function declarations. Seed each statement list
with exact local-callable values before evaluating assignments.

## Horizontal investigation and prevention

Regressions cover arrow, function-expression, declaration, shadowed timer, and
opaque non-timer Reflect invocation paths.
