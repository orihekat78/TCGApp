## 仕様 (D11007 公式テキスト、rules/07-08)

D11007 萩原研二 a3「【自分ターン中】【ターン1】**このキャラより** AP の高いキャラとコンタクトしたとき、
手札を1枚リムーブしてもよい。そうした場合、**このキャラ**を AP+3000」。
= D11007 自身が高AP相手とコンタクトしたときのみ。

## 期待動作

D11007 が攻撃者として自分より高AP のキャラとコンタクトしたときのみ a3 が発火。

## 実動作 (バグ)

[cond/eval.ts contactOpponentApHigher](../../src/engine/cond/eval.ts) は contact:start payload の
`aUid` (攻撃者) / `bUid` (防御側) の AP だけを見て `bAp > aAp` を返し、**D11007 自身がその
コンタクトの当事者かを確認していなかった**。`contact:start` は全コンタクトで emit され、listener は
全カードを走査するため、**D11007 が関与しない任意のコンタクト** (defender>attacker) でも a3 が発火。
→ 任意の (任意発動の) discard + 非当事者 D11007 に無意味な AP+3000。

## RCA

BUG-097 (D11016) と同じクラス: matcherCondition が `ctx.source.uid` (ability 所有者) を見ず、
payload の当事者と照合していなかった。`matcherCondition` 経路は ctxMc.source.uid=card.uid を
持つため照合可能だが、contactOpponentApHigher がそれを使っていなかった。

## 修正

[cond/eval.ts contactOpponentApHigher](../../src/engine/cond/eval.ts) に
`if (payload.aUid !== ctx.source.uid) return false;` を追加。自分が攻撃者 (aUid) のコンタクトのみ評価。
【自分ターン中】= 自分が攻撃するので攻撃者限定で十分 (user 裁定)。D11007 a3 のみが本 condition を使用。

## 水平展開

- contactOpponentApHigher を使うのは D11007 a3 のみ。
- 他の matcherCondition (guardedBySelf=BUG-097修正済 / enterOrderEquals / boundMatchesFilter) の
  自己照合は OK (guardedBySelf は ctx.source.uid 照合、enterOrderEquals は selfOnly/scope で絞られる
  enter hook、boundMatchesFilter は binding 経由で当該カード文脈)。

## 防止策

behavioral test ([triggered-limit-guard.test.ts](../../tests/engine/listeners/triggered-limit-guard.test.ts)):
自分が攻撃者→発火 / 別キャラが攻撃者→不発火。unit ([eval.test.ts](../../tests/engine/cond/eval.test.ts)):
aUid !== source.uid → false。
