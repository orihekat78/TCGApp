3. step 3 `discard` (pick) — 手札 1 枚リムーブ → log: `効果: 手札リムーブ`

## RCA

`src/engine/effect/atom-handlers.ts:L232 / L247` の不整合:

```typescript
case 'evidenceToHand': {
  const p = a.player as Player;
  const target = a.target as string;  // ← string 期待
  const list = s.players[p].evidence;
  const idx = list.findIndex(e => e.cardId === target);  // ← string 比較
  ...
}
case 'handAddFromRemove': {
  const p = a.player as Player;
  const target = a.target as string;  // ← 同じく string 期待
  ...
}
```

[BUG-065](BUG-065.md) で `resolve-picks.ts:substituteAtomPick` は pattern B の解決時 **常に target を array** (`[pickValue]`) で構築する設計に変更:

```typescript
return {
  kind: 'atom',
  verb: atom.verb as never,
  args: { ...args, target: [pickValue] },  // ← array
};
```

これは `discard` atom (L159 で `a.target as string[]`) と互換だが、`evidenceToHand` / `handAddFromRemove` の **string 期待** と非互換。runtime で:

- `a.target = ['D08015']` (array)
- `target = a.target as string` → TypeScript 上 string、実体は array
- `list.findIndex(e => e.cardId === target)` → `e.cardId === ['D08015']` は常に false → idx = -1
- moved = false → 何もしない、log なし

これは BUG-066 で私が立てた「3 点 verify」protocol を BUG-065 で守らなかった結果。array 化の影響を 1 atom 単位で verify せず、`discard` のみ確認して「全部動く」と断言していた。BUG-073 でも実機 verify せず「engine 修正の自動恩恵」と楽観視。

## 修正方針

`atom-handlers.ts` に `normalizeTargetToString` ヘルパーを追加し、`evidenceToHand` / `handAddFromRemove` の両 atom で:

- `a.target` が `string` → そのまま使用
- `a.target` が `string[]` (BUG-065 経由) → `target[0]` を使用
- それ以外 (pick query object、undefined) → awaiting-pick として silent skip + log
  - `effect:evidenceToHand:awaiting-pick` / `effect:handAddFromRemove:awaiting-pick`
  - LogPanel ACTION_LABEL に対応する日本語 mapping 追加

これにより BUG-065 の array 化と互換になり、人間 pick 待ち時の skip も log で可視化される。
