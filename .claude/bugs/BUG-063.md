## ユーザー指摘

BUG-059 spec doc の **案 2** を選択:

> 案 2: CPU 行動 step pause (オプション)
> 概要: ユーザー設定で「CPU 各 move 後に X 秒 wait」を追加。SpectatorHUD slider
>       を人間 vs CPU でも展開
> 規模: M (100-150 行)

## 期待動作

人間 vs CPU モード (spectatorMode=false) でも `SpectatorHUD` を表示し、CPU
ターン中の pause/step UI を提供。speed slider で CPU 速度を任意調整可能。

## 実動作 (修正前)

`src/ui/components/SpectatorHUD.tsx:34`:
```ts
if (!spectatorMode) return null;
```
spectator mode のみで表示されるため、人間 vs CPU では HUD 不可視 →
pause/step / speed slider 全て利用不可。

一方 `useOppTurnDriver.ts:129-144` は既に `isAiPaused` / `aiStepCounter` を
subscribe して pause/step に対応していたため、**HUD だけが見えない gap**。

## 修正

### `src/ui/components/SpectatorHUD.tsx`

1. gate 変更:
   ```ts
   if (gameState === null) return null;  // 旧: if (!spectatorMode) return null;
   ```
   → game 中なら常時表示。
2. label を mode で切替:
   - spectator: 「AI 速度」「制御」「観戦モード制御」(aria)
   - human vs CPU: 「CPU 速度」「CPU 制御」「CPU 行動制御」(aria)
3. preset / pause / step button は両モード共通。

### `tests/ui/components/SpectatorHUD.test.tsx`

- `beforeEach` で `gameState: {} as never` placeholder set
- 既存「renders nothing when spectatorMode === false」テストを
  「renders HUD with CPU label when spectatorMode === false」に変更
  + 新規「renders nothing when gameState === null」追加
- 8 件 → 9 件 PASS
