# Iframe property flow classification

## Expected

Computed iframe keys use their value at the access point. A locally constructed
plain object with a `contentWindow` field is not treated as a browser iframe.

## Actual

A later safe key assignment hid an earlier iframe access. Fail-closed unresolved
owner handling also classified an ordinary local model as a browser context.

## RCA

Computed properties used a scope-wide constant result, while local plain objects
without privileged values had no distinct allocation identity.

## Fix

Track string values per use, seed typed iframe parameters, and retain a narrow
identity for local object literals that declare browser-named fields.

## Prevention

Source and bundle regressions cover access-point ordering, typed and unresolved
iframes, and locally constructed models.
