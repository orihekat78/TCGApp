# Projected timer invocation alias

## Expected

Timer string execution is rejected through destructured or array-projected
`Reflect.apply` aliases. A timer alias overwritten with a local callable passes.

## Actual

Projected `Reflect.apply` calls passed, while historical timer provenance caused
a false positive after a definite local overwrite.

## RCA

Flow values did not preserve intrinsic, string, or safe-callable identity through
binding patterns. Invocation resolution fell back to all historical sources.

## Fix

Track intrinsic and callable sentinels at each use, project them through binding
patterns, and prefer exact flow state before historical callable relations.

## Prevention

Focused source and bundle regressions cover destructuring, array projection, and
definite overwrite.
