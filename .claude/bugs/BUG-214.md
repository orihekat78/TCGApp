# BUG-214: 相手の宣言能力コストの所有者が反転する回帰

## 期待値

相手が `B05007` の宣言能力 `a2` を使う時、`removeFromHand` の費用は能力の使用者である相手の手札から支払う。人間側には選択UIを出さない。

## 実際値

`sample-d08` (YOU) vs 青緑 (AI) の実操作で、T6にAIが `B05007` を手札から使用し、直後に `宣言能力 → case:opp:a2` を実行した。ログはT6に `効果: 手札リムーブ : 1`、次の人間手番T7に `効果: 手札選択待ち` を記録し、人間側の手札8枚から1枚リムーブする強制選択を表示した。

## RCA

`a2.cost` は `removeFromHand` の pick (`side:'self'`) である。能力所有者が `opp` の場合でも、pending pick のsideまたはchooserが人間側へ解決されている。BUG-181/187で修正済みとされたowner-relative pick解決の回帰候補。

## 横展開実測 (2026-07-16)

`黒赤デッキ` (YOU) 対 `少年探偵団・標準` (AI) で、AIの事件 `D08026` が解決編へ移行した。`D08026.a1` は `case:to-resolved` の `discard { player: 'self', n: 1 }` であり、本来はAIの手札を1枚リムーブする。ログもT7の相手側に `効果: 手札リムーブ : 1` を記録したが、次の人間手番T8で人間側へ `効果: 手札選択待ち` と7枚からの強制リムーブを表示した。コストだけでなく、相手側triggered `discard self` 全般でownerが人間側へ反転している。

`黒赤デッキ` (YOU) 対 `警察・標準` (AI) でも、AIが `D11014.a2` を宣言した。印字効果中の `discard { player: 'self', n: 1 }` はAIの手札をリムーブしてからリムーブの警察を登場させるべきだが、ログはT6相手側の `効果: 手札リムーブ : 1` の直後、次の人間手番T7に人間側の `効果: 手札選択待ち` を記録した。相手の効果内の `discard self` でもpicker所有者が反転する。
