# 推理・アクション共通能力の推理側発動時点

## 期待動作

「推理かアクションしたとき」は、推理キャラをスリープした後、証拠追加前に発動する。

## 実動作（修正前）

D03007、B02004系、B04039、B09047は推理側を`reasoning:end`へ接続し、
証拠追加後に能力を発動した。

## RCAと修正

共通印字の推理時点を推理完了通知として実装していた。対象定義を
`reasoning:after-sleep`へ統一し、CardDef例とreuse説明も同じ契約へ更新した。

## 横断調査と予防

公式TSVの完全一致印字を横断し、D03007、B02004/B02004P/D10023/PR173、
B04039、B09047を同一familyとして固定した。アクション側`action:declare`は維持する。
