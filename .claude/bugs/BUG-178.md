# BUG-178: cardNameComponents が全角＆を分割しない — rules/19 複数名ルール破綻 (57 file)

## 期待動作
rules/19: 「&」で複数キャラ名が併記されたカード名は全分割名を持つ。印字は全角＆のカードが多数
(『江戸川コナン＆工藤新一』等 57 shipped file) — 全角/半角どちらでも分割されるべき。

## 実動作
`cardNameComponents` (src/engine/target/card-def-registry.ts) と tsv-loader の title 分割が
`split('&')` (半角のみ) — 全角＆の名前は非分割 → 【絆】/カード名 filter /同名重ね制限が
これらのカードの分割名を認識しない。paren は `[(（]` 両対応済で、＆のみ欠落。

## 発見経緯
hybrid-batch5 manual probe (B08062 佐藤美和子＆高木渉 a2 の自己条件評価) で probe agent が検出。

## 修正
両 site を `split(/[&＆]/)` へ。回帰 = tests/engine/target/card-name-components-fullwidth.test.ts。

## 水平展開
- 影響 shipped = names に全角＆を含む 57 file (bond/名指定 filter の対象になった時のみ顕在)。
- paren （） は既対応、『』は全角のみ存在 — 他の全角/半角非対称なし (grep 確認)。
- 防止策: name-component 系の新記号対応時は全角/半角ペアで実装 + 回帰 test。
