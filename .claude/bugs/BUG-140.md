## 概要

catalog-reuse / 旧 batch 出荷カードの一部が、TSV の **cutIn / hirameki 列を実装せず**
effect 列のみで出荷されていた。機械監査 (`npx tsx scripts/audit-icon-abilities.mts`、
defHasKeyword = 単一真実源で判定) の結果:

- **cutin 欠落 13 枚** / **hirameki 欠落 63 枚** (出荷 1137 枚中、P 版含む)
- 全リスト: [BUG-140-audit-data.txt](BUG-140-audit-data.txt)

## 影響

1. 該当カード自身がコンタクトでカットイン使用不可 / 証拠リムーブ時にヒラメキ発動しない
2. ability-presence filter (「【カットイン】を持つカード」等、cluster2 で解禁) が該当カードを
   正しく検出できない — B03128 の decoy 検証で B04096 が match せず発見
3. 大半は「カードを1枚引く」「証拠を1つ得る」級の定型 hirameki — 修正は機械的だが 76 枚

## 修正状況

- **B04096 / B04096P のみ cluster2 で補修済** (B03128 filter の live decoy として必要だったため。
  conditional if/else でターン別 AP+1000/+3000)
- 残り 74 枚は専用 wave で一括補修する (定型 hirameki はテンプレ化可能 — D05007 a2 同型)

## 防止策

- `scripts/audit-icon-abilities.mts` を恒久化 (report-only)。残欠落の補修完了後に
  `npm run lint:icon-abilities` として CI 組込み (欠落 = fail 化)
- card-addition-checklist に「TSV cutIn/hirameki/henso 列の非空確認」を明記
