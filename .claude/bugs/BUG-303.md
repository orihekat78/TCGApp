# 【ターン①】の両プレイヤー共通ターン境界

## 期待動作

rules/17の【ターン①】は各ターン1回。自分のカードが自分ターンに発動しても、直後の
相手ターンでは再び1回発動できる。

## 実動作（修正前）

`endTurn(..., { startNextTurn: true })`が次の手番プレイヤーだけをリセットした。
前ターン中に非手番側カードへ記録された`declaredUseCount`が残り、次ターンの発動を拒否した。

## RCA

ターン境界はゲーム全体に1つだが、`resetTurnFlags`の呼出側が手番所有のリセットとして
扱っていた。初回の直接`startTurn`経路にはリセット自体がなかった。

## 修正

`startTurn`の先頭で両プレイヤーのturn-scope flagsと`declaredUseCount`をリセットし、
`turn:start`のlistenerやオートフェイズが旧ターン状態を観測できないようにした。
continuation側の片側リセットは削除した。

## 水平展開

UI、CPU、Replay、観戦の通常経路はすべて`endTurn(..., { startNextTurn: true })`から
`startTurn`へ合流する。初回ゲーム開始だけが`startTurn`を直接呼ぶため、同じ境界で覆った。
終了時効果が前ターン状態を読む必要があるので、`endTurn`清掃へ前倒ししない。
