# favicon 未定義による 404

## 発見契機

YOU vs CPU ループテスト中のブラウザ監査で、`/favicon.ico` の 404 を確認。

## 期待動作

アプリが favicon を明示し、参照先の静的リソースが HTTP 200 を返す。

## 実動作（修正前）

`index.html` に favicon 宣言がなく、ブラウザの既定取得 `/favicon.ico` が HTTP 404。

## 関連ファイル

- `index.html`
- `meta-app/index.html`
- `meta-app/vite.config.meta.ts`
- `public/favicon.svg`
- `meta-app/tests/e2e/bug-275-favicon.spec.ts`

## RCA

5173 / 5174 両入口に favicon の `<link rel="icon">` がなく、共有静的ファイルも
未作成だった。既存E2Eのconsole collectorは汎用404を除外するため検知しなかった。

## 修正

- 5173 / 5174 の両 `index.html` に `/favicon.svg` の宣言を追加。
- `public/favicon.svg` を追加。
- meta-appの `publicDir` を共有 `public/` へ接続。
- 宣言の一意性、参照先、HTTP 200をPlaywrightで固定。

## 水平展開

両 `index.html`、`public/`、E2Eの404除外を検索。favicon以外の同種宣言はなし。
汎用collectorの404除外変更は既存テスト全体への影響が広いため、本件では専用回帰で監視する。

## 検証

- RED: 実際の5174入口で `link[rel~="icon"]` が0件となりPlaywright失敗。
- GREEN: meta-app Playwright desktop 1件通過、`/favicon.svg` HTTP 200。
- in-app browserの現在ブランチ入口で宣言1件、href一致、console error / warning 0。
- 851x393では共有faviconと無関係なレイアウト変更がないことを確認。
- full Vitest 883 files / 6,991 tests通過、typecheck、lint、両build通過。

## 防止策

`meta-app/tests/e2e/bug-275-favicon.spec.ts` でfavicon宣言と配信を直接検証する。
