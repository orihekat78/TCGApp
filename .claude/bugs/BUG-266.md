## Expected

CT-P10 B10050 permits a level-5-or-higher character that has only printed
【カットイン】 and/or 【ヒラメキ】 icons, while rejecting any other printed ability.

## Actual

The only absence filter was `hasOriginalAbility:false`; it rejects every
printed icon. Combining `keywordNot` cannot restore a rejected candidate.

## RCA

Original-ability presence is deliberately static, but the filter lacked the
complementary static predicate that excludes only a declared icon set.

## Horizontal investigation

The new reader is wired through scene, deck, and bound filters. It recognizes
only the existing icon predicates and fails closed for unknown icon names.

## Prevention

Use `hasNoOriginalAbilityExceptIcons` for text of the form
「【X】以外の元の能力を持たない」. Its regression covers vanilla, each
allowed icon, both icons, and a mixed non-icon ability.
