## 仕様 (rules/19 D08013, rules/03)

D08013 吉田歩美【登場時】「証拠を1つ得る / **自分の証拠を1つ選び手札に加える** (evidenceToHand) / 手札を1枚リムーブ」。
「自分の証拠を1つ選び」に表向き/裏向きの区別はなく、**どの証拠でも選択可能**であるべき。

## 期待動作

evidenceToHand の pick モーダル「自分の証拠エリア」で、表向き証拠 cell も選択可能 (クリックで手札に加わる)。

## 実動作

表向き証拠 cell は表示されるが選択不可。**非公開 (裏向き) カードしか選べない**。

## RCA

- engine 候補列挙 (`target/candidates.ts` evidence) は faceUp で絞らず**全 index を候補化** ✓
- `Playmat.tsx:724` は `pendingEffectPick.candidates` を**フィルタせず** pickCands に渡す (表向き index も含む) ✓
- **`CardListModal.tsx` の表向き分岐 (faceDownCount ループ内 `if (faceUpCardId !== undefined)`) が
  `findFaceDownPickUid(idx)` を呼ばず**、`onExpand`/静的描画のみで返していた ✗ (BUG-085 で追加時に pick 未配線)
  - `findFaceDownPickUid` は `evidence:side:idx` を引く index ベースなので、表向き index にも本来使える

## 修正

`CardListModal.tsx` 表向き分岐に pick 判定を追加: `findFaceDownPickUid(idx)` が候補なら
裏向き cell と同じ pickable button (`card-list-pick-evidence:self:idx`、onPick/toggleSelect) として描画。
候補に無ければ従来通り expand/静的 (= flip picker は候補が裏向き index のみ → 表向きは非 pick のまま、影響なし)。

## 水平展開

- flipFaceUpEvidence picker (BUG-085): 候補=裏向き index のみ → 表向き cell は `findFaceDownPickUid`=undefined で
  非 pick のまま。e2e bug-085「表向き混在: 裏向きのみ選択可」が**維持される**ことを確認 (4/4 pass)。
- 他の evidence/remove pick (handAddFromRemove 等) は cardId ベース uid (`findFaceUpPickUid`) で別経路、影響なし。
