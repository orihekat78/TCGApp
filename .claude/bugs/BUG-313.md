# PR135/PR141の第2能力欠落

## 発見契機

leave-trigger QA familyの未閉鎖行を公式rawとCardDefで再照合した。

## 期待動作

PR135/PR141は、相手ターン中に自身が現場からリムーブされたとき、
デッキから最初の「阿笠博士」を公開して手札に加え、残りを下に戻してシャッフルする。

## 実動作

`src/cards/pr-01/PR135.ts`と`PR141.ts`は公式文をコメントに持つが、
`a2` を `DEFERRED` として `abilities: [a1]` のまま出荷している。

## 修正契約

- 両printingへ同一の `leave:to-remove + selfOnly + turn:opp` 能力を追加する。
- 阿笠博士の強制取得、no-match、bottom後shuffle、短いデッキを公開dispatchで証明する。
- 相手ターン/自分ターン/他キャラ離場、PR135/PR141 parityを回帰に含める。

## 水平展開

primitive実装後も `DEFERRED` コメントのまま `abilities`から欠落するCardDefを全件再走査する。

## RCAと修正

必要primitiveは既に出荷済みだったが、初期実装時の `DEFERRED` 判定がCardDefへ残っていた。
両printingへ同一a2を追加し、強制取得、残り順序保持、shuffleを公式文どおり固定した。

## 回帰

- public contact離場で相手ターン、自分ターン、他キャラ離場、owner mirrorを確認する。
- match/no-match、duplicate、短いデッキrefresh、不要なreorder不在を確認する。
- BUG-311静的familyを34定義へ拡張し、PR135/PR141のserialized parityを固定する。
