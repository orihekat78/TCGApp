# String timer dynamic execution

## Expected

The production graph rejects every browser dynamic-code execution surface.

## Actual

`setTimeout("code", 0)` and timer aliases passed source and bundle inspection.

## RCA

Dynamic-code analysis covered `eval` and function constructors but not the
browser timer overload that evaluates strings.

## Fix

Resolve bare, window-qualified, and aliased timers. Reject statically recoverable
string arguments while preserving shadowed local functions.

## Prevention

Focused source and generated-bundle regressions cover direct, aliased,
window-qualified, and shadowed timer calls.
