## 仕様 (rules/17)
条件アイコン未達なら「そもそもその能力を持っていない扱い」= 宣言不可。declared ability も同様。

## 実動作 (バグ)
`canDeclaredAbility` (declared-ability.ts:76-87) は findCardOnBoard + `limit` のみ判定し
`ability.condition` を evalCond しない (コメント:10「対象キャラ存在 + 回数制限のみ判定」)。
triggered は triggered.ts:172 で condition 評価済だが declared は未配線。
→ **D08026 a2** (【解決編】) / **D11003 a2** (婚活&警察2) / **D11021 a2** (解決編&神奈川県警1) が
条件未達でも宣言できてしまう。

## 修正
canDeclaredAbility に追加 (limit チェック後):
```ts
if (ability?.condition) {
  const ctx = { source: { player: found.player, uid, abilityId: abilId, area: found.area }, bindings: {} } as EffectCtx;
  if (!evalCond(state, ability.condition, ctx)) return false;
}
```
UI/AI 列挙は canDeclaredAbility で gate するため自動波及。

## 水平展開
condition を持つ declared ability は MVP で D08026/D11003/D11021 a2 のみ。triggered は gate 済。
