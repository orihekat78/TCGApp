# Bounded Cloudflare audit requests

## Expected

Every API and public probe terminates within a fixed operator-safe deadline.

## Actual

A fetch that never settled could hang preflight or post-deploy verification.

## RCA

The authorization wrapper forwarded only the caller signal and supplied no
per-request timeout.

## Fix

Compose caller cancellation with a validated 15-second default deadline. Abort
the transport and reject even when the injected fetch ignores abort.

## Prevention

Focused tests use a never-resolving fetch and caller cancellation.
