# Wave105 registered all-card name authority

## Expected

- 指定できるのは実在する登録済みカード名だけ。
- カード番号やIDによる追加指定は不要。
- human、AI、save再開、replayが同じ宣言名authorityを使う。

## Actual

- B09003 a3、B09108 a2、B09111 a2はlegacy `unrestricted` domainだった。
- 実在しない任意文字列でも、コスト支払いと使用回数消費を伴って能力を受理した。

## Root cause and fix

- 対象3能力に `registered-card-name` domainが指定されていなかった。
- B09003/P、B09108/P、B09111/Pの印刷能力にdomainを追加。
- 旧pending saveは旧effectの完全一致に加え、area、printed index、set-card witnessの正当性まで検証する。
- 旧replayの宣言名省略は該当印刷能力だけに限定し、当時の合法moveを再現する。
