# B04048 registered all-card name authority

## Expected

- 一意に特定できる省略・1文字違いは登録済みカード名へ正規化する。
- 複数名に該当する入力は、使用回数・queue・deckを変えず拒否する。
- human、AI、save再開が同じ宣言名authorityを使う。

## Actual

- B04048 a2はlegacy `unrestricted` domainだった。
- 入力を自由文字列のままdeck filterへ渡し、一意な省略名でも一致しなかった。
- constrained化だけではUI列挙とAI列挙が必須name未供給で消えた。

## Root cause and fix

- 全カード名を制約するdomainがなく、character-only domainを流用できなかった。
- `registered-card-name`をreader、writer、validator、runtime schema、UI、AIへ追加。
- UI preflightは合法候補で能力を列挙し、modal確定値だけをdispatchする。
- AIはhidden deck順を読まず、登録名辞書順の先頭をMoveへ保存しpolicyが同値を渡す。
- B04048/B04048Pの旧pending saveは、旧effect完全一致と2世代のexact ctx形状だけ許可する。

## Horizontal investigation

- PR099/PR105のcharacter-only domainは既に正しい。
- B01095/B09003/B09052/P/B09108/B09111/B09112にもlegacy unrestrictedが残る。
  exact Q&Aと対象kindをgroundしてから個別に移行する。
- arbitrary unrestricted入力を使う既存カードの挙動は変更しない。
