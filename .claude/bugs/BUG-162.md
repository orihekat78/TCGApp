## 概要

Track B compiler の line-rule 採掘器 (mine.cjs) が「同一印字行に異なる shipped DSL がある」= conflict として
検出した 6 key を手動裁定した結果、**カード DSL の誤訳 2 件**を確定。いずれも公式テキストの語義とズレた実装。

1. **PR276 (萩原千速 promo)** — 同一カードの通常版 B03094 (Q&A grounded、2026-06-23 出荷) と divergence。3 誤り:
   - `sequence` (ungated) → 正: `chain`。「2枚リムーブしてもよい。**そうした場合**、〜」= gated (公式Q&A「デッキ1枚で全リムーブして AP+1000 できるか→いいえ」)。
   - `mill` に `gate:true` 無し → 正: あり。deck<2 で chain break させ AP+1000 を不成立にする必要。
   - `charModifyAP scope:'turn'` → 正: `scope:'action'`。「**アクション終了時まで**」(rules/22: action-end で失効、turn とは別 scope)。
2. **D02004 (服部平次)** — 水平展開で発見。同型の `charModifyAP scope:'turn'` bug。「アクション終了時までこのキャラを AP＋1000する」を turn scope で実装。PR276 のコメントが本カードを precedent に**誤って引用**しており、誤 exemplar が clone で伝播した典型 ([[reference-compiler-b1-mined-line-rules]] の「refuse card 由来 elim rule」と同じ carrier-reuse false-green パターン)。

## 影響 / 期待動作

- **scope bug (PR276/D02004)**: AP+1000 が「アクション終了時」でなく「ターン終了時」まで残る。同ターンに再アクション/ガード/推理が絡む局面で AP が過大に持続 (rules/22「『アクション終了時まで』効果はアクションが終了するごとに失効」に違反)。
- **gate bug (PR276)**: デッキ 0-1 枚で「2枚リムーブ」不成立でも AP+1000 が発動していた (Q&A で否定される all-or-nothing 違反)。
- 期待: いずれも B03094 (Q&A grounded) と一致。

## engine 側の確認 (誤訳であって engine bug ではない)

- `scope:'action'` は engine で honor 済: `mutate/char.ts` ModScope union に `'action'` (L12)、`apMod_action` に積む、
  `read/char.ts:173` で合算、`flow/action/state-machine.ts:342/458` の action-end で `clearTurnEffects('action')` + turn-end safety net。
- ⚠ auto-memory に「engine は scope:action 未対応」の観測 (stale) があったが、直接コード読解 + 既存 golden test
  (wave-deck-mill-gated-chain ⑥ が B03094 の `apMod_action=1000` を assert) で否定済み。

## 修正

- `src/cards/pr-01/PR276.ts` a2: `optional{chain[mill{n:2,gate:true}, charModifyAP{$self,+1000,scope:'action'}]}` に修正 (B03094 a2 と完全一致)。
- `src/cards/ct-d02/D02004.ts` a1: forEach `do` の charModifyAP を `scope:'action'` に修正。
- `src/cards/ct-p07/B07048.ts`: **変更なし**。faceUp 省略は意図的 (`wave-colornot-removeset-0627.test.ts` が `faceUp).toBeUndefined()` を pin)。読取は全経路 falsy 判定 (`!entry.faceUp`、read/char.ts:69/296/305) ゆえ `faceUp:false` と挙動同一 = bug ではない。conflict は benign encoding drift として据え置き (B3 queue)。

## 水平展開

- 「アクション終了時まで」を含む全 shipped ability を機械走査 (hexp-scope.cjs) → non-action scope の charModify は
  PR276/D02004 の 2 件のみ (両方本 commit で修正)。逆パターン (「ターン終了時まで」に scope:'action') は 0 件。
- carrier-reuse で誤 exemplar が伝播する構造リスク: compiler の conflict 検出が今後も同種の「同文言→異DSL」を機械的に surface する
  (= 継続的な回帰ゲート)。残 conflict 5 key は benign encoding drift と裁定 ([[reference-compiler-b1-mined-line-rules]] / B3 queue)。

## 防止策

- Track B compiler の oracle (mismatch=0 の G1 ゲート) + conflict 検出を回帰ゲートとして常用。同一印字行に異なる shipped DSL が
  生じたら CI/mine で surface される。
- clone 実装時は precedent の scope/gate を語義 (rules/22 の action vs turn) で再検証してから流用する。
