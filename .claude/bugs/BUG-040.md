## ユーザー指摘

> #15: カードの宣言効果が使えない

## 期待動作 (rules/21-declared-ability-cost.md)

自分の現場にいるキャラ・自分の事件・自分のパートナーエリアの MR が持つ
【宣言】能力 (【宣言】アイコン付き能力) を使用できる。アクションパネルの
「宣言能力」メニューから source picker → ability picker → 確認モーダル
→ dispatch。

## 実動作 (修正前)

`src/ui/components/Playmat.tsx:382` で ActionsPanel に渡す
`declaredTargetCount` が **literal `0` でハードコーディング** されていた:

```tsx
<ActionsPanel
  ...
  declaredTargetCount={0}
  reasoningTotalLP={
    gameState ? enumReasoningCandidates(gameState, 'self').length : 0
  }
  ...
/>
```

ActionsPanel.tsx:117-118 で `subtitle: '対象 ${declaredTargetCount}キャラ'`、
`disabled: declaredTargetCount === 0` なので、**実際の宣言能力保持キャラの
有無に関係なく、メニューは常に「対象 0キャラ」「disabled」**。

ユーザーは UI 上「宣言能力」項目を見ても disabled なので click できず、
「使えない」と認識した。

## RCA (Root Cause Analysis)

Phase 8.8b で declared ability の UI フロー実装時、`reasoningTotalLP` と同じ
パターンで `declaredTargetCount` も `enum*` 関数で計算する設計だったが、
**Playmat.tsx の prop 受け渡しで literal 0 のままになり、計算配線が漏れた**。

エンジン層 (`flow.canDeclaredAbility` / `useDeclaredAbility`)、UI フロー
(`useActionsPanelFlow.runDeclaredAbilityFlow` / `enumDeclaredAbilitySources`)、
dispatch (`useEngineDispatch` の `declaredAbility` ケース)、picker / confirm
モーダル — すべて完成していたが、**メニュー項目の enable 判定だけが繋がって
いなかった**ため、ユーザーから見ると「実装されていない」ように見えた。

unit test `useActionsPanelFlow.declared-ability.test.ts` (6/6 PASS) は
`runDeclaredAbilityFlow` を直接呼ぶため、Playmat.tsx の prop 漏れを
検出できなかった。

## 水平展開

`Playmat.tsx:376-411` の ActionsPanel props を全件確認:

| prop | 計算配線 |
|------|----------|
| handCount | ✓ handCards.length |
| handUseRemaining | ✓ turnState 由来 |
| nextHintFileCount | ✓ file.length |
| nextHintUsed | ✓ turnState 由来 |
| partnerActive | ✓ partner.state 由来 |
| **declaredTargetCount** | **✗ literal 0** (本 bug) |
| reasoningTotalLP | ✓ enumReasoningCandidates(...).length |
| canAssist | ✓ canAssistForUi |
| canSolveCase | ✓ canSolveCaseForUi |
| actionMode | ✓ pickerPhase 由来 |

→ `declaredTargetCount` のみが配線漏れ。他の prop は全て正しく計算済み。

`partnerActive` のような boolean prop も Playmat 側で計算しているが、partner
ability flow には `enumPartnerAbilities` 等の追加 enum 関数が無く、別系統。
declared だけが「enum 関数あるが Playmat で literal にしていた」パターン。
