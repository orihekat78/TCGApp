# Hand level snapshot is lost on removal

## Expected

- B09040/B09050は、手札からリムーブするカードと盤面候補の両方について、
  効果解決時点の増減後レベルを参照する。

## Actual

- `discard` bindingと`removeFromHand` costPaidがcardIdだけを保持し、
  後続dyn評価で手札カードの印字レベルへ戻っていた。
- 実効レベル4・印字レベル6のカードを使うと、実効レベル5の盤面キャラまで
  誤って候補へ含まれた。

## Root cause and fix

- 手札から離れた後ではhand continuous modifierを再評価できない。
- 離れる直前に`effectiveHandLevel`をsnapshotし、discard bindingとcostPaidへ保存する。
- `$discarded.level`はsnapshotを優先し、旧bindingだけ印字値へfallbackする。
- `discardToRemove`は実在occurrenceだけをremoveへ移し、stale hand pickは
  atom/continuation実行前にfail-closedする。

## Horizontal investigation and prevention

- `$discarded.level` consumer B05040/B09040、`$discarded.levelSum` consumer B07076、
  `$cost.removeFromHand.level` consumer B09050を走査した。
- scene側は既存の実効レベルfilterを維持。hand側だけ離脱前snapshotを追加した。
- 重複・不存在raw targetと、human pick後のhand差し替えを回帰試験化した。
