## 期待動作

推理 / アクション宣言で actor (scene character / partner) が `state: 'sleep'` になり、UI 上で `.sleep` class (横向き表示) が即時反映される (rules/03 §状態、rules/07 §アクション宣言、rules/11 §推理)。

## 実動作 (Round 4c 修正前の user 報告)

「内部処理はうまくいっているけど UI 上で動かすとうまくいっていない」 — engine state は `'sleep'` に変わるが UI に反映されないケースがあった。

## 実機検証 (Round 4d、commit d54e328 適用後)

MCP playwright で再現試行: ✅ 推理 (self-2 → sleep)、✅ アクション[case] (self-3 → sleep)、両方とも DOM `.sleep` class + state 同時反映を確認。**現状の build では再現しない**。

## RCA

Round 4c で BUG-006 修正のため [src/ui/state/store.ts:78-89](../../src/ui/state/store.ts) の `dispatch` に `Object.is(next, current) ? { ...current } : next` の shallow-copy fallback を追加した。これは Zustand `setState` で同一参照が来たときに subscribers が起きない問題を解消する。本 BUG も **同根原因 (Zustand subscriber 不発火)** だったため、BUG-006 修正で副次的に解消された。
