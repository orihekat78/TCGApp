# BUG-186: sceneEnter 短縮形が side に絶対値を渡し owner='opp' で反転 (候補0)

## 期待動作
`sceneEnter{player:'self', from:'remove', max:1, ...}` を **opp 所有**キャラの能力が解決したとき、
opp のリムーブエリアが pick 候補になる。

## 実動作
候補 0 件で pick が surface せず、効果が silent no-op (B05052 a2 の owner=opp probe で実測)。

## RCA
`atom-handlers/scene.ts` sceneEnter 短縮形が `buildShortFormPick(a.from, a, seP0, seP0)` と
**解決済み絶対値** (seP0) を side に渡していた。`sidesForQuery` は query.side を
**owner (ctx.source.player) 相対**で解釈するため、owner='opp' で二重相対化 → 反転。
BUG-174 と同族。sceneToDeck / sceneSetState / charModifyAP 等は `a.player` を相対値のまま
渡しており正しい (各所に BUG-174 コメントあり)。

## 修正
side を `(a.player as 'self'|'opp'|undefined) ?? 'self'` (相対値のまま) に変更。
owner='self' では従来と同値 = 挙動不変、owner='opp' のみ修復。
probe: tests/cards/night-w0/B05052.test.ts (owner=opp pin)。

## 水平展開 → BUG-187
hand 系 atom 短縮形 (~10 call site: discard dcP / handToDeckBottom / handReveal /
partnerAreaRemove / evidenceToHand / handToEvidence / handToFileBottom / useEventFromHand /
handAddFromRemove / removeAreaToDeckTop) が同じく (絶対値, 絶対値) を渡している。
owner='opp' の AI/human 経路で side 反転する latent。個別 probe 付きで別途修正 (BUG-187)。

## 防止策
paShortFormAwait / buildShortFormPick の side 引数は「相対値のまま」規約を lint 化検討。
