# Navigation and legacy clipboard export

## Expected

Navigation state mutation and legacy clipboard commands are forbidden runtime
capabilities in source and generated bundles.

## Actual

`navigation.updateCurrentEntry({ state })` and `document.execCommand("copy")`
were not classified as persistence or export channels.

## RCA

The persistent capability set omitted the Navigation API and legacy document
command surfaces.

## Fix

Add navigation and document command members to privileged persistent surfaces.

## Prevention

Focused regressions cover static and dynamic command forms in source and bundles.
