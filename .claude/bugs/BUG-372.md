# Simultaneous set-card observer loss

## Expected

- setcard離場observer自身と別hostが同時に離れても発動する。
- batch入力順、owner、同時離場枚数で結果が変わらない。

## Actual

- `removeToRemoveBatch`はキャラを逐次spliceした。
- observerを先に処理すると、後続hostの`setcard:leave`時にlive scanから消えた。

## Root cause and fix

- batch開始時に印字`setcard:leave` observer authorityを保存していなかった。
- 公開情報だけのplayer/uid/cardId/abilityIndex/use-countをsnapshotする。
- listenerは離場済みobserverをCardDefから再構築し、回数制限を同じplain recordへ反映する。
- 内部snapshotはqueue前に除去し、GameState/saveへ永続化しない。

## Horizontal investigation and prevention

- source-first/host-first、両owner、Base/P、既使用1回、observer2枚を検証。
- B02020/PとPR234/PR240の同型observerも離場後に1回だけqueueされる。
- raw hook payloadは裏向きset IDとSceneCharacterを含まない。
