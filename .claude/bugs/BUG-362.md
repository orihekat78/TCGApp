# B06025 own-scene target authority

## Expected

- B06025は自分の現場のキャラを1枚まで選ぶ。
- 相手の現場は候補外。0枚選択時は登場しない。

## Actual

- a2が`side: 'either'`を使い、相手キャラも除去できた。
- descriptionから「自分の」が欠落し、誤挙動を表示にも固定した。

## Root cause and fix

- 所有者指定済み公式文を、所有者未指定時のrules/15既定へ誤分類した。
- a2を`side: 'self'`へ限定し、公式descriptionを復元。
- both-ownerでown targetとopponent decoyを同時配置し、候補境界を固定。

## Horizontal investigation

- `side: 'either'`のsceneRemove定義を横断検索。
- 類似候補の「自分の現場」は発動条件・コスト句で、除去対象句は所有者未指定。
- B06025型の追加誤りなし。
