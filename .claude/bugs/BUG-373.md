# B07034 face-down trigger gate

## Expected

- B07034/Pは自側の裏向きset cardが離れた場合だけ発動する。

## Actual

- matcherはowner sideだけを確認し、payloadの`faceUp`を見なかった。
- 表向きset cardの出荷後、表向き離場でもdrawしていた。

## Root cause and fix

- 旧実装は「表向きset producerなし」という前提でfilterを省略していた。
- B10018等により前提が破綻した。
- JSON-safe condition `setCardFaceIs`を追加し、B07034/Pを`faceUp:false`へ限定した。

## Horizontal investigation and prevention

- face-down positive、face-up negative、self leave、simultaneous leaveをpublic pathで検証。
- condition union/evaluator/whitelist同期testを通す。
