## ユーザー指摘

> #12: AIVSAI観戦モードについては、早すぎて何を行っているかがわからない。
> ゆっくり行ってほしい。途中で終わってしまう。手札からカードが全然でない。

## 期待動作

観戦モード (AI vs AI) で:
1. AI 進行速度をユーザーが調整できる (gather slider / preset)
2. 一時停止 / ステップ実行で観察ペースを保てる
3. AI が手札からカード (特に character) を適切に使う

## 実動作 (修正前)

1. `useOppTurnDriver.ts:113` / `useSpectatorTurnDriver.ts:69` で
   `oppTurnDelayMs = 400ms` / `spectatorDelayMs = 400ms` が **固定**
2. 既存 API (`_setOppTurnDriverDelay` / `_setSpectatorDriverDelay`) は test 用
   programmatic のみで、UI 制御 (slider / pause / step) は **未実装**
3. `src/ai/policies/heuristic.ts:168` で `handUseCard` は priority 6 (最低)
   かつ AP/LP scoring なし → event 優先 / なければ手札先頭固定で、
   character card が AP/LP に応じて選ばれない

## RCA (Root Cause Analysis)

- spectator mode (B5 / Round 4l) 実装時、観戦は「動くこと」を優先して
  programmatic delay setter のみ用意 (test 補助)。UI 化は scope outside
- `handUseCard` heuristic は Phase 6 Group B (Task 6.4) 時点で
  「event 優先、character は scoring 後回し」と意図的に簡略化。実プレイで
  character の AP/LP 評価が不足 → 1000 戦 smoke で hand-use 率低下

## 修正

### Fix 1: speed slider UI (`49a7063`)

- `store.aiSpeedMs: number` (default 400) + `setAiSpeedMs`
- `SpectatorHUD.tsx`: `spectatorMode === true` のとき右上に表示
  - preset 5 段: 200/400/800/1500/3000ms
  - active 状態を `is-active` class + `aria-pressed` で示す
- `useOppTurnDriver` / `useSpectatorTurnDriver` を store 直読に refactor

### Fix 2: pause/step ボタン (`4b654fd`)

- `store.isAiPaused: boolean` / `setAiPaused`
- `store.aiStepCounter: number` / `incrementAiStep` (step request 用 counter)
- `SpectatorHUD.tsx` に pause toggle + step button 追加
- driver 側で module-level `_lastConsumedStep` を tracker、paused 中は step
  counter 増分時のみ 1 回駆動

### Fix 3: handUseCard sparse-aware heuristic (`25589ad`)

`heuristic.ts:168-220` を書き換え:
- scene < 3 (sparse): character を `AP + LP * 1.5` で scoring して最良を選ぶ
- scene >= 3 (full): event 優先 (盤面補強より effect 活用)
- 同種内は scoring 最大

### Fix 4: E2E spec `spectator-speed.spec.ts` (`f1b3ebc`)

3 シナリオ: HUD 表示 / slider preset / pause→step→resume 連携

## 水平展開

- 観戦 / 対戦どちらでも HUD は spectatorMode フラグ依存なので干渉なし
- module-level `_lastConsumedStep` は driver ごとに別 (opp / spectator) で
  独立、両 driver が 1 step で fire するため「1 step = 1 cycle (opp + self)」
  となる挙動

  でも必要)

  バランス) を必須
