# Human pre-guard action reconciliation

## Expected

- 宣言時効果でactorまたは対象が現場を離れた時点でactionを終了する。
- guard入力、unguarded hook、contactを追加で要求しない。
- humanとAIで同じタイミングになる。

## Actual

- AIは宣言時効果drain直後に`abortIfMissing`を呼んでいた。
- human dispatchは`activeActionId`を残し、次のguard操作で初めてabortした。
- UIは完了済みactionのguard入力を要求し続けた。

## Root cause and fix

- public dispatchの効果解決境界にguard-window reconciliationが無かった。
- 未解決effect/decisionが完全にsettleした後だけ、全guard-windowを検査する。
- actor/target不在なら既存`abortIfMissing`でcontext削除、action:end、scope清掃を行う。
- action:end observerは同じdispatch内で再drainする。

## Horizontal investigation

- B05092のtarget移動、B03030/B09047のactor switchを即時abortへ統一した。
- contact開始後の離脱は既存contact participant resolverに残し、今回のhelperは
  `guard-window`だけを対象とする。
- AIの既存直後abortは維持した。

## Prevention

- public decision解決後はGameState contextとZustand `activeActionId`を同時に検証する。
- action終了を次のユーザー入力に依存させない。
