# Iframe browsing-context alias escape

## Expected

Persistence and cross-context export through iframe window or document aliases
are rejected in source and generated bundles.

## Actual

`contentWindow` and `contentDocument` were treated as ordinary DOM properties, so
storage and messaging reached through them could pass the boundary.

## RCA

Browser-object propagation did not map iframe browsing-context properties back to
privileged window and document objects.

## Fix

Classify `contentWindow` and `contentDocument` as privileged browser aliases.

## Prevention

Source and generated-bundle regressions cover iframe storage and messaging paths.
