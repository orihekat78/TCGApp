# Iframe browsing-context alias escape

## Expected

Persistence and cross-context export through iframe window or document aliases
are rejected in source and generated bundles.

## Actual

`contentWindow` and `contentDocument` were ordinary properties for unresolved
iframe owners or computed const keys. Bare `parent`, `top`, `opener`, and `frames`
also passed.

## RCA

Browser-object propagation required an already-known DOM owner, computed keys used
an unscoped string evaluator, and the privileged global set omitted bare contexts.

## Fix

Classify browsing-context properties regardless of unresolved owner, resolve scoped
constant property names, and include the browser's bare cross-context globals.

## Prevention

Source and generated-bundle regressions cover created and typed iframes, bare
contexts, storage, and messaging.
