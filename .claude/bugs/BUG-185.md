# BUG-185: 複数名カード 23 枚の names 分割漏れ (rules/19)

## 期待動作
《江戸川コナン＆工藤新一》型のカード名 (「&」「＆」連結) は **すべての分割名を持つ**
(rules/19)。names = [完全名, 分割名...] が規約 (例 B05066: ['赤井秀一＆沖矢昴','赤井秀一','沖矢昴'])。

## 実動作
23 枚 (B05005/B05027/B05086/B05106/B06074/B06084/B06098/B07015/B07065/B08062/B09002/
PR003/PR004/PR005/PR110-113/PR248/PR258-261) が names = [完全名] のみ。
【絆 工藤新一】等の分割名参照・カード名指定効果・同名重ね制限が **不成立になる**。

## RCA
出荷 wave ごとの authoring で rules/19 分割規約の適用が author 依存だった
(exemplar に names 分割例が含まれない wave で漏れ)。M3 triage の二次 finding で発覚。

## 修正
node one-shot script で 23 枚一括分割 (＆/& split、完全名 + 分割名)。
P twin は spread (…BASE) のため base 修正で伝播。

## 水平展開
src/cards 全走査 (names[0] に ＆/& かつ length===1) で 23 枚が全量。
**enforcement: tests/cards/m3-pa-batch/names-split.lint.test.ts** (全登録 def を走査し
未分割を fail — 以後の新カードも自動検出)。

## 防止策
上記 lint test が回帰ゲート。card-addition-checklist に rules/19 分割確認は既載。
