## 概要

Phase 18 (cardId 是正 + DeckEditor/CardsScreen 全面リデザイン) の自己レビューを多エージェント敵対的
ワークフローで実施し、確定した 7 件の本物の回帰/不整合を同セッションで修正した (2 件は refuted)。
cardId へ「表示」を寄せた一方で「トグル/カウント/ハイライト」が印刷num単位のまま残った取りこぼしが中心。

## 確定した回帰と修正 (すべて meta-app 内)

| # | 重大度 | 内容 | 修正 |
|---|-------|------|------|
| 1 | 中 | お気に入りの★がグリッド=cardId単位／詳細パネル=num単位で不整合 → ★が解除できず重複エントリが溜まる | CardsScreen 詳細の isFavorited/onToggle を cardId 単位に統一 (解除時は登録済み全印刷を外す) |
| 2 | 中 | `metaStore._matchMeta` が persist され consume もされない → チュートリアル対戦が前回 Setup のデッキ名/種別で履歴記録 | persist を settings のみに限定(partialize) + `consumeMatchMeta` で読取後クリア |
| 3 | 低 | CardsScreen の FilterRail カウントが印刷(47)単位で、折畳グリッド/CATALOG(34)と食い違う | FilterRail に `pool={foldParallels?DISTINCT_CARDS:CARD_POOL}` を渡す |
| 4 | 低 | DeckEditor の FilterRail カウントがパートナー/事件を含む(プールはキャラ/イベントのみ) → 「アシスト」が0件facet等 | FilterRail に キャラ/イベント限定の poolForRail を渡す |
| 5 | 低 | パラレルまとめON時に別イラスト選択するとグリッド選択ハイライトが消える | CardGrid の選択判定を folded 時 cardId 一致にフォールバック |
| 6 | 低 | validateDeck が存在しないカード番号を受理(デッキコード import で幽霊カード混入可) | validateDeck に未知 num 拒否を追加 |

※ migration の修復不足 (高) は [[BUG-126]] に追記。

## refuted (誤検出として棄却)

- 複製デッキの未保存ガード無し → 複製は編集を破棄せず fork するので benign。
- Date.now() デッキID衝突 → onSave の update/add ガードで重複ID不可、人手クリックで1ms衝突は不可達。

## 防止策

- cardId リファクタ後は「表示・選択・トグル・カウント・集計」の **全経路**を cardId 単位に揃える
  (一部だけ寄せると表示と操作が乖離する)。
- transient な store フィールドは persist の partialize で除外し、使い切り値は consume パターンで明示クリア。
- 検証ゲート(validateDeck)は import/手編集の不正入力(未知num/型違反)も backstop する。
- e2e `deck.spec.ts` に migration 修復・同ID上限可視の回帰テスト、`filter-decoy.spec.ts` に facet decoy 検証を追加。
