# remaining inherent sleep entries

## 期待動作

- B01011/B01050/B01052/B03120/D06016は通常・能力・効果の全経路で
  sleep状態のSceneCharacterとして生成される。
- `enter` observerと本人の【登場時】能力は最初からsleepを観測する。

## 修正前

- 5枚はactiveで登場してからsynthetic `enter → sceneSetState(sleep)`を積んだ。
- observer、owner-order、保存状態が一時activeを観測し、偽の`state:change`も発生した。
- B01011の通常登場後の最終状態だけを見た既存証拠はfalse-greenだった。

## RCAと修正

- BUG-341でPR180/PR186だけを正規化した際、同一印字句5枚がaudit対象のまま残った。
- 5 CardDefを`entersSleep:true`へ移し、synthetic sleep abilityを削除した。
- 残る印刷済みability IDは再採番せず、sparse IDを維持した。

## 回帰と水平確認

- RED: effect-entry時の同期observerが5枚をactive、PR180/PR186をsleepと観測。
- GREEN: 7枚すべてが`enter`時点でsleep、偽`state:change`は0回。
- public event effect-entry、full-scene switch、owner=`opp`、save hydrationを固定。
- B01050/B01052/PR180/PR186/D06016の本来のa2は1回だけ発動する。
- BUG-341のcoherent legacy index-1 hydration証拠を維持した。
