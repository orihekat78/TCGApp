## ユーザー指摘

> #8: 手札のカードの拡大表示ができていない。虫眼鏡マークをつけましょう。
> もしくは右クリックで拡大とか。どっちがいいかな？

## 期待動作

手札の個別カードの詳細 (art / abilities / stats) をモーダルで拡大表示できる。
他 zone (SceneArea / PartnerArea / CaseArea) と同様の操作感。

## 実動作 (修正前)

- `CardExpandModal.tsx` (BUG-001 で実装済) は他 zone から `expandModal.open(cardId)`
  で開ける
- しかし HandZone は `onCardClick` (hand-use trigger) と `onExpand` (zone 折畳
  → 展開) のみで、**個別カードの CardExpandModal を開く trigger が無かった**
- 結果、手札カードは click では hand-use しか起動できず、拡大表示できない

## 関連ファイル

- `src/ui/components/HandZone.tsx` (HandMiniCard / HandCard 両方)
- `src/ui/components/Playmat.tsx:355-380` HandZone への prop 配線
- `src/ui/components/CardExpandModal.tsx` 既存実装 (変更なし、再利用)

## RCA (Root Cause Analysis)

BUG-001 で CardExpandModal を実装、Phase 1 Explore 報告では「HandZone L195/L244
で onExpand / onCardClick 配線済」とあった。これは HandZone 内部に `onExpand`
prop が存在することの記述で、**意味は「zone 折畳→展開」のための callback**。
個別カードの拡大表示用の prop ではなかった。

Playmat.tsx での既存配線:
```tsx
onExpand={() => setHandExpanded(true)}  // ← zone 展開、個別カードではない
```

→ 名前空間の混同で、Phase 1 Explore 時に「実装済」と誤判定された。実機検証で
手札カードのみ右クリック → 無反応であることを発見。

## 水平展開

他の zone で onContextMenu (右クリック) trigger があるか確認:

| Zone | click 動作 | 右クリック動作 |
|------|-----------|---------------|
| SceneArea | candidate なら select、それ以外で onExpand 呼出 (BUG-001 経由) | 未配線 (click で十分) |
| PartnerArea | 同上 | 未配線 |
| CaseArea | 同上 | 未配線 |
| HandZone | onCardClick (hand-use trigger) | **本 BUG で右クリック追加** |
| FileArea / RemoveArea | 全体 click で CardListModal 開く | 未配線 (list 内で別途) |

HandZone のみ click が hand-use に占有されているため、独立した拡大表示 trigger
として右クリック (`onContextMenu`) を採用。他 zone は click で十分なので追加
不要。

## 修正

### `src/ui/components/HandZone.tsx`

`HandMiniCard` / `HandCard` 両 component に `onExpand?: (cardId) => void` prop 追加、
`onContextMenu` ハンドラで `e.preventDefault()` + `onExpand(cardId)` を呼出。
title 属性に「右クリックで拡大表示」のヒントを追加。

`HandZoneProps` に `onCardExpand?: (cardId) => void` を追加 (既存 `onExpand`
zone 展開と名前空間を区別)、collapsed / expanded 両方の card 配置に伝播。

### `src/ui/components/Playmat.tsx:362` (1 行追加)

```tsx
<HandZone
  ...
  onCardExpand={expandModal.open}
  ...
/>
```

他 zone (SceneArea / PartnerArea / CaseArea) で既に使われている
`expandModal.open` を HandZone にも配線。
