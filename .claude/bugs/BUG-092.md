## 仕様 (rules/13 §突撃/迅速, rules/24)

「ターン終了時まで突撃[事件]を持たせる」等、scope='turn' のキーワード付与は、その間
名乗り状態でもアクションできる等の効果を持つべき。

## 期待動作

`mutate.char.grantKeyword(uid, kw, 'turn')` で付与したキーワードが、その間
`read.char.keywords()` / `hasKeyword()` に反映され、突撃の名乗り例外判定等で有効になる。

## 実動作

**scope='turn' のキーワード付与が完全に無効**。
- `mutate.char.grantKeyword` は scope='turn' のとき `turnEffects['grantedKeywords']` に格納する。
- しかし `read.char.keywords()` は `keywordOverrides.granted` + base + continuous のみを読み、
  **`turnEffects['grantedKeywords']` を読まない** (grep で read 箇所ゼロ)。
- 結果、`flow/main/action.ts namedExceptionAllowed` (突撃/迅速 の名乗り例外判定) は
  `read.char.keywords()` を使うため、付与した突撃が効かない。

## 影響カード (charGrantKeyword scope='turn' を使う全4枚)

- D08005 (突撃) / D08011 (突撃) / D11015 (突撃[キャラ] / 突撃[事件]) / D11019 (突撃[事件])
- いずれも「付与した突撃が名乗り状態のアクションを許可しない」= カード効果が空振り。

## 関連調査メモ

- `mutate.char.clearTurnEffects(s, uid, 'turn')` は `grantedKeywords` を含めて削除するが、
  **呼出元が見当たらない** (turn end での turnEffects クリーンアップ配線も要確認)。
- 修正候補: `read.char.keywords()` に `turnEffects['grantedKeywords']` を統合 +
  clearTurnEffects の turn-end 配線 (phase:end:cleanup) を確認・補完。

## 防止策 (修正時)

- scope='turn'/'contact' の charGrantKeyword e2e (名乗り状態キャラに突撃付与→アクション可) を追加。
- 突撃4枚 (D08005/D08011/D11015/D11019) の回帰テスト。
