## 仕様 (rules/17 §【疾風 N】)
「自分の現場にこのターン N 番目に登場したとき」発火。N 判定は turn 境界でリセットされる
`enterOrderThisTurn` を見るべき。

## 実動作 (バグ)
**D11003 a1** / **D11009 a2** の trigger が closure matcher `(p)=>p.enterOrder===1`。
`enterOrder` は累積 scene 位置 (scene.ts:55 = currentCount+1、turn 跨ぎでリセットされない)。
→ 現場に前ターンからのキャラが残ると当ターン1番目登場でも enterOrder≥2 で疾風が不発 (false-neg) /
現場が一旦空になった後の登場で誤発火。canonical な `enterOrderEquals` (cond/eval.ts:189-190) は
`payload.enterOrderThisTurn` を参照しており、D11014 a1 が正しい型。

## 修正
両カードの trigger を closure matcher から `matcherCondition: { kind:'enterOrderEquals', n:1 }` に置換
(hook:'enter' + selfOnly:true 維持)。未使用になる `GameState` import を除去。engine 変更なし。

## 水平展開
疾風 closure は D11003/D11009 のみ (D11014 は既に正)。

## 検証

enterOrderThisTurn:1 で発火確認) / smoke 1000 例外0。
