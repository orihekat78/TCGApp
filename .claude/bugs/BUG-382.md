# Declared cost reaction overtakes source effect

## Expected

- 宣言コストの手札公開で発動した反応は、現在の宣言効果が完了してから解決する。
- 反応発動後に条件能力が無効化されても、発動済み効果は維持する。

## Actual

- cost event journalが宣言効果entry作成前にcommitされ、公開反応が先にqueueされた。
- 同ownerの反応と宣言効果が任意順group化され、宣言効果開始前に停止する経路もあった。

## Root cause and fix

- cost中にqueueされた反応を一度分離し、宣言entry作成後へ戻すだけでは
  `pendingOwnerOrderGroup`のprecedenceを表現できなかった。
- 反応へ宣言entryと同じ`declaredBatch`/`declaredReaction`を付与し、現在効果と
  decision continuationが完了するまで反応をgateする。
- post-payment失敗時はpending runtimeをtransactionalに復元する。

## Horizontal investigation and prevention

- `hand:reveal` consumer B09004/B10006、AI/legacy、owner mirrorを走査した。
- queue順、実resolver進行、rollback、B10006 production activationを個別回帰化した。
