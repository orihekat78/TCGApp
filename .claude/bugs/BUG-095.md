## 仕様 (rules/24, 25)

常時有効型 (`type:'continuous'`) の `continuousModifier.apDelta`/`lpDelta` は
「read 時に毎回再計算し、AP/LP に合算する」セレクタ。条件成立中のみ有効・条件外で即失効。

## 期待動作

D08005 a1「【自分ターン中】自分の表向きの証拠1つにつき AP+1000」が
`engine.read.char.ap` に反映され、表向き証拠 N 枚で AP = base + N×1000 になる。

## 実動作 (バグ)

- `continuousModifier.apDelta`/`lpDelta` は **関数のみ型** (card-def.ts:70-71)。
- engine が `continuousModifier` から読むのは **`grantKeywords` のみ** (read/char.ts continuous walk)。
  `ap()`/`lp()` は `turnEffects['apMod_*']` + override しか合算せず **apDelta/lpDelta を一切呼ばない**。
- リポジトリ全 grep で apDelta/lpDelta の production consumer は **0件** → D08005 a1 は完全な
  **デッドコード**。AP+1000/証拠は実機で効いていなかった (smoke でも AP に未反映)。
- 既存テストは `toBeDefined()` のみで数値挙動を検証せず、バグを見逃していた。

## RCA

- card-def.ts のコメント (「engine.read.char.ap/lp 等が selector 経由で動的に合算する」) は
  apDelta/lpDelta の配線を **意図していた** が、実装が grantKeywords のみで止まっていた (未配線)。
- charModifyAP atom はスナップショット (1回発火) モデルのため、証拠枚数のターン中増減に
  追従する常時再計算型には不適。宣言形にするには engine 配線が必須だった。

## 修正 (骨格バグ修正例外)

1. **eval.ts**: dyn root `$self.faceUpEvidence` 追加 (ctx.source.player の表向き証拠数、sceneTrait と同型)。
2. **card-def.ts**: `ContinuousDelta` 型 (`number | {dyn} | closure`)。apDelta/lpDelta を拡張。
3. **read/char.ts**: `continuousDelta()` helper を追加し `ap()`/`lp()` に合算配線
   (keywords() の grantKeywords walk と同経路、condition を evalCond で gate、dyn/closure/定数を解決、NaN ガード)。
4. **D08005 a1**: `continuousModifier:{apDelta:{dyn:'$self.faceUpEvidence * 1000'}}` の宣言形へ。

## 水平展開

- closure 形 AP/LP 修正は **D08005 a1 が唯一** (他カードは charModifyAP atom)。横展開の修正対象なし。
- grantKeywords-only continuous (D08021/D11007/partnerColorKeyword) は apDelta undefined で skip → 誤加算なし。
- `lpDelta` は production 未使用だが対称配線 (将来カード + ability-def.test synthetic closure 用)。
- 循環 import (dyn/eval ↔ read/char) は runtime-only (関数本体内参照のみ) で TDZ ハザードなし。

## 防止策

- behavioral オラクル追加 (D08005.test.ts: 表向き N 枚→AP+N×1000 / 相手ターン失効 / owner=opp / 裏向き除外)。
- convention 規則6 を「apDelta/lpDelta は dyn 宣言形・推奨 + `$self.ap`/`$self.lp` 参照禁止 (再帰回避)」へ更新。
- adversarial verify workflow 3レンズ (correctness/regression/rules) で sound 確認。
