## 修正 (Round 4l)

[OppTurnOverlay.tsx](../../src/ui/components/OppTurnOverlay.tsx) を拡張: `activeActionId` 進行中なら「相手がアクション解決中…」表示、`MAX_MOVES_PER_TURN = 200` (= PLAY_TURN_SAFETY_CAP) を「安全上限 200 手」として明示表示。`useOppTurnDriver` は既に `pauseOnAction: true` を使用済 (Phase 8 で実装)、Round 4l では UI 側可視化のみ拡張。


## 期待動作

相手の各 action を視覚的に追跡可能、タイムアウト明示。各 action 1 つ 1 つに pause + ハイライト/演出。

## 実動作

OppTurnOverlay の text + 3-dot spinner のみ、AI 完了まで pause。「タイムアウトになっている可能性あり」とユーザ報告。
