## Expected

B02023 has all printed abilities. Its 【宣言】【ターン1】 removes one facedown set card from the controller's scene as a cost, then sleeps up to one scene character.

## Actual

Only the enter and hirameki abilities were registered. The declared ability remained a stale deferred comment despite the `removeSetCard` primitive already being shipped.
The public flow also lacked an exact physical-occurrence witness, so duplicate set cards and legacy states could not be selected safely without revealing facedown IDs.

## RCA

The card definition was authored before the generic facedown set-card cost primitive. The later engine wave did not return to this deferred card.
The cost seam carried only host UIDs and silently normalized malformed arrays into fallback payment. Legacy optional `instanceId` values were not canonicalized at hydration.

## Horizontal investigation

No B02023P printing exists. All seven consumers were checked: B02023, B03035, B05052, B07048, B08033, B08041, and B09027. Their selected public cost branches resolve through the shared picker. B03035's printed text permits any set card, so its cost now uses `anyFace:true`; face-up PR234/PR240 are covered. B08041 keeps `hostSelf`; the other facedown-only consumers remain unchanged. The adjacent B02023 enter/hirameki definitions remain separately retained and tested by descriptor shape.

## Prevention

On every engine primitive unlock, search stale `DEFERRED` card comments and adjudicate all matching printed costs. Public activation tests must include own/opp set-card decoys, exact occurrence selection, malformed/sparse witness rejection, hydration ID collisions, AI fallback, and all consumers of the shared cost primitive.
