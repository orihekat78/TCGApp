## 期待動作

851x393 の Pixel 5 landscape でも、guard / effect / ChoicePickerModal 系の候補、詳細、最終操作を
viewport 内で確認・scroll・click できる。最終操作は 44px 以上を保つ。

## 実際動作

3 modal shell は portrait 幅だけを対象にしていた。landscape の 851px 幅では desktop 固定寸法が残り、
長い候補列の詳細または decline / confirm が viewport 外へ出る。

## RCA

`GuardPickerModal.css` と `ChoicePickerModal.css` は `max-width: 600px`、
`EffectPickerModal.css` は `max-width: 480px` のみで小画面規則を適用していた。
Pixel 5 landscape は 851x393 のため全規則を bypass し、shell 自体に短辺制約・scroll escape hatch がない。

## 横断調査

`GuardPickerModal` は contact guard-window から到達。`EffectPickerModal` は area/direct-pick を除く
`pendingEffectPick` から到達。Choice shell は declared choice、effect choice、optional、repeat optional、
choose-intercept、set-card replacement、leave-intercept、RPS / set-card choice が mount する。長い tile 列を
実際に持てる主経路は effect pick、choose-intercept、set-card replacement。leave-intercept は固定2枚、
guard は field 上限由来の有限候補だが短辺 overflow を再現する。

## 再発防止

viewport 幅ではなく短辺で失敗する dialog は `max-height` と `overflow-y:auto` を shell に持たせる。
Pixel 5 landscape E2E で bounds、内部scroll、detail close、最終操作と pending/state を固定する。
