## RCA

Guard, effect, and choice picker shells used width-only mobile breakpoints, so 851x393 bypassed short-height containment and pushed fixed actions outside the viewport.

## Evidence

- `src/ui/components/GuardPickerModal.css`
- `src/ui/components/EffectPickerModal.css`
- `src/ui/components/ChoicePickerModal.css`
- `tests/e2e/bug-241-landscape-pickers.spec.ts`

## Verification

Formal 851x393 tests cover guard, effect, choose-intercept, set-card replacement, leave-intercept, optional/repeat/RPS, fixed 44px actions, detail close, and exact resolution. `d25ff570` pins the shared footer; `bc09b049` removes obsolete test support.

## Horizontal investigation

All shared choice hosts and dedicated set-card choice were checked; only the candidate body scrolls, while header and action footer remain fixed.

## Prevention

Mobile means 851x393 landscape. Each picker change needs short-height bounds, real scroll, fixed action, and callback-after-close proof.
