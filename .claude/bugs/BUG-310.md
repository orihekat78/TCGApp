# 必須順序選択のEscape結果

## 期待動作

必須のデッキ下順序選択でEscapeを押した結果が明確で、カード順を意図せず変更しない。

## 実動作（修正前）

focus trapがEscapeを消費したがcallbackがなく、modalも状態も変わらず説明もなかった。

## RCAと修正

必須decisionの安全な取消は「公開時の元順で確定」と定義。Escapeと可視buttonを同じdispatchへ接続し、
説明文にも結果を表示する。ローカルで並べ替えた後のEscapeでも元の`cardIds`を送る。
