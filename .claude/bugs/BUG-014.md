## 期待動作

後攻 Human プレイヤーが手番に入ったとき、auto-phase (パートナー active + ドロー + FILE 配置) が自動実行される。

## 実動作

後攻 Human の手番開始時に auto-phase が走らず、初手で行動不能になった。

## RCA

`gameStarter.ts` と `useEngineDispatch.endTurn` で `flow.startTurn` の呼出経路がバラついていた。

## 修正

`engine.flow.startTurn` を 3 箇所 (`gameStarter.ts:43` + `useEngineDispatch.endTurn` + `useOppTurnDriver`) で統一呼出に集約。**1 修正で BUG-014 / BUG-015 / BUG-016 を同時解消**。

- 同 root cause: BUG-015 / BUG-016
