## ユーザー指摘

> #17: 今、2 デッキ使えますが対戦開始すると強制的に 08 のほうになっている。
> 対戦開始前に自分と CPU のデッキを選べるようにしてほしい。

## 期待動作

MVP 提供の 2 デッキ (CT-D08「青の古城探索事件」/ CT-D11「千速と重悟の婚活
パーティー」) をユーザーが選んで対戦開始できる。self / opp それぞれ独立に
選択可能 (ミラー戦も可)。

## 実動作 (修正前)

- `src/ui/services/deckBuilder.ts:42-47` の `buildMvpDeckPair()` が
  self = CT-D08、opp = CT-D11 で **固定**
- `src/ui/services/gameStarter.ts:performGameStart()` が `buildMvpDeckPair()`
  を引数なしで呼ぶ
- `src/ui/components/GameSetupModal.tsx` にデッキ選択 UI が存在しない

→ 「対戦開始」「チュートリアル」「観戦モード」全 button から常に同じ組合せで
起動。コード内に「カード def 上 D11 のみ宣言能力持ち」「engine API は両方
対応」とドキュメントがあるのに UI が選択肢を出さず、ユーザーから「強制的に
08 になる」と認識。

## 関連ファイル

- `src/ui/services/deckBuilder.ts` — ハードコーディング箇所
- `src/ui/services/gameStarter.ts` — performGameStart シグネチャ
- `src/ui/components/GameSetupModal.tsx` — UI 未配備
- `src/ui/components/GameSetupModal.css` — スタイル拡張

## RCA (Root Cause Analysis)

Task 8.4b で MVP の deck 配線を実装する際、コメントで「MVP では デッキ選択
UI を出さず、両者固定の対戦を提供」と意図的に scope を絞っていた。Phase 9
以降の拡張で対応予定だったが、user_request #17 でユーザーから明示要望。

## 水平展開

- `buildMvpDeckPair` を直接呼び出す箇所: `gameStarter.ts` 1 件のみ (本 fix
  対象)
- ハードコーディングを残す箇所: `createSampleGameState` (turn-4 デモ用) は
  本要望と関係なし (固定 state ロード)、変更不要
- engine.flow.setup.init は validateDeck で各 deck の整合性を検証するため、
  任意の組合せでも安全

## 修正

### `deckBuilder.ts` (API 拡張)

- `DeckId` 型 (`'CT-D08' | 'CT-D11'`) を export
- `AVAILABLE_DECKS` 配列 (id + label の組) を export
- `buildDeckSpec(deckId)` private 関数で各 deck の DeckSpec を生成
- `buildDeckPair({selfDeckId, oppDeckId})` 新 API で任意組合せの DeckPair 生成
- `buildMvpDeckPair()` は後方互換 wrapper として残置 (内部は buildDeckPair に委譲)

### `gameStarter.ts` (optional 引数追加)

- `performGameStart` に optional 第二引数 `deckSelection?: {selfDeckId, oppDeckId}`
- 渡されたら `buildDeckPair` を、なければ既存の `buildMvpDeckPair` を使用
  (既存テスト/外部呼出への影響なし)

### `GameSetupModal.tsx` (デッキ選択 UI)

- `useState<DeckId>` で selfDeckId / oppDeckId を管理
- `<fieldset>` 内に 2 つの `<select>` (data-testid: game-setup-self-deck /
  game-setup-opp-deck)
- 「対戦開始」「チュートリアル」「観戦モード」全 button が
  `deckSelection` を `performGameStart(undefined, deckSelection)` に渡す
- デモは固定 sampleGameState のため deck 選択無関係

### `GameSetupModal.css` (style 追加)

- `.game-setup-deck-select` / `.game-setup-deck-row` / `.game-setup-deck-label`
  のスタイル追加 (既存配色 [青系 + 黄系 button] に合わせた dark theme)
