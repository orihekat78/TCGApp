## 概要

`deckToBottomBound` (atom-handlers.ts) は bound カードを **公開順固定** でデッキ下に移す。
公式テキスト「残りを**好きな順番で**デッキの下に移す」の順序選択権 (デッキ循環で後に公開情報化
する戦略要素) を human にも AI にも surface していない。D05007.ts に既知注記
(`player-reorder not surfaced — see notes`) がある既存非準拠の正式起票。

## 影響範囲

deckToBottomBound 使用カード全件 (deck-look-N 系 38+ 枚、BUG-132 GAP-1 の chooseMatch 対象と同族)。

## 期待動作

human: 並べ替え UI (modal) で順序を決定。AI: heuristic (現状の固定順は合法な一choice なので暫定可)。

## 修正方針 (defer)

並べ替え UI (drag or 順次クリック) の新設が必要 — UI 工数があるため独立 wave で対応。
engine 側は deckToBottomBound に `order: cardId[]` 引数を追加し、未指定は従来順とする後方互換案。

## 防止策

- 「好きな順番で」句を含むカードの certify では順序選択の surface 有無を明記する
