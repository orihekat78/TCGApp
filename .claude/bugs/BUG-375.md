# Public hand reveal presentation omission

## Expected

- 「手札から1枚公開」したカードを両プレイヤーが効果解決中に確認できる。
- 解決後はpresentationを閉じ、再び非公開にできる。

## Actual

- `handReveal`はzone不変と内部hookだけを処理した。
- `audience`と`lifetime`が無いCardDefは公開windowを生成しなかった。

## Root cause and fix

- 初期CardDefが公開表示metadata導入前の短縮形を残していた。
- B07053へ`audience:'all'`と`lifetime:'presentation'`を追加した。
- 同型のB07022、B08082、B09036/P、B10009、B10093も同時修正した。

## Horizontal investigation and prevention

- 7 printingを実hand-use、human pick、公開window、closeまで検証した。
- B07053はself/opp owner、decline、desktop/mobileを検証した。
- 手札snapshotは表示中だけ保持し、GameStateへ追加フィールドを作らない。
