# React default projection mutation

## Expected

Mutation through an interop namespace's `.default` projection revokes trust for
every sibling namespace backed by the same vendor export.

## Actual

Namespace ownership accepted identifiers only, so `First.default.useCallback`
was not connected to `First` or a later sibling interop result.

## Related files

- `scripts/private-hosted/audit-runtime-boundary.ts`
- `tests/release/private-hosted-runtime-boundary.test.ts`

## RCA and fix

The wrapper's shared default projection was absent from namespace ownership.
Resolve static `.default` projections back to their owning namespace binding.

## Horizontal investigation and prevention

Regressions cover direct sibling mutation, default-projection mutation, computed
mutation, bulk mutation, and opaque mutation calls.
