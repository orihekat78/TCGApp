# B08054 host-leave set-card replacement missing

## Expected

- 相手の能力・効果またはコンタクトAPでB08054が離場するとき、裏向きset全枚を
  通常のリムーブ処理の代わりに所有者の手札へ戻す。
- host本体の行先は変えず、同時発動能力より前に同期処理する。
- 表向きset、stacked card、自分の効果・cost・switchには適用しない。

## Actual

- B08054 a1に実装がなく、すべてのset cardが通常どおりremoveされた。
- remove以外のscene離場mutatorには効果帰属を保持する共通契約もなかった。

## Root cause and fix

- 従来の`leaveInterceptRedirect`はhost本体の行先変更専用で、付属setだけを置換する
  同期primitiveがなかった。
- CardDefへ`hostLeaveSetCardReplacement`を追加し、全scene離場mutatorの通常set cleanup
  直前に純粋consultを行う。
- effect callerとB02052 pending resumeに`cause/byUid/byPlayer`を保存し、旧saveで値が
  無い場合は適用しないfail-closed互換にした。
- `setcard:leave`は行先`hand`を保持する。実B02020 observerのpending continuationで
  hidden identity漏洩をRED検出し、private-hand行きのqueued payloadだけを匿名化した。

## Horizontal investigation and prevention

- remove/hand/deck/evidence/stack、contact、batch、B02052 hydrationを走査した。
- owner effect、cost、switch、misplay、prevented leave、attribution欠落を負例化した。
- face-up setとstacked cardは従来のremove処理を維持する。
- B02020/B07034、B02084、PR234/PR240を走査し、face-up consumerは匿名化対象外とした。
