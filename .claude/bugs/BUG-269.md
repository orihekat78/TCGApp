# Escape abandoned an active match

## Expected

During `#match`, Escape must not navigate HOME and discard a human player's
active turn or target-selection context.

## Actual

In row 015, an action target selection had no visible cancel control. Pressing
Escape routed from MATCH to HOME and abandoned the game.

## Evidence and RCA

- Public UI reproduction: action target selection -> Escape -> HOME.
- `meta-app/src/router/useGlobalShortcuts.ts` protected only `aria-modal`
  overlays. Playmat target selection is not a dialog, so the global Escape
  handler called `onNav('home')`.

## Fix and prevention

- Suppress Escape/Backspace global navigation while route is `match`.
- Added `useGlobalShortcuts` regression coverage. Focused Vitest: 14 passed.
- Horizontal check: modal escape paths remain covered by the same test file;
  other route hotkeys are unchanged.
