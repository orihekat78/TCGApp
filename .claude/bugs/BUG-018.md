## 期待動作

アシスト宣言の ConfirmModal で「アシスト後 FILE が 7+ になると事件編 → 解決編へ移行する (rules/01)」の警告を表示。

## 実動作

警告が一切無く、ユーザが意図せず解決編に移行してしまうケースがあった。

## 修正

ConfirmModal の body に動的警告ロジックを追加 — `self.file.length + 1 >= 7` のとき「解決編へ自動移行」警告を出す。
