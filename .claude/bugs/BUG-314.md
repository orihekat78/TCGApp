# 公開残りだけのshuffle範囲誤り

## 期待動作

「残りをシャッフルしてデッキの下に移す」は、公開した残りだけを無作為化し、
未公開のデッキ本体の順序を変えず、その下へ戻す。

## 実動作（修正前）

B01022、B03018、B03042、B08026は、残りを任意順で下へ移した後、
`deckShuffle`で未公開部分を含むデッキ全体を無作為化した。
人間所有者には印字にない順序選択も表示し得た。

## RCAと修正

異なる印字「残りを下に移し、デッキをシャッフルする」と同じDSL列へ変換していた。
正しい6定義B01022/B02019/B02019P/B03018/B03042/B08026を
`deckToBottomBound { bindKey:'$revealed', order:'shuffle' }`へ統一し、後続`deckShuffle`を除去した。

## 横断調査と予防

公式TSVの完全一致句を横断し、上記6定義だけをfamilyとして固定した。
D11019などデッキ全体shuffleを明記する別句は変更しない。

## 回帰

- 静的familyでexact 6、`$revealed`、`order:'shuffle'`、`deckShuffle`不在を検証する。
- B08026、B01022、B03042、B03018のpublic経路で未公開tailの順序不変を検証する。
- 複数登場、複数取得、離場トリガ後の選択occurrence pruneを含める。
