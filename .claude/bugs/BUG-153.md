## 概要

`charSetCard{fromDeckTop:true}` (atom-handlers/char.ts:186 `atomCharSetCard`) は
**deck.shift() で上端カードを除去してから** `mutate.char.setCard(scUid, ...)` を呼ぶ。
`setCard` は host が現場に不在なら `if (!found) return;` (mutate/char.ts:210-213) で no-op。
→ host 離場時、シフトした上端カードが **deck からも remove からも消える (カード消失)**。

## 期待動作 / 実動作

- 期待 (公式Q&A、B05035 等): 効果解決までに対象キャラ (host) が現場を離れていたら
  「裏向きでセット」は実行できず、**公開した/上端のカードはそのままデッキの上に戻す**。
- 実動作: `deck.shift()` が先に走り、その後 `setCard` が host 不在で no-op →
  カードはデッキにも戻らず、リムーブにも入らず、setCards にも付かない = **消失**。

## 根本原因

`atomCharSetCard` の fromDeckTop 分岐 (char.ts:208-220) が **「シフト → setCard」** の順:

```
scCardId = sscDeck.shift()!;          // 先に deck から除去
mutate.char.setCard(s, scUid, scCardId, faceUp);  // host 不在なら no-op (カード行き場なし)
```

host 存在チェックを **shift の前** に置けば修正可能 (host 不在なら shift せず return = カードは deck 上端に残る)。

## 影響範囲 (水平展開)

`charSetCard{fromDeckTop}` を使う全カード。当初リスト (B03061 / B07034 / PR099 / B05030 / B02018 /
B02020 / B02023 / B02030 / B08054) は **過少申告**で、敵対 review (水平展開 lens, 2026-06-23) が
`grep -rl fromDeckTop src/cards` = **約30ファイル**を確認。host 引数の種別で到達性が異なる:

- **host = `$self`** (B03061 / B05030 / PR099 等の単発 enter→atom): enter と atom の間に介入が無く
  host 離場は **実用上到達不能**。
- **host ≠ `$self`** (= host-absent の真の到達経路): B03034 (`$contact.targetUid`, player:opp) /
  B07058・B09038 (`$entered.uid`) / PR049 (`$pick`) / B02020・B03032 (opp PA短縮形 max:1) 等。
  対象キャラが解決前に離場し得る。
- **全ケースで faithfulness は改善方向**: 旧 = deck 上端消失 → 新 = deck 上端保持 (rules/16・公式Q&A
  「離場時はデッキ上に戻す」整合、「1枚まで選び」型は 0枚解決と等価)。回帰は無い (host-present は完全不変)。
- **B05035 のみ公式Q&A が host-absent 挙動を明示** (「デッキの上に戻す」) → faithfulness 違反が
  documented だったため当初 DEFER。本 wave で修正し **再出荷済** (ALL_CARDS 1409→1410)。

## 修正 (実施済、engine additive)

`atomCharSetCard` (atom-handlers/char.ts) の fromDeckTop explicit-uid 分岐で、`sscDeck.shift()` の
**前**に `readScene.byUid(s, scUid)` で host 存在を確認し、不在なら shift せず return (カードを deck
上端に残す)。`readScene.byUid` は `setCard` の `findChar` と byte-identical な scene scan
(self.scene+opp.scene のみ) ゆえ host 存在時は従来と完全同挙動 = 回帰ゼロ。diff = char.ts に 10 行追加のみ
(1 import + host-check ブロック、既存行の変更なし)。
