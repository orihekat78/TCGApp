# Browser persistence and cross-context export

## Expected

Game state remains memory-only and cannot enter accounts, browser persistence,
clipboard, or another browsing context.

## Actual

History state, `window.name`, Credentials API, clipboard, opener messaging, and
BroadcastChannel passed source and bundle inspection.

## RCA

The persistent and network capability sets omitted these browser surfaces.

## Fix

Classify the omitted persistence, account, clipboard, and cross-context channels
as forbidden runtime capabilities.

## Prevention

Focused source and generated-bundle regressions cover every confirmed channel.
