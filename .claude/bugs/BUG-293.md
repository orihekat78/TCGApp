# Exposed vendor factory result

## Expected

Bundle React trust requires the pinned vendor factory to be used only in the
exact trusted interop expression, with no mutable result exposure.

## Actual

An earlier call could mutate the cached vendor export before a syntactically
valid `interop(factory(), 1)` call.

## Related files

- `scripts/private-hosted/audit-runtime-boundary.ts`
- `tests/release/private-hosted-runtime-boundary.test.ts`

## RCA and fix

Trust checked only the final expression shape. Reject any other runtime reference
to the pinned factory and propagate mutation across sibling interop namespaces.

## Horizontal investigation and prevention

Regressions cover cached-result mutation, indirect factory exposure, and mutation
through a sibling exact interop namespace.
