## Expected

While B04059 is in the scene, it has both card names [水無怜奈] and [本堂瑛海].
Outside the scene, it only has [水無怜奈].

## Actual (before fix)

B04059 only defined its opponent-turn leave trigger. Name readers never exposed
[本堂瑛海], so scene card-name checks, bonds, and name-filtered effects failed.

## RCA

The card was partial-shipped before the existing area-scoped `grantNames` path
was applied to it.

## Related files

- `src/cards/ct-p04/B04059.ts`
- `tests/cards/official-qa/B04059.test.ts`

## Horizontal investigation

B07053 and B05012 use the existing `continuousModifier.grantNames` pattern.
It is evaluated only for a known scene character; hand, deck, and remove retain
printed names only.

`consult-choose-intercept.ts` and `distinctNames` intentionally remain
printed-only hidden consumers. The regression confirms the latter does not
collapse B04059 with a printed 本堂瑛海 card.

## Prevention

Use a card-bound regression test for scene-positive reader, bond, target filter,
and hand/deck/remove-negative identity checks.
