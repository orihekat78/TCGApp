## 仕様 (rules/15)
D11012 a1「LP0の[警察]を1枚まで選び、ターン終了時までLP＋1するか、AP＋2000する」はプレイヤーが
LP＋1 / AP＋2000 を **択一** する。

## 実動作 (バグ)
1. `resolver.run` の choice は `ctx.dyn.choiceIndex` を読むが、production の人間/AI どちらも choiceIndex を
   set せず、かつ effect は `event.queue` → `entryToCtx` で ctx.dyn が落ちるため runtime に届かない →
   常に option0 (LP＋1) 固定、option1 (AP＋2000) 到達不能。UI に択一 modal も無い。
2. (副次 pre-existing) D11012 a1 の cost `selfToDeckBottom` は useDeclaredAbility 呼出前に source を
   デッキ下へ移すため `findCardOnBoard` が null → "not on board" throw (full dispatch 経路が未検証だった)。

## 修正 (human 経路)
- **engine**: `resolveEffectPicks` の choice case を、`ctx.dyn.choiceIndex` 指定時に「選択 option のみ」へ
  unwrap (dyn-arg / pick と同様に walk 中に bake)。未指定/範囲外は全 option walk (resolver default 0)。
- **engine**: `useDeclaredAbility` で findCardOnBoard が null かつ cost.pay 済 `ctx.source` がある場合、
  ctx.source (cardId/player/area) から ability を解決 (selfToDeckBottom 救済、rules/21 cost-first 維持)。
- **ui**: `useChoicePicker` store/hook + `ChoicePickerModal` 追加。`runDeclaredAbilityFlow` が複数 option の
  top-level choice で modal を ask → 選択 index を `ctx.dyn.choiceIndex` に積む。`choiceOptionLabel` で
  「LP＋1」「AP＋2000」を導出。Playmat に PlaymatChoicePickerModal を mount。
- 単一 option の choice (D11014 a2 step2 / D08019 / D08026 / D11009 / D11021 等) は modal を出さず既定 0 (動作不変)。

## 効果範囲 / 水平展開
- 複数 option の choice は **D11012 a1 のみ** (他 8 箇所は単一 option、choiceIndex=0 で正)。
- **AI fan-out**: D11012 a1 の option は PA 短縮形 charModifyLP/AP。**BUG-109 修正後、AI の choice 効果は
  drain で適用される** (既定 option0=LP+1)。AI が AP/LP を intelligent に択一する choiceIndex 選択
  (branch 評価) は別途 (BUG-108 AI fan-out 残、低優先)。
