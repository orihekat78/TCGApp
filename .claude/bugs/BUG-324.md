# キャラ限定sceneEnterの対象種別漏れ

## 期待動作

B08056は手札の指定名かつレベル7以下のキャラだけを登場候補にする。
B09055/P/P2はパートナーエリアかリムーブエリアの指定名キャラだけを
登場候補にする。条件を満たす同名イベントは候補外になる。

## 実動作（修正前）

B08056は対象filterが`cardName`と`levelMax`だけを指定していた。
B09055/P/P2は`cardName`だけだった。共通候補列挙と`sceneEnter`処理側に
暗黙のキャラ制約がなく、条件を満たす合成イベントが公開候補へ混入した。

## RCAと修正

カード定義が「登場」verb自体にキャラ種別制約があると仮定したが、
候補列挙とmutationの責務にはその制約がなかった。B08056と
B09055/P/P2の対象filterへ`kind: 'character'`を追加した。

## 回帰

- 修正前: 同名・レベル7のイベントが候補へ混入してRED
- 修正後: B08056公開宣言経路10/10、B09055 union経路4/4 PASS
- 同レベル別名、同名レベル超過、同名同レベルイベントを別々に除外
- B09055はPA/remove両方の同名イベントを除外し、3 mirrorのfilterを固定
- 入場した対象のenter能力が1回だけ解決して1枚だけドロー

## 水平展開と防止策

`src/cards`の`sceneEnter`直接filterと`target.query.filter`をAST横断した。
同型漏れはB09055の3 mirrorだけで、修正後に残存なし。登場候補テストでは、
許可条件を種別以外すべて満たすイベントdecoyを必須にする。
