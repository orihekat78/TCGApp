# BUG-187: hand 系 atom 短縮形の side 絶対値渡し (BUG-186 同族、owner='opp' latent)

## 概要
BUG-186 の水平展開で発見。以下の call site が `buildShortFormPick(area, a, chooser, side)` の
side に **resolvePlayer 済み絶対値**を渡している。`sidesForQuery` は owner 相対解釈のため、
owner='opp' のとき side が反転する (owner='self' は偶然一致で無害 = 全既存 probe が素通し)。

- core.ts:72 discard (side=dcP) — ⚠ B01077 probe は owner=opp で pass しているが、
  fixture の対称性で偽陰性の可能性あり。要 side 非対称 fixture で再検証
- core.ts:132 handToDeckBottom / :217 handReveal / :271 partnerAreaRemove /
  :722 evidenceToHand / :750 handToEvidence / :778 handToFileBottom /
  :817 useEventFromHand / :1014 handAddFromRemove / :1057 removeAreaToDeckTop

## 影響
CPU (opp) 所有キャラの triggered/declared 効果で該当 atom が解決されるとき、
pick 候補が逆側 zone から列挙される。例外は出ず silent 誤動作。

## 対応方針
1 site ずつ「owner=opp + side 非対称 fixture (両 zone に異名カード)」の probe を先に書き、
赤→相対値化→緑 を確認して修正。一括置換は挙動変更範囲が読めないため行わない。
