## 概要

カードが **効果/能力によって登場** (reanimate / sceneEnter / sceneSwitch atom 経由) したとき、
その登場キャラ自身の **【登場時】(trigger hook:'enter', selfOnly:true)** が **発火しない**。

rules/17:「【登場時】キャラが現場に登場したときに発動。**能力/効果による登場でも発動**」に違反。

## 根本原因 (RCA)

`selfOnlyMatches` (listeners/triggered.ts) は scene カードについて **`source.uid === card.uid`** で一致判定する。

- **手札使用 / ネクストヒント登場** (hand-use-card.ts / next-hint.ts): enter emit の source = `{uid: 登場キャラ uid, cardId}` →
  selfOnly 一致 → 【登場時】発火 ✓。
- **効果/能力による登場** (atom-handlers.ts sceneEnter:768 / sceneSwitch:797): enter emit の 4th arg = **`ctx.source`**
  (= 登場を引き起こした能力の所有カード)。よって `source.uid` = 原因カード uid ≠ 登場キャラ uid → **selfOnly 不一致 → 不発火**。

## 経験的確認 (diag、2026-06-15)

- DIAG: SRCLV5(lv5) の ability で B01021 (【登場時】draw) を sceneEnter atom 経由で登場 → hand 0→0 / pendingEffects 0 = **不発火**。
- DIAG2: 同 B01021 に対し enter を **source={登場キャラ uid}** で手動 emit (viaEffect=true) → **draw 1 = 発火** (条件ロジックは正)。
- 既存 akamajutsu test (B07031 a1 登場時) は `runEffect(d, a1.effect!, ctx)` で **effect を直接駆動**し enter hook を踏まない → 本 bug を覆わない。

## 影響範囲

- shipped の **任意の【登場時】キャラが reanimate/効果登場された場合**、その登場時能力が無音で不発 (live 影響)。
  MVP デッキ (CT-D08/D11) での実発生有無は未 audit (要決定論調査: どの reanimate/summon カードが【登場時】持ちを登場させるか)。
- cluster11 (B01014/B01015/B01021/B07019 = enterSource。**効果登場を必須要件とする**) は本 bug に **block** される。

## 修正方針 (案、未実施 — 高リスク広域変更のため専用クラスタ)

- sceneEnter/sceneSwitch atom の enter emit の **source を登場キャラ** (`{player: enterPlayer, uid: newChar.uid, cardId}`) に変更し、
  原因カードは payload (`sourceCardId`、cluster11 で設計済) で運ぶ → selfOnly 一致 + enterSource 両立。
- ⚠ これにより **全ての効果登場キャラの【登場時】が新たに発火** → 既存カード挙動が広く変化 + smoke baseline 移動の可能性大。
  full 敵対設計レビュー + 全 enter listener (非 selfOnly / triggerCharMatches / 疾風) の水平展開 + smoke 再 bless が必須。
- 同クラスタで cluster11 (enterSource + 4枚) を同時出荷 (両者は coupled)。

## 防止策

- 【登場時】の挙動テストは **enter hook 経由** (event.emit('enter') or 実 atom) でも 1 本書く (runEffect 直叩きだけにしない)。
- enter emit の source 規約 (= 登場キャラ) を全 emit 箇所で統一し、原因カードは payload で運ぶ。
