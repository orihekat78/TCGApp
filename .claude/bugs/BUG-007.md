## 期待動作

各カードの triggered ability (`trigger.hook`) が発火条件成立時に effect 解決される。

## 実動作

大半のカード効果が無反応。

## 水平展開

Phase 5 / Round 1-3 で追加された全 47 cards の triggered ability すべて影響。AI smoke で気づけなかった理由: AI policy が effect resolution を直接駆動するパス (hirameki/misread のみ) のみ test されていた。

## 防止策

Round 4b で `src/engine/listeners/triggered.ts` 新規 + 7 hook 配線 (本 commit 実施済)。各カードの trigger.hook を listener 側に網羅する仕組み (カード追加時のチェックリスト spec 化、BUG-004 + card-addition-checklist.md 参照)。

## 修正

Round 4b commit (本セッション): `src/engine/listeners/triggered.ts` 実装。collectCardsInPlay で scene + partner + case + hand の全カードを scan、各 ability.trigger.hook を check し、scope / selfOnly / matcher 合格分の effect を pendingEffects へ queue。`event.queue` を経由するため `runAllUntilEmpty` で resolver が処理。

handUseCard / next-hint の emit payload も `'event-use' | 'character-use'` に分離 (eventRemoveByAP 等の matcher 整合)。

**残課題**: 47 cards の triggered ability が実際に動作するか Playwright で実機検証は次セッション。BUG-005 と同様に戦略的プレイで個別確認予定。
