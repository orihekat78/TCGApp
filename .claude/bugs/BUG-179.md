# BUG-179: filter 無し triggerCharMatches — 「現場にいるキャラが〜したとき」がパートナーにも誤発火

## 期待動作
印字「(自分/相手の) 現場にいるキャラが推理/アクションしたとき」はパートナーの行動では発火しない
(パートナーは現場のキャラではない、rules/06)。

## 実動作
cond/eval.ts の triggerCharMatches は `cond.filter` が無いと payload.player のみ照合し
scene 走査 (partner uid 除外) を行わない。partner 推理/アクションの emit (uid='partner:*') でも
発火していた。B02026 refutation (2026-06-11) 後の正準 idiom = `filter:{}` 付与だが、
それ以前出荷の 4 枚が anti-pattern のまま残存: **B05080 / B03096 / B08034 / D04007**。

## 発見経緯
miniwave consumer B01045 の verify lens が同型を NOT_EQUIVALENT で棄却 → 水平 grep で shipped 4 枚検出。

## 修正
4 枚に `filter: {}` 追加 (scene 走査強制)。回帰 = miniwave probe の partner-negative test。

## 水平展開
- `grep "triggerCharMatches', side" src/cards | grep -v filter` = 0 (全数修正済)。
- 防止策: hybrid finish.cjs idiomLint に「triggerCharMatches に filter 無し」warn を追加候補 (次 batch)。
