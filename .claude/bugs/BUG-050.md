## ユーザー指摘

> #4: 先攻のときファイル数が７以上なのに解決編にならない
> #16: 先攻の時、パートナーカードのアシスト込みだったら解決編になるんだけど
> オートフェイズでファイルが７枚以上になっても解決編にならないんだよね。

## 期待動作

rules/13 + rules/25:
- FILE 7 枚以上 (アシストパートナー含む) で **必ず** 事件編→解決編に移行
- 公式 Q&A: 「アシスト後、FILE 7+ 条件達成時、解決編にしないことは不可」
- アシスト経由でも auto-phase 経由でも、FILE 加算先のいかなる path でも適用

## 実動作 (修正前)

`src/engine/mutate/partner.ts:51 assist` に FILE >= 7 check はあるが、
`src/engine/mutate/file.ts:15 addFromDeckTop` (auto-phase で呼ばれる) に
check がなかった:

```ts
function addFromDeckTop(s: GameState, p: Player, n: number): void {
  for (let i = 0; i < n; i++) {
    const d = s.players[p].deck;
    if (d.length === 0) break;
    const cardId = d.shift();
    if (cardId === undefined) break;
    const card: FileCard = { type: 'card-back', cardId };
    s.players[p].file.push(card);
  }
  // ← rules/13+25 の解決編移行 check がない
}
```

呼び出し元:
- `src/engine/flow/auto-phase.ts:75` (オートフェイズで毎ターン FILE +2 / 先攻初手 +1)
- `src/engine/effect/atom-handlers.ts:110` (カード効果で FILE 加算する atom)

このため、先攻オートフェイズで FILE が 6 → 7 に到達しても、`assist` 経由で
ないため解決編に移行しない。「アシスト込みだと OK」というユーザー観察と一致
(assist 経由は L57 で check 通過)。

## RCA (Root Cause Analysis)

Round 4a で BUG-008 (UI assist 経路で解決編移行しない) を修正した際、
`assist` mutator 内に check を移動して全 caller (AI / UI) で適用される
ようにした。しかし「FILE 加算 = 解決編 trigger 候補」の汎用 invariant に
昇格させず、`addFromDeckTop` への波及を見逃した。

CLAUDE.md「水平展開調査必須」運用に従えば本来 Round 4a で同時に修正されて
いるべきだったが、「assist 内」と局所的に scoping したのが gap の原因。

## 修正

`src/engine/mutate/file.ts`:

```ts
function addFromDeckTop(s: GameState, p: Player, n: number): void {
  for (let i = 0; i < n; i++) {
    const d = s.players[p].deck;
    if (d.length === 0) break;
    const cardId = d.shift();
    if (cardId === undefined) break;
    const card: FileCard = { type: 'card-back', cardId };
    s.players[p].file.push(card);
  }
  // user_request 20260522_01 #4/#16 fix: FILE 7 枚以上で事件編→解決編 自動遷移
  // (rules/01 + rules/13 + rules/25)。assist() に同等 check があるが、
  // auto-phase の addFromDeckTop は経由しないため独立で必要。
  if (s.players[p].case.status === '事件編' && s.players[p].file.length >= 7) {
    s.players[p].case.status = '解決編';
  }
}
```

## 水平展開

- `insertAssistedPartner` (assist 経路) は既に `assist()` mutator 側で check
  済 → 影響なし
- atom-handlers L110 `deckToFile` 系 atom も本修正で自動恩恵
- 全 FILE 加算 path がカバーされる
- 既存テスト: 全 1530+ vitest PASS / smoke 1000 戦 0 exception

## 防止策

- 「FILE 加算」のような複数 caller を持つ mutator は、関連 invariant
  (本 case: rules/13+25 解決編移行) を mutator 内で実施する pattern を
  汎用化検討
- BUG-008 / 本 BUG / 類似 case (例: evidence 加算で勝利判定) も同 pattern
  で audit (Phase 3-A の audit に含める)
