# decision再開時のsource identity欠落

## 期待動作

人間のpick、skip、choice、optionalを再開しても、元効果の
`player / uid / cardId / abilityId / area / resolutionKind`をstackへ保持する。

## 実動作（修正前）

非continuation再開の`event.queue`がsourceを部分的に再構成した。
pick/skipは`uid / abilityId / area`、choiceは`abilityId / area`、optionalは`abilityId / area`を失った。
欠落した`area`はstack復元時にlegacy既定の`scene`へ変わった。

## RCAと修正

4つの再開分岐が同じsource契約を共有していなかった。
`resumedEntrySource`へ集約し、保存済み`PendingEffectSource`から完全tupleを復元する。
