## 仕様
現場キャラの AP＋XXXX / LP＋X 等の修正が、UI のカード下の数値に反映されて見えるべき
(プレイヤーが buff/debuff の有無を視認できる)。

## 実動作 (バグ)
`SceneArea.tsx` の `SceneCharacterCard` が `ch.apOverride ?? meta.ap` を表示していた。turn-scoped 修正
(charModifyAP scope:'turn' → `turnEffects.apMod_turn`) や continuous modifier は `apOverride` に入らず
`read.char.ap` でのみ合算されるため、**カード表示は印字 base 値のまま** (例: 横溝重悟 AP＋2000 後も 4000 表示、
有効値は 6000)。

## 修正
- `SceneArea`: `resolveCharStats?: (uid) => { ap; lp }` prop を追加 (read.char.ap/lp 由来の有効値)。
  `SceneCharacterCard` は `stats?.ap ?? ch.apOverride ?? meta.ap` を表示し、印字 base (meta.ap) と異なれば
  `.modified` クラス + `data-mod`(up/down) を付与。
- `Playmat`: `resolveCharStats={(uid)=>({ ap: readChar.ap(state,uid), lp: readChar.lp(state,uid) })}` を配線
  (self/opp 共通の PlayerArea 経由で両者に適用)。
- `SceneArea.css`: `.modified` を bold + glow、`[data-mod=up]` 緑 (#51e08a) / `[data-mod=down]` 赤 (#ff6b6b)
  で着色 (buff=緑 / debuff=赤)。apOverride (元の AP を N にする) も base と異なるため modified 扱い。

## 効果範囲 / 水平展開
- 現場の全キャラ表示に適用 (self/opp 両側)。charModifyAP/LP・apOverride/lpOverride・continuous modifier いずれも反映。
- partner-area / hand の数値表示は対象外 (修正対象は現場キャラ。partner LP buff が出たら別途検討)。
