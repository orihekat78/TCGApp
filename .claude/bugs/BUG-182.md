# BUG-182: chain passthrough + tryRePickFromAtom の side 二重解決

## 期待動作
opp 所有カードの chain 内 `handAddFromRemove` 等 short-form pick は owner 相対で
opp 自身のエリアを列挙・変異する。

## 実動作
chain は resolve-picks.ts:727 で pre-walk passthrough → runtime tryRePickFromAtom で
atomHandAddFromRemove が `p=resolvePlayer('self',ctx)='opp'` で buildShortFormPick し
query.side='opp' (**絶対値**) を積む → candidates.ts:129 sidesForQuery が owner(=opp)
相対で **再解釈** し oppSide('opp')='self' に反転。候補は self 側から拾われ mutate は
opp 側を叩くため add 不発 + discard が self.hand のカードを opp.remove へ複製 (state 破損)。

## 再現
tests/cards/m1-megasweep/B03078.manual.test.ts (現状 lock の documentation test)。

## RCA
非 chain の short-form は resolveEffectPicks が atom を直接 walk して query.side=literal
'self' を積むため sidesForQuery が正しく解決する。chain 経由だけ「絶対値を相対再解釈」の
二重解決になる。

## 修正案
sidesForQuery の二重解決を止める or atom 側 pre-resolve を抑止 (どちらか一方に統一)。
