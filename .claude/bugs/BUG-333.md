# deck look remainder refresh checkpoint

## 期待動作

デッキ上のカードを見て1枚まで手札に加え、残りをリムーブする効果では、
見ている間はカードがデッキにある。選択カードを加えた時点ではなく、
残りをリムーブへ移し終えた時点でdeck 0を判定しrefreshする。

## 修正前

- `handAddFromDeck`が最後の1枚を加えると即refreshした。
- 選択カードだけで残り0枚の場合、`boundToRemove`はrefreshしなかった。
- B09078/B07015は条件付きdiscardを残り移送より先に実行した。
- B08050の既存matched証拠は登録/direct deck-threeのみで境界を未検証だった。

## RCAと修正

- CardDef 23件が既存の正しいB10082契約を使っていなかった。
- 対象`handAddFromDeck`へ`deferRefresh:true`を追加。
- 対応`boundToRemove`へ`refreshAfter:true`を追加。
- B09078/B07015を印字順のadd→remainder/refresh→discardへ修正。
- runtime CardDef invariantで24 shipped descriptorを横断検査。

## 回帰

- Wave51 10カードを全public routeでdeck 1/2/3 positive selectionとdecline。
- 決定前はdeck不変、refresh/evidence 0。
- `effect:boundToRemove` log後にのみ`refresh`、refreshCount 1、相手証拠1。
- B09078/B07015はdiscard札がrefreshへ戻らないことを別probeで確認。
