## ユーザー指摘

> #3: ログではカード名も記載するようにしてください

## 期待動作

`LogPanel` の log entry で target が cardId (例: `D08025`) のとき、
カード名 (`蘭の一撃`) を併記する。

## 修正

### `src/ui/components/LogPanel.tsx`

`formatTarget(target)` helper を追加:
- target が `D\d{2}\d{3}` cardId pattern にマッチ → `cardIdToDisplayName`
  で名前解決
- 名前解決成功時 → `${name} (${cardId})` 形式 (例: `蘭の一撃 (D08025)`)
- 失敗時 (cardId 未登録) → cardId そのまま素通し
- cardId pattern にマッチしない target (uid 等) → 素通し

レンダリング時に `<span className="log-target">→ {formatTarget(e.target)}</span>`
へ差し替え。

## 補足

- target が SceneCharacter uid (e.g., `self-1`) の場合は cardId pattern に
  マッチしないため素通しになり、後続改善で uid → cardId → name 解決を
  検討可能 (本 BUG では cardId 表示のみで対応)
