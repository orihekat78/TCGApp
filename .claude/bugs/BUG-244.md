## ユーザー報告

正式 mobile viewport (851x393 landscape) の長い候補一覧で、CutIn/Disguise、Misread、Hirameki picker の操作を常に表示・操作できるようにする。

## 期待動作

shell は viewport 内、header と最終 action は固定、候補 body だけが scroll する。action は 44px 以上で、詳細を閉じても pending と元の選択順を維持する。

## 実際動作

CutIn/Disguise は modal 全体を scroll し、header/pass が流れ、pass は 44px 未満。Misread と Hirameki は短い高さの containment と body-only scroll、44px action footer がない。

## RCA (Root Cause Analysis)

3 modal は shell の flex-column/overflow hidden と body の min-block-size: 0 が無い。CID は shell 自体を overflow-y: auto にし、Misread/Hirameki は viewport 高を制約しないため、landscape で header/footer が候補本文と一緒に viewport 外へ移動する。

## 修正

RED: 実 mobile-chromium 851x393 の長い候補で、bounds、body scroll、scroll 後の固定 header/action、44px、詳細 close、pending/state/engine callback を検証する。

## 水平展開

同じ modal-stack cluster の BUG-241 対象は fixed flex shell 済み。今回の未適用 3 picker を同じ short-height 構造へ揃え、実 flow をそれぞれ確認する。

## 再発防止

special picker を追加・変更するときは、851x393 E2E で body-only scroll、固定 header/action、44px final action、詳細 close 後の resolution を必須にする。

## 検証

- RED: mobile 851x393 で CID pass viewport 外、Misread shell y=-18.5、Hirameki skip 35px。
- GREEN: focused modal unit 17/17、mobile Playwright 3/3、desktop Playwright 3/3、typecheck、lint、lint:bugs、diff check。
- Review remediation: B06032 の実listener長文を 851x393 で body scroll・header/skip固定として確認。desktop は既存 360px/420px min-width 契約を維持し、short-height media のみ幅制約を適用。
