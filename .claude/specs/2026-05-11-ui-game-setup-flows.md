# ゲーム開始時フロー (2026-05-11)

マリガン / 先攻決定 / オートフェイズ自動進行。

## マリガン (引き直し) — rules: [04](../rules/04-game-setup.md) §5

```text
1. 開始時に手札5枚 (rules/04 §4)
2. <MulliganModal> 表示:
   - 手札5枚を表示 (自分のみ可視)
   - 各カードクリックで「戻す対象」トグル選択 (赤枠マーク)
   - [シャッフル & 引き直し] ボタンでデッキ戻し→シャッフル→同枚数引き直し
   - [マリガンしない] ボタンで 0枚指定相当
3. 先攻プレイヤーが先に決定 → 後攻プレイヤーが決定
4. 1回のみ実施可能
```

**ポイント**: 戻すカードは自由選択。引き直すカードはシャッフル後のデッキトップから (選択不可)。

## 先攻/後攻決定 — rules: [04](../rules/04-game-setup.md) §3

```text
<TurnOrderDecisionModal>:
  - じゃんけん相当のランダム判定
  - 結果アニメ (「あなたが先攻です」等)
  - 勝った方が先攻 (rules/04 明記)
※ MVP は CPU 対戦中心なので一切ユーザー操作不要、即決定でもOK
```

## オートフェイズ自動進行 — rules: [05](../rules/05-turn-phases.md)

`<AutoPhaseSequenceOverlay>` で 4ステップを順次表示:

1. パートナーをアクティブ (FILEにアシスト中ならパートナーエリアに戻してアクティブ)
2. 現場のキャラをすべてアクティブ (スタン状態は代わりにスリープになるアニメ)
3. デッキから1枚引いて手札 (先攻1T目もドロー)
4. デッキから2枚を裏向きでFILEへ (先攻1T目のみ1枚)

**スキップ条件 (公式プレイシート明記)**:

- 手順①②は「できる状況でなければスキップ」
- 例: 1ターン目はパートナー・キャラに対する処理が初期状態なのでスキップ

各ステップに 0.4 秒のアニメを挿入。プレイヤー操作はロック (`UIState.lockedForResolution`)。

## ゲーム開始シーケンス全体

```text
[Title Screen]
  ↓ デッキ選択 (CT-D08 / CT-D11)
[VS CPU difficulty selection]
  ↓
[TurnOrderDecisionModal] 先攻決定
  ↓
両プレイヤーがデッキシャッフル + 手札5枚配布アニメ
  ↓
[MulliganModal] 先攻 → 後攻 の順
  ↓
事件・パートナーを表向き化アニメ
  ↓
「ゲームスタート!」演出 (1秒)
  ↓
[先攻プレイヤー 1ターン目]
  ↓
オートフェイズ自動進行 (上記4ステップ + スキップ条件適用)
  ↓
[メインフェイズ] (プレイヤー操作開始)
```
