# 効果スタック・痕跡 (2026-05-11)

ゲーム動的振る舞いの中で、効果の蓄積・解決順・痕跡フラグを定義。

## 効果スタック (pendingEffects) — rules: [15](../rules/15-abilities-effects.md), [25](../rules/25-qa-effects-resolution.md)

### 発火条件と解決順

```text
能力発火 → pendingEffects.push(effect)

解決順:
  1. 同タイミングで複数発火 → すべて同時発動扱い
  2. 同一プレイヤー所属 → 所有者が好きな順で解決
  3. 両プレイヤー所属 → ターンプレイヤー優先、それから非ターンプレイヤー
  4. 「〜の場合」「〜してもよい」は解決時に参照・選択
```

### 即時解決例外

以下は pendingEffects に積まず即解決:

- 「〜とき、(中略)**代わりに**〜」
- 「〜とき、(中略)**無効にする**」

### 行動中の発火扱い

- 行動中・効果解決中に発火 → 「未解決」状態で待機 → 完了後に解決
- 発火後・解決前に発火キャラが現場を離れても効果は無効にならない

### UI 表示

`<EffectStackPanel>` (TopBar 隣接):

- 未解決効果の件数バッジ
- クリックで一覧モーダル展開
- 各効果のソースカード・発火条件・所属プレイヤー
- 解決中はプレイヤー操作ロック (`UIState.lockedForResolution = true`)

## 痕跡 [発見済/未発見] — rules: [13](../rules/13-keywords.md), [26](../rules/26-qa-deck-refresh.md)

### 状態遷移

```text
初期: 両プレイヤー [未発見]
イベント: 相手プレイヤーがリフレッシュを行う
  → 自分の痕跡が [発見済] になる
[発見済]: このゲーム中ずっと維持
※ 自分のリフレッシュでは自分の痕跡は発見されない
```

### UI 表示

`<ScratchTraceIndicators>` (TopBar 内):

- 自陣: 「痕跡: 発見済 ★」 or 「痕跡: 未発見」
- 相手陣: 同様
- 発見済になった瞬間にハイライトアニメ

### カード効果との連携

- 「痕跡[発見済] のとき」効果はこのフラグを参照
- [未発見] 状態でも痕跡関連の選択肢は選べる (何も起こらないだけ)
