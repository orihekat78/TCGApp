# 非コンタクト系モーダル (2026-05-11)

ミスリード / ヒラメキ / 捜査 / スイッチ / カード詳細 / 領域展開。
コンタクト系は [ui-modal-flows-contact.md](2026-05-11-ui-modal-flows-contact.md)。

## ミスリード発動 (推理時) — rules: [13](../rules/13-keywords.md)

```text
自分の推理宣言時、相手側に <MisleadActivationModal>:
  - 相手のアクティブなミスリード持ちキャラ一覧
  - 「Yをスリープさせて LP-X 適用」/「発動しない」 (複数同時可)
  - 1回の推理に対し何枚でも同時発動可

LP-X 効果はその推理終了時まで継続
最終LP ≤ 0 なら証拠0枚
```

## ヒラメキ発動 (アクション[事件] リムーブ時) — rules: [10](../rules/10-action-event.md)

```text
相手の証拠最上部がヒラメキ持ち && アクション[事件]によるリムーブ
  → 相手側に <HiramekiActivationModal>:
  - 「ヒラメキを発動する/しない」
  - 発動すれば効果解決後、リムーブエリアへ
  - 発動しなくてもリムーブエリアへ

※ 解決中はまだリムーブエリアに置かれていない (リフレッシュシャッフル対象外)
※ 能力/効果によるリムーブではヒラメキ発動不可
```

## 捜査X (相手のデッキ操作) — rules: [13](../rules/13-keywords.md)

```text
捜査X発動 → 相手側に <SearchModal>:
  - 相手のデッキ上からX枚公開
  - 相手が好きな順番にデッキ下へ並べ替え (順番は見せる義務なし)
  - 公開されたカードは「発見された」状態として保持
  - その後の効果で「発見された」カードを参照可能

※ デッキX枚未満なら残り全部公開
```

## スイッチ対象選択 — rules: [20](../rules/20-color-and-switch.md)

```text
現場5枚 + 新キャラ登場 (または2枚以上同時で上限超過) → <SwitchTargetModal>:
  - 現場のキャラ一覧 (アクティブ/スリープ/スタン/名乗り 区別なし、全て選択可)
  - リムーブする枚数を選択

※ リムーブされるキャラは「能力によるリムーブ」扱い
※ 名乗り状態のキャラもリムーブ可
```

## カード詳細モーダル

```text
任意のカードをクリック (盤面・手札・リムーブ・証拠展開内) → <CardDetailModal>:
  - フルサイズカード画像
  - 効果テキスト全文 (エラッタ後)
  - カード固有Q&A (あれば)
  - 現在状態 (回転・名乗り・セット・重ね・付与能力・無効化能力)
  - APLP/レベルの実効値 (override 反映)

※ 裏向きカードはクリックしてもこのモーダル出ない (中身不可視のため)
```

## 領域展開モーダル

```text
証拠/リムーブ/FILE/デッキ をクリック → 各種ExpandModal:
  - 自分の証拠: 裏向きで一覧 + 由来情報 (ターン・推理元) 表示
    ※ 自分も中身は基本不可視。表向き化されたカードのみ画像表示
  - 相手の証拠: 枚数 + 由来のみ可視 (内容不可視)
  - リムーブ: 表向きで全件
  - FILE: 裏向き横向き全件 + アシスト中パートナーは表向き
  - デッキ: 残量のみ (内容は通常不可視)
```

## 「〜してもよい」選択モーダル — rules: [15](../rules/15-abilities-effects.md)

```text
効果テキストが「〜してもよい」型 → <OptionalEffectModal>:
  - 効果の説明文
  - [効果を発動する] / [発動しない]
  - 解決時に選択 (発動時ではない)
```

## 「〜枚まで選び」マルチ選択 — rules: [15](../rules/15-abilities-effects.md)

```text
効果テキストが「キャラを〜枚まで選び」 → <TargetMultiSelectModal>:
  - 対象候補ハイライト (どちらの現場のキャラでも、自身も選べる)
  - 0枚〜N枚 選択可
  - 「決定」で確定 → 効果解決
```
