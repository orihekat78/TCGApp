# エッジケース集 (2026-05-11)

ハッピーパス外の挙動。UI実装時にテストで必ず通すこと。

## ① 0枚エッジケース

| ケース | 挙動 | 出典 |
|-------|------|------|
| 手札0 | 手札使用/NHのカード選択肢が空 → 行動不可 | — |
| デッキ0 | リフレッシュ自動発動 → リムーブ0なら敗北 | [14](../rules/14-refresh.md) |
| 現場0 | 推理・アクション不可 (パートナーで推理は可) | [11](../rules/11-reasoning.md) |
| 相手証拠0 | アクション[事件]の対象不可 | [10](../rules/10-action-event.md) |
| FILE0 | NH不可 / Lv1以上のカード使用不可 | [12](../rules/12-next-hint.md) |
| リムーブ0 + リフレッシュ要 | 即敗北 (gameResult.reason='deck-out') | [14](../rules/14-refresh.md) |

## ② 不可逆操作

| 操作 | 不可逆性 | UI対応 |
|------|---------|-------|
| アシスト | 同ターン勝利不可 + FILE≥7で必ず解決編移行 | 強警告ConfirmModal |
| 事件解決 | ゲーム終了 | 勝利予告ConfirmModal |
| 解決編→事件編 | **不可** | スタンプ固定 |
| ネクストヒント | 同ターン手札使用不可化 | 警告ConfirmModal |
| カード変装 | 元キャラはデッキ下へ | 確認ConfirmModal |

## ③ 名乗り状態 + キーワード例外

| キャラの状態 | 推理 | アクション | 宣言能力 | ガード |
|-------------|------|----------|---------|-------|
| 名乗り + なし | ✗ | ✗ | ✓ | ✓ |
| 名乗り + 迅速 | ✓ | ✓ | ✓ | ✓ |
| 名乗り + 突撃 | ✗ | ✓ | ✓ | ✓ |
| 名乗り + 突撃[キャラ] | ✗ | キャラのみ | ✓ | ✓ |
| 名乗り + 突撃[事件] | ✗ | 事件のみ | ✓ | ✓ |

突撃で開始したアクション → ターン途中で突撃失っても進行中アクションは継続 ([22](../rules/22-qa-action-contact.md))。
名乗り状態で突撃のみキャラがアクション後アクティブ化 → 推理不可 ([24](../rules/24-qa-naming-stun.md))。

## ④ 数値マイナス・下限

| ケース | 挙動 |
|-------|------|
| LP ≤ 0 で推理 | 証拠0枚 (推理自体は実行・スリープ化はする) |
| AP ≤ 0 でアクション | コンタクト発生・AP判定で負ければ何も起こらない |
| AP/LP/レベル下限なし | マイナスでもキャラはリムーブされない |
| 「元のAP/LPを0」 | 元数値0扱い + 他効果の +/- 修正は残る |

## ⑤ 状態相互作用

**スタン状態 特殊** (rules/03,24): アクティブにする効果→代わりにスリープ。スリープ/スタン効果→スタンのまま。

**同時リムーブと条件参照** (rules/25): 効果解決時の盤面を参照する設計。

**コンタクト中の現場離脱** (rules/08,22): ガード前離脱→アクション即終了。コンタクト中離脱→コンタクト終了処理まで進める。

## ⑥ 複数名カード — rules: [19](../rules/19-special-rules.md)

```text
《江戸川コナン&工藤新一》= 3つのカード名すべてを持つ
影響: 【絆 工藤新一】効果が有効、カード名指定の効果が両方マッチ、《江戸川コナン》と両方下に重ね不可
適用: 「&」「( )」「『 』」表記のみ
```

## ⑦ 効果スタックのエッジ — rules: [15](../rules/15-abilities-effects.md), [25](../rules/25-qa-effects-resolution.md)

- 同時発動 → 同所有者なら好きな順、両プレイヤーならターンプレイヤー優先
- 「〜の場合」効果 → 解決時に条件参照 (発動時ではない)
- 「〜してもよい」効果 → 解決時に選択モーダル
- 「代わりに〜」「無効にする」 → 即時解決 (スタックに積まない)
- 効果発動キャラの離脱 → 効果は無効化されない

## ⑧ リフレッシュ細則 — rules: [14](../rules/14-refresh.md), [26](../rules/26-qa-deck-refresh.md)

| 効果テキスト | デッキ不足時 |
|------------|------------|
| カードを引く / 証拠を得る / FILEに置く | リフレッシュ後に残り解決 |
| 上から○枚見る / 公開 | リフレッシュしない。残り枚数で解決 |
| 上から○枚リムーブ | 可能な限りリムーブ後リフレッシュ。残り分はリムーブしない |
| ○枚リムーブしてもよい (コスト) | デッキ○枚未満なら能力使用不可 |

## ⑨ 痕跡 / アシスト+解決編

痕跡: 相手リフレッシュのみがトリガー、自分のリフレッシュでは発見されない、[未発見]でも選択可。
アシスト+FILE7枚 → 必ず解決編移行 (移行させない選択不可) ([25](../rules/25-qa-effects-resolution.md))。
