# コンタクト関連モーダル (2026-05-11)

コンタクト処理 + カットイン + 変装 + ガード判定。
非コンタクト系モーダル (ミスリード/ヒラメキ/捜査/スイッチ等) は [ui-modal-flows-other.md](2026-05-11-ui-modal-flows-other.md)。

## コンタクト処理全体 — rules: [08](../rules/08-contact.md), [09](../rules/09-cutin-disguise.md), [22](../rules/22-qa-action-contact.md)

```text
コンタクト発生
  ↓
行動順確認:
  - AP低い側が1番目、高い側が2番目
  - AP同じなら非ターンプレイヤーが1番目
  ↓
<CutInDisguiseChoiceModal> 1番目用: [カットイン] [変装] [パス]
  ↓ 行動 / パス
<CutInDisguiseChoiceModal> 2番目用: 同上
  ↓
1番目がパスして2番目が行動した場合のみ → 1番目に再行動権 (1回のみ)
  ↓
AP判定:
  - アクション側AP ≥ 相手AP → 相手リムーブ (同値でもリムーブ)
  - アクション側AP < 相手AP → 何も起こらない
  - 「コンタクトによってリムーブされない」フラグ持ちはAP判定リムーブ免疫
  ↓
コンタクト終了 (カットインAP+効果は切れる)
  ↓
※ 「コンタクトを発生させる」効果によるコンタクトはここで終了。アクション終了処理に進まない
  ↓
アクション終了 (終了時能力発動・効果切れ)
```

## カットイン詳細 — rules: [09](../rules/09-cutin-disguise.md), [23](../rules/23-qa-disguise-cutin.md)

```text
[カットイン] 選択 → 手札からカットイン持ちカードをクリック
  → カットイン2つ以上持つカードなら効果選択モーダル (効果は1つだけ選択)
  → 効果適用 → カードはリムーブエリアへ
  → コンタクト中の効果として登録 (終了時に切れる)

制限:
  ※ 1コンタクトにつき1回(1枚) まで使用可 (2枚以上は不可)
  ※ 1枚のカードが持つカットイン効果が複数あっても、選べるのは1つ
  ※ 自分の事件と異なる色のカットインも使用可能 ([20](../rules/20-color-and-switch.md))
```

## 変装詳細 — rules: [09](../rules/09-cutin-disguise.md), [23](../rules/23-qa-disguise-cutin.md)

```text
[変装] 選択 → 手札から変装持ちキャラをクリック
  → コンタクト中のキャラと入れ替え
  → 元キャラ: 裏向きでデッキ下へ
  → 入れ替わったキャラ: コンタクト続行

引継ぎ:
  ✓ スリープ状態
  ✓ 受けている効果 (AP/LP増減・ターン終了時リムーブ・コンタクト免疫)
  ✓ セット/重ねカード
  ✗ カード名・色 (新カードのもの)

発動:
  ✗ 【登場時】能力 (変装は登場ではない)
  ✓ 【変装時】能力 → <OptionalEffectModal> で「発動する/しない」選択可

※ 元キャラはリムーブされていない → 【現場リムーブ時】も発動しない
```

## ガード判定 (相手の応答) — rules: [07](../rules/07-action-flow.md)

```text
攻撃宣言の瞬間、相手側に <GuardSelectionModal>:
  - 自分のアクティブキャラ一覧 (名乗り状態でも可、APは不問)
  - [このキャラでガード] / [ガードしない]
  - 攻撃側がブレット持ちなら「ガード不可」表示でモーダル省略

選択キャラ → スリープ → コンタクト発生 (ガードキャラ vs 攻撃キャラ)
ガードしない → 元の対象でコンタクト発生 (対象=事件なら証拠処理)
```
