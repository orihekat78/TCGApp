## abilities

### a1【パートナー青】 突撃 (常時付与)

- type: continuous, condition: `{ kind: 'partnerColor', color: '青' }`, scope: on-scene
- effect (continuous): `keywords += ['突撃']` while condition true
  - 実装: `engine.read.char.keywords` の selector で condition を評価し動的合算
- ⚠ 条件失効時: 突撃失効 (rules/24)。ただし開始済アクションは継続 (rules/22)

## patterns

- **partnerColorKeyword** (D08009/10, D08022, D11011, ほか): 【パートナー色】 → 単純キーワード付与
- 多発予想 → 強い候補 → cards/_shared/partnerColorKeyword.ts

## エッジ

- パートナー色 ≠ 青 (相手側パートナー視点 etc): 突撃なし
- LP=0: 推理しても証拠0枚 (rules/11)。アタッカー専用
