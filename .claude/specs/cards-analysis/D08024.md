# D08024 「あら…頼もしいじゃない…」 (イベント)

## 公式情報

- カードNo: D08024
- 種別: イベント
- 色: 青
- レベル: (要確認、典型的に5以下)
- レアリティ: D
- 公式テキスト:
  > 自分のリムーブエリアにあるレベル5以下の〚カード名［阿笠博士］〛かレベル5以下の〚特徴［少年探偵団］〛のキャラを1枚まで選び、登場させる。
  > 〚特徴［少年探偵団］〛のキャラを1枚まで選び、ターン終了時までAP＋2000する。
- ヒラメキ:
  > 【ヒラメキ】（証拠からリムーブされるときに発動する）カードを1枚引く。

## 能力分解

### a1 メイン効果 (使用時)

- type: triggered
- trigger: `{ hook: 'effect:declared', matcher: payload => payload.cardId === 'D08024' }`
  - イベントカード使用 = effect:declared 相当
- scope: on-hand (発火後 mainEffect 解決 → リムーブエリアへ自動)
- effect:
  ```typescript
  { kind: 'sequence', steps: [
    // ① リムーブエリアから登場
    { kind: 'choice', chooser: 'owner', options: [
      { kind: 'atom', verb: 'sceneEnter',
        args: { player: 'self', cardId: '$pick', viaEffect: true,  // 色制限なし (rules/20)
          target: { kind: 'pick',
            query: { area: 'remove', side: 'self',
              filterAny: [
                { cardName: '阿笠博士', levelMax: 5 },
                { trait: '少年探偵団', levelMax: 5 }
              ] },
            n: { min: 0, max: 1 }, chooser: 'owner' } } } ] },
    // ② AP+2000 (ターン終了時まで)
    { kind: 'choice', chooser: 'owner', options: [
      { kind: 'atom', verb: 'charModifyAP',
        args: { uid: '$pick', delta: 2000, scope: 'turn',
          target: { kind: 'pick',
            query: { area: 'scene', side: 'either', filter: { trait: '少年探偵団' } },
            n: { min: 0, max: 1 }, chooser: 'owner' } } } ] },
  ] }
  ```
- ruleRefs: rules/20 (色制限例外: 効果による登場), rules/19 (キャラ種別)

### a2 ヒラメキ

- type: icon-flash
- scope: on-evidence
- trigger: `{ hook: 'evidence:remove-by-action' }` ※自分の証拠が対象であることを matcher で確認
- effect: `{ kind: 'atom', verb: 'draw', args: { player: 'self', n: 1 } }`
- ruleRefs: rules/10 (ヒラメキ発動条件)

## エンジンAPI 表現可否

- ✅ effect.kind: 'custom' 不使用
- ✅ TargetQuery.filterAny で OR 条件カバー (cardName OR trait)
- ✅ 0枚選択可 (n.min=0)
- ✅ ヒラメキは別 ability として `icon-flash` で対応

## 共通パターン候補

- **eventReanimate**: リムーブエリアから条件付きで登場 → 同種出現次第 `cards/_shared/`
- **eventBuffAP**: 特徴Xのキャラに AP+ (ターン終了時まで) → 同種出現次第

## エッジケース

- リムーブエリアに該当カード0枚: 0枚選択可 (rules/15) → ① スキップ
- 現場が5枚埋まり登場できない: スイッチ不要なら登場不可 → 0枚選択でスキップ
  - スイッチ可なら別ロジック (このカード文では「スイッチ可」明記なし → 不可と解釈)
- 現場特徴[少年探偵団] 0枚: AP+ 対象 0枚 → ② スキップ
- ヒラメキ解決中にリフレッシュ発生: 該当カードはまだリムーブにない (rules/10) → シャッフル対象外
- 「能力/効果でリムーブ」の場合はヒラメキ不発動: trigger を `evidence:remove-by-action` のみに限定済 (rules/10)
