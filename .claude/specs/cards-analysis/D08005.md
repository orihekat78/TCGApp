no D08005/D08006 | キャラ | 青 | Lv7 | AP6000 | LP1 | 特徴[少年探偵団,科学者]
> 【自分ターン中】自分の表向きの証拠1つにつき、このキャラをAP＋1000する。
> 【宣言】【ターン1】〚裏向きの証拠を1つ表向きにする〛：ターン終了時までこのキャラは〚突撃〛（登場したターンからすぐにアクションできる）を持つ。

## abilities

### a1 自分ターン中 表向き証拠数だけ自身AP+

- type: continuous (rules/24, 25 — 常時有効型)
- condition: `{ kind: 'turn', player: 'self' }`
- scope: on-scene
- effect (continuous なので動的計算): self.AP += `engine.read.player.evidence(s,'self').filter(e=>e.faceUp).length * 1000`
- 実装: continuous は AbilityDef に `effect` を入れず `selfBuff` 系の専用フィールドが必要 → **G23**: `AbilityDef.continuousModifier?: (s, ctx) => Modifier[]` 追加検討
- 暫定: `engine.read.char.ap` の計算ロジックにこの修正を反映 (selectorで合算)

### a2【宣言】【ターン1】 証拠表向きで自身突撃

- type: declared, limit: turn1, cost: `{ kind: 'flipFaceUpEvidence', n: { min:1, max:1 } }`
- effect: `{ kind:'atom', verb:'charGrantKeyword', args:{ uid:'$self', kw:'突撃', scope:'turn' } }`
