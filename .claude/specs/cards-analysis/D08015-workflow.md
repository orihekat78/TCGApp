## 効果テキスト (公式)

> 【登場時】カードを1枚引き、手札を1枚リムーブする。
> 【カットイン】AP＋1000

## アビリティ構造

- **a1** (triggered): `trigger.hook: 'enter'` + `selfOnly: true` → 登場時に発動
- **a2** (cutin): `cutinFixedAP({ delta: 1000 })` — コンタクト中の AP+1000

## a1 登場時効果

```text
[ 登場 ]
   │
   ▼
[ step 1: 1 ドロー ]
   │
   ▼
[ step 2: 手札から 1 枚リムーブ ]
   │
   ▼
[ a1 完了 ]
```

> **変装による登場では a1 は発動しない** — rules/09 「変装は『登場』ではない」より `enter` hook 自体が発火しないため、triggered listener も呼ばれない。
>
> **登場経路 (手札使用 / ネクストヒント / 効果による登場 / スイッチ) は a1 の挙動に影響しない** — 全経路がエンジン内部で `enter` hook 発火に集約されており、カード視点では「現場に登場した」事実のみが意味を持つ。
>
> **step 1 ドローのデッキ 0 枚処理 (リフレッシュ → リムーブ 0 なら敗北、rules/14) は `draw` atom の責務** — カード固有の挙動ではないため本図には含めない (BUG-036 で配線済)。
>
> **step 2 リムーブの選択者分岐 (human → EffectPickerModal / AI → heuristic) は engine 内部の `resolve-picks` の責務** — 同じく本図には含めない (BUG-053 / BUG-054 で配線済)。

### a1 エンジン処理フロー (詳細)

カード視点では `[ 登場 ] → [ 1 ドロー ] → [ 1 リム ] → [ 完了 ]` だが、エンジン内部では以下のように処理される (参考):

```text
[ D08015 が現場に出る ]
   │ 出方は 4 通り:
   │   ・ 手札からそのまま使う
   │   ・ ネクストヒントの 2 段階目で使う
   │   ・ 他カードの効果で現場に呼び出される
   │   ・ 現場 5 枚到達時に既存キャラと入れ替わる (スイッチ)
   ▼ どの経路でも、ここからは同じ処理になる
[ 現場にカードを置く ]
   │ 名乗り状態フラグを ON、何番目に出たかを記録する
   ▼
[ 「キャラが登場した」というイベントを全カードに通知 ]
   │ 通知の中身: 登場したカードの ID、効果経由かどうか、登場順番
   ▼
[ 登場時能力を持つカードがいないか全エリアをチェック ]
   │ 現場 / パートナーエリア / 事件エリア / 手札 を全部 scan
   ▼
[ D08015 の a1 が「登場した本人なので発動する」と判定される ]
   │ 条件: 「自分自身が登場した時だけ反応するフラグ」が ON
   ▼
[ 効果テキスト内の「プレイヤーに選ばせる箇所」を先に解決しておく ]
   │ AI なら自動で選択、人間なら「選択待ち」にして処理を一時停止する
   ▼
[ 効果を「あとで処理するリスト」に登録 ]
   │
   ▼
[ 「あとで処理するリスト」を上から順に実行 ]
   │
   ├─▶ step 1: 「デッキから 1 枚引く」処理を呼ぶ
   │       │
   │       ▼ デッキは 0 枚か?
   │       │
   │       ├── 0 枚 ──▶ リフレッシュ処理 (rules/14)
   │       │             │
   │       │             ├── リムーブも 0 枚で失敗
   │       │             │      └─▶ 自分の敗北を確定 (相手の勝利として記録)
   │       │             │            理由ラベル: deck-out (BUG-036 配線)
   │       │             │
   │       │             └── 成功 ─▶ リムーブを全部シャッフルしてデッキに戻す
   │       │                          相手の証拠を 1 枚増やす
   │       │                          引く処理に戻ってもう一度試す
   │       │
   │       └── 残あり ─▶ デッキの一番上を 1 枚手札に追加
   │
   └─▶ step 2: 「1 つだけある選択肢」を選ぶ (実質は実行確定)
           │
           ▼ 「手札から 1 枚をリムーブする」処理を呼ぶ
           │
           ▼ 「誰が選ぶか」で分岐
           │
           ├── 人間 ─▶ 「選択待ちフラグ」を立てる
           │            │
           │            └─▶ 手札選択モーダル (EffectPickerModal) を表示
           │                  │
           │                  └─▶ ユーザーが手札のカードをクリック
           │                        │
           │                        └─▶ 選択結果をエンジンに送り返す
           │                              │
           │                              └─▶ 処理対象を確定したカードに差し替え
           │                                    │
           │                                    └─▶ 「あとで処理するリスト」に再投入
           │
           └── AI ────▶ AI 用の「捨てる候補選び」ロジックで 1 枚を自動選択
           │
           ▼
[ 選ばれたカードを 手札 → リムーブ へ移動 ]
   │
   ▼
[ a1 の効果実行完了 ]
   │
   ▼
[ ログに「ドロー & リムーブ」アクションを記録 ]
   │
   ▼
[ Toast 表示 / 相手ターン中なら OppTurnOverlay の更新 ]
```

## a2 カットイン効果 (コンタクト中)

```text
[ アクション / コンタクト発生 ]
   │
   ▼
[ 手札の D08015 を カットインとして使用 ]
   │ (1 コンタクト 1 枚制限、rules/09)
   ▼
[ コンタクト中 actor の AP +1000 ]
   │
   ▼
[ コンタクト終了で modifier 解除 ]
```

### a2 エンジン処理フロー (詳細)

```text
[ アクション宣言 ]
   │ 攻撃する側のキャラと、攻撃対象 (相手キャラ / 相手の事件) を指定する
   ▼
[ ガード判定 ]
   │ 相手が「アクティブ状態のキャラでガードする」か「ガードしない」を選択
   ▼
[ 「コンタクト発生」イベントを全カードに通知 ]
   │ 通知の中身: 攻撃側キャラ、対象キャラ (またはガードキャラ)
   ▼
[ コンタクト中の「カットイン / 変装」のフェーズに入る ]
   │
   ▼
[ カットイン / 変装の選択モーダル (CutInDisguisePickerModal) を表示 ]
   │ 攻撃側の手札からカットイン使用可能なカードを列挙
   │ 自分の事件の色と合致するかチェック (rules/20)
   ▼
[ プレイヤーまたは AI が「D08015 をカットインとして使う」を選択 ]
   │
   ▼
[ D08015 を 手札 → リムーブ へ移動 ]
   │ rules/09: カットインしたカードは即リムーブされる
   ▼
[ D08015 専用の「AP +1000 効果」を起動 ]
   │ 効果の性質:
   │   ・ 種類: 持続効果 (continuousModifier)
   │   ・ 有効範囲: このコンタクトの間だけ (scope=contact)
   │   ・ 効果値: AP +1000
   │   ・ 効果先: 攻撃側キャラ (actor)
   ▼
[ 「現在有効な効果リスト」に登録 ]
   │
   ▼
[ 「このプレイヤーは今のコンタクトでカットイン使用済み」フラグを ON ]
   │ rules/09: 「1 コンタクトにつきカットインは 1 枚まで」の制限管理用
   ▼
[ AP 比較の時、攻撃側の最終 AP に +1000 を反映 ]
   │ 元の AP(2000) + 有効な効果の合算 = 3000 として比較される
   ▼
[ コンタクト結果判定 (AP 比較で対象キャラをリムーブ / 維持を決定) ]
   │
   ▼
[ 「コンタクト終了」イベントを全カードに通知 ]
   │
   ▼
[ 持続効果が自動で解除される ]
   │ 「有効範囲=コンタクト中」に紐づいていたため、コンタクト終了で自動的に外れる
   ▼
[ カットイン使用済みフラグは保持され、次のコンタクト開始時にリセットされる ]
```
