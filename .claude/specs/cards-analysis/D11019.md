# D11019 15の受難 (イベント)

## 公式情報

- カードNo: D11019
- 種別: イベント
- 色: 黄
- レベル: (確認要)
- レアリティ: D
- 公式テキスト:
  > 自分のデッキのカードを上からレベル4以下の【黄】のキャラが出るまで1枚ずつ公開し、それを登場させる。
  > 残りの公開したカードをデッキの下に移し、デッキをシャッフルする。
  > 自分のリムーブエリアに【黄】のカードが20枚以上ある場合、ターン終了時までそのキャラに〚突撃［事件］〛（名乗り状態でもアクション［事件］できる）を持たせる。
- カットイン:
  > 【カットイン】AP＋1000（コンタクトに手札からリムーブして使う）

## 能力分解

### a1 メイン効果 (使用時): デッキ上から条件キャラまで公開→登場→残りデッキ下シャッフル→任意で突撃[事件]付与

- type: triggered (event 使用)
- effect:
  ```typescript
  { kind: 'sequence', steps: [
    // ① デッキ上から条件キャラまで reveal
    { kind: 'atom', verb: 'deckRevealUntil',  // ⚠ 新verb (G18)
      args: { player: 'self',
              filter: { color: '黄', levelMax: 4, kind: 'character' },
              bind: '$revealed', bindMatch: '$matched' } },
    // ② 該当キャラを登場
    { kind: 'conditional',
      if: { kind: 'bound', key: '$matched' },     // ⚠ 新Condition (G19)
      then: { kind: 'atom', verb: 'sceneEnter',
              args: { player: 'self', cardId: '$matched.cardId', viaEffect: true } },
    },
    // ③ 残り公開カードをデッキ下、シャッフル
    { kind: 'atom', verb: 'deckToBottomBound',
      args: { player: 'self', bindKey: '$revealed.rest' } },   // ⚠ 新 verb
    { kind: 'atom', verb: 'deckShuffle', args: { player: 'self' } },
    // ④ 条件付き突撃[事件] 付与
    { kind: 'conditional',
      if: { kind: 'and', cs: [
        { kind: 'bound', key: '$matched' },
        { kind: 'evidenceAtLeast', player: 'self', n: 0 },     // 「リムーブに【黄】20枚以上」: rules/-, 直接 condition なし
      ] },
      // ⚠ 「リムーブエリアの色別枚数」condition が未定義 (G20)
      then: { kind: 'atom', verb: 'charGrantKeyword',
              args: { uid: '$matched.uid', kw: '突撃[事件]', scope: 'turn' } },
    },
  ] }
  ```

### a2 カットイン AP+1000

- type: icon-cutin

## エッジケース

- デッキ上に該当キャラなし (全めくり): リフレッシュ判定 (rules/26 「上から見る」中はデッキ扱い)
- デッキ <該当キャラ位置> で残り0: シャッフル不要
- 現場5枚埋まり: 登場できない → スイッチ不可とすると登場スキップ → 0枚カウント
- リムーブエリア【黄】20枚未満: ④ スキップ
- 突撃[事件] 既に持っている場合: 重複 grant は実害なし (turn scope) → 無害
