# D11014 横溝重悟 (キャラ・疾風+宣言)

## メタ + 公式テキスト
TSV: [cards-data/ct-d11/character.tsv](../cards-data/ct-d11/character.tsv) row=D11014
> 【疾風】キャラを1枚まで選び、ターン終了時までAP－1000する。
> 【宣言】【スリープ】〚手札を1枚リムーブする〛：自分のリムーブエリアにあるレベル5以下の〚特徴［警察］〛のキャラを1枚まで選び、登場させる。**〚カード名［萩原千速］〛を登場させた場合、カードを1枚引く。**

## abilities

### a1【疾風】 キャラ1枚 AP-1000

- type: triggered, trigger: `{ hook:'enter', selfOnly:true,
    matcher:(p,s)=> engine.read.scene.enterOrderOf(s,p.uid)===1 }`
- effect:
  ```typescript
  { kind:'choice', chooser:'self', options:[
    { kind:'atom', verb:'charModifyAP',
      args:{ uid:'$pick', delta:-1000, scope:'turn',
        target:{ kind:'pick', query:{ area:'scene', side:'either' }, n:{min:0,max:1}, chooser:'self' } } } ] }
  ```
- ⚠ 数値マイナス可 — AP < 0 でもリムーブされない (rules/19)

### a2【宣言】【スリープ】 自スリープ + 手札1リム → リムーブから登場 (続効果あり)

- type: declared, scope: on-scene
- cost: `{ kind:'pay', items:[ { kind:'sleepSelf' }, { kind:'removeFromHand', n:1, target:{ kind:'pick',
    query:{ area:'hand', side:'self' }, n:{min:1,max:1}, chooser:'self' } } ] }`
- effect:
  ```typescript
  { kind:'sequence', steps:[
    { kind:'choice', chooser:'self', options:[
      { kind:'atom', verb:'sceneEnter',
        args:{ player:'self', cardId:'$pick.cardId', viaEffect:true, bind:'$entered',
          target:{ kind:'pick',
            query:{ area:'remove', side:'self', filter:{ trait:'警察', levelMax:5 } },
            n:{min:0,max:1}, chooser:'self' } } } ] },
    // 萩原千速を登場させた場合 +1ドロー
    { kind:'conditional',
      if: { kind:'custom', check:(s,ctx)=>{
        const e = ctx.bindings['$entered']?.[0];
        return e && engine.read.def.card(e.cardId).names.includes('萩原千速');
      } },
      then: { kind:'atom', verb:'draw', args:{ player:'self', n:1 } } }
  ] }
  ```

## patterns
- **shippuTargetAPMinus** (D11014): 疾風で AP-X 修正
- **declaredSleepHandRemoveReanimate** (D11014): 宣言+自スリ+手札リム → リムーブから登場

## エッジケース
- 疾風 N≠1 で登場: a1 不発
- 手札0枚: コスト不可 → 宣言不可 (rules/21)
- リムーブに該当 0枚: 0枚選択可 (rules/15) → コストは消費するが効果空 → 「発動した扱い」(rules/24)
- 萩原千速登場時 1ドローはオプショナルではなく強制 (rules/15「〜引く」)
- リムーブからの登場は viaEffect=true (色制限なし rules/20)
