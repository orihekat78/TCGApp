# D11012 横溝重悟 (キャラ・宣言+ヒラメキ)

## メタ

## 公式テキスト
> 【宣言】〚デッキの下に移す〛：LP0の〚特徴［警察］〛のキャラを1枚まで選び、ターン終了時までLP＋1するか、ターン終了時までAP＋2000する。
> ヒラメキ: 自分のリムーブエリアにある〚カード名［萩原千速］〛を1枚まで選び、手札に加える。

## abilities

### a1【宣言】 自身デッキ下コスト → LP0警察キャラに LP+1 or AP+2000 (選択)

- type: declared, scope: on-scene
- cost: `{ kind:'selfToDeckBottom' }` (rules/21 「デッキの下に移す:」 = 自身が対象)
- effect:
  ```typescript
  { kind:'choice', chooser:'self', options:[
    // 対象選択 (LP0 警察)
    { kind:'choice', chooser:'self', options:[
      { kind:'atom', verb:'charModifyLP',
        args:{ uid:'$pick', delta:1, scope:'turn',
          target:{ kind:'pick',
            query:{ area:'scene', side:'self', filter:{ trait:'警察', lpMax:0 } },
            n:{min:0,max:1}, chooser:'self' } } },
      { kind:'atom', verb:'charModifyAP',
        args:{ uid:'$pick', delta:2000, scope:'turn',
          target:{ kind:'pick',
            query:{ area:'scene', side:'self', filter:{ trait:'警察', lpMax:0 } },
            n:{min:0,max:1}, chooser:'self' } } } ] } ] }
  ```

### a2 ヒラメキ リムーブ→手札 (カード名指定)

- type: icon-flash, scope: on-evidence
- effect:
  ```typescript
  { kind:'choice', chooser:'self', options:[
    { kind:'atom', verb:'handAddFromRemove',  // ⚠ 新atom verb (G30): mutate.hand.addFromRemove
      args:{ player:'self', target:{ kind:'pick',
        query:{ area:'remove', side:'self', filter:{ cardName:'萩原千速' } },
        n:{min:0,max:1}, chooser:'self' } } } ] }
  ```
- ⚠ G30: descriptor.md atom verb 追加 (state-mutate.md には書いていないが mutate.hand.add(s, p, ids) で実装可)

## patterns
- **declaredSelfDeckBottomBuff** (D11012): 自身デッキ下コストで条件キャラ buff
- **hiramekiReanimateName** (D11012): ヒラメキで指定名カードをリムーブから手札へ

## エッジケース
- LP0 警察キャラ 0: 0枚選択可 → 効果なし
- 対象がスリープ/スタン: 修正は可能 (修正は数値のみで状態に依存しない)
- ヒラメキ: 萩原千速がリムーブに 0枚 → 0枚選択可
