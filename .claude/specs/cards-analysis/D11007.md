## 公式テキスト (2026-05-11 完全取得)
> このキャラは相手の現場にいるレベル7以上のアクティブ状態のキャラを指定してアクションできる。
> 【パートナー黄】〚突撃〛
> 【自分ターン中】【ターン1】このキャラが、このキャラよりAPの高いキャラとコンタクトしたとき、手札を1枚リムーブしてもよい。**そうした場合、そのコンタクト中、このキャラをAP＋3000する。**

公式 Q&A: TSV qAndA 列参照
- 発動タイミング: コンタクト発生時 (カットイン/変装より前)
- AP+3000 反映: 「行動順の確認」より前 — 行動順が変わりうる
- 効果由来コンタクトでも発動

## abilities

- type: continuous, scope: on-scene
- 通常 (rules/07): 対象は相手のスリープ/スタンのみ
- 拡張: レベル7以上アクティブも対象可

- partnerColorKeyword 同型

### a3【自分ターン中】【ターン1】 高APコンタクト時 手札1リムで自身AP+3000

- type: triggered, condition: `{ kind:'turn', player:'self' }`, limit: turn1
- trigger: `{ hook:'contact:start',
    matcher:(p,s)=> p.aUid===self && engine.read.char.ap(s,p.bUid) > engine.read.char.ap(s,p.aUid) }`
  - ⚠ Q&A: コンタクト発生時 (カットイン/変装より前) → contact:start hook で正しい
- effect:
  ```typescript
  { kind:'optional', effect: { kind:'sequence', steps:[
    // コスト的: 手札1リム
    { kind:'choice', chooser:'self', options:[
      { kind:'atom', verb:'discard', args:{ player:'self', target:{ kind:'pick',
        query:{ area:'hand', side:'self' }, n:{min:1,max:1}, chooser:'self' } } } ] },
    // そうした場合: 自身AP+3000 (コンタクト中)
    { kind:'atom', verb:'charModifyAP', args:{ uid:'$self', delta:3000, scope:'contact' } }
  ] } }
  ```
- ⚠ Q&A: AP+3000 反映タイミング = 「行動順の確認」より前 → engine が contact:before-judge より前に解決保証 (rules/22)
