# D08001 江戸川コナン (パートナー)

## 公式情報

- カードNo: D08001
- 種別: パートナー
- 色: 青
- LP: 1
- 特徴: なし
- レアリティ: D
- 公式テキスト:
  > 【解決編】【事件解決】【スリープ】：自分の証拠が事件レベルの数以上ある場合、ゲームに勝利する。
  > 【アシスト】【スリープ】：FILEエリアに移動する。自分のFILEエリアにカードが7枚以上ある場合、事件を解決編にする。

## 能力分解

両能力とも **全パートナー共通能力**。`engine` 側に組込済 ([engine-api-card-shape.md §PartnerDef](../engine-api-card-shape.md))。
カード本体の `abilities[]` は **空配列**。

### a1 (記述上)【解決編】【事件解決】

- engine 側実装: `engine.flow.canSolveCase` + `engine.mutate.partner.solveCase` (rules/01)
- 条件チェック (case=解決編 / 証拠 ≥ requiredEvidence / partner active / assistedThisTurn=false)
- 「事件レベルの数」 = `requiredEvidence` (先攻7/後攻6, rules/01)

### a2 (記述上)【アシスト】

- engine 側実装: `engine.cost.assist.pay` + 自動 `case.toResolved` 判定
- FILE 7以上で必ず移行 (rules/25 拒否不可)

- アシスト後その同ターン勝利不可 → `flow.canSolveCase` で false (rules/01)
- パートナーがスタン状態でアシスト試行 → `cost.assist.canPay` false (rules/24)
