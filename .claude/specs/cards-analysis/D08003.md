# D08003 江戸川コナン (キャラ)

## 公式情報

- カードNo: D08003
- 種別: キャラ
- 色: 青
- レベル: 8 / AP: 7000 / LP: 2
- 特徴: [探偵], [毛利探偵事務所], [少年探偵団]
- レアリティ: D
- 公式テキスト:
  > 【パートナー青】【登場時】手札から〚特徴［少年探偵団］〛のキャラを1枚リムーブしてもよい。そうした場合、AP8000以下のキャラを1枚まで選び、リムーブする。
  > 自分のターン終了時、自分の現場に〚特徴［少年探偵団］〛のキャラが3枚以上いる場合、カードを1枚引く。

## 能力分解

### a1【パートナー青】【登場時】 手札特徴リムーブ → 任意キャラリムーブ

- type: triggered
- condition: `{ kind: 'partnerColor', color: '青' }`
- trigger: `{ hook: 'enter', matcher: payload => payload.uid === <self.uid> }`
- scope: on-scene
- effect:
  ```typescript
  {
    kind: 'optional',                        // 「リムーブしてもよい」(rules/15)
    effect: {
      kind: 'sequence',
      steps: [
        // ① コスト的に手札特徴リムーブ (effect 内なので「コスト」ではなく「効果」)
        { kind: 'choice', chooser: 'owner', options: [
          { kind: 'atom', verb: 'discard',   // 手札→リムーブ
            args: { player: 'self',
              target: { kind: 'pick',
                query: { area: 'hand', side: 'self',
                  filter: { trait: '少年探偵団', cardName: undefined } },
                n: { min: 1, max: 1 }, chooser: 'owner' } } } ] },
        // ② そうした場合 — sequence 自体が optional 内なので、ここまで来た=「そうした場合」成立
        { kind: 'choice', chooser: 'owner', options: [
          { kind: 'atom', verb: 'sceneRemove',
            args: { uid: '$pick',
              cause: 'effect',
              target: { kind: 'pick',
                query: { area: 'scene', side: 'either',
                  filter: { apMax: 8000 } },
                n: { min: 0, max: 1 }, chooser: 'owner' } } } ] }
      ]
    }
  }
  ```
- ruleRefs: rules/17 (登場時/パートナー色), rules/15 (してもよい)

### a2 ターン終了時 ドロー条件

- type: triggered
- condition: なし (常時)
- trigger: `{ hook: 'phase:end:cleanup', matcher: payload => payload.player === 'self' }`
- scope: on-scene
- effect:
  ```typescript
  { kind: 'conditional',
    if: { kind: 'sceneHas',
          query: { area: 'scene', side: 'self', filter: { trait: '少年探偵団' } },
          nMin: 3 },
    then: { kind: 'atom', verb: 'draw', args: { player: 'self', n: 1 } }
  }
  ```
- ruleRefs: rules/17 (条件アイコン), rules/05 (エンドフェイズ)

## エンジンAPI 表現可否

- ✅ effect.kind: 'custom' 不使用
- ✅ 全 atom verb は既定 (discard / sceneRemove / draw)
- ✅ Condition (partnerColor / sceneHas) 既定
- ⚠ a1 の「手札からリムーブ → 〜したら効果」: 文法的にはコスト的だが、能力テキストでは効果内。`optional` 内 sequence で表現

## 共通パターン候補

- **discardTraitForRemove**: 「手札から特徴Xリムーブして AP上限のキャラリムーブ」 → 同種出現次第 `cards/_shared/`
- **drawIfTraitN**: 「ターン終了時、現場に特徴Xが N枚以上で1ドロー」 → 同種出現次第 `cards/_shared/`

## エッジケース

- 手札に特徴[少年探偵団]が0枚: optional 全体スキップ (effect 不発動だが、登場時 trigger は発火済) → 状態整合
- 自身も特徴[少年探偵団]・現場0で登場時 → ターン終了時に現場に自身のみ → 1<3 で不発動
- 自身がリムーブ対象になる (AP8000以下=自身も対象): rules/15 「効果発動キャラ自身も選べる」 → 可能
- a2 解決中に自身が現場を離れた場合: rules/15 「効果は無効にならない」→ ドロー実施
