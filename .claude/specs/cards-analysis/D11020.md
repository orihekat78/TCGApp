# D11020 18の想起 (イベント)

## メタ + 公式テキスト
TSV: [cards-data/ct-d11/event.tsv](../cards-data/ct-d11/event.tsv) row=D11020
> レベル7以下のスリープ状態のキャラを1枚まで選び、リムーブする。
> 自分のリムーブエリアに〚特徴［神奈川県警］〛のキャラが3枚以上ある場合、AP8000以下のキャラを1枚まで選び、リムーブする。

## abilities

### a1 メイン (使用時): 2段階リムーブ

- type: triggered, trigger: `{ hook:'effect:declared', matcher: cardId='D11020' }`
- scope: on-hand
- effect:
  ```typescript
  { kind:'sequence', steps:[
    // ① レベル7以下スリープを 1枚まで リムーブ
    { kind:'choice', chooser:'self', options:[
      { kind:'atom', verb:'sceneRemove', args:{ uid:'$pick', cause:'effect',
        target:{ kind:'pick',
          query:{ area:'scene', side:'either', filter:{ levelMax:7 }, state:['sleep'] },
          n:{min:0,max:1}, chooser:'self' } } } ] },
    // ② 条件: 自リムーブに神奈川県警 3枚以上 → AP8000以下 1枚まで リムーブ
    { kind:'conditional',
      if: { kind:'removeTraitAtLeast', player:'self', trait:'神奈川県警', n:3 },
      then: { kind:'choice', chooser:'self', options:[
        { kind:'atom', verb:'sceneRemove', args:{ uid:'$pick', cause:'effect',
          target:{ kind:'pick',
            query:{ area:'scene', side:'either', filter:{ apMax:8000 } },
            n:{min:0,max:1}, chooser:'self' } } } ] } } ] }
  ```

## patterns
- **eventRemoveBySleep** (D11020 a1): スリープ状態限定リムーブ
- **eventRemoveByAP** (D11020 a2, D08025): AP上限リムーブ — **2件以上** で共通候補
- **conditionalSecondaryEffect** (D11020 a2): リムーブ集計条件で2段目効果

## エッジケース
- 対象0枚: 0枚選択可 (rules/15) → スキップ
- 神奈川県警 3未満: a2 効果なし (a1 のみ実行)
- 同一キャラを a1+a2 両方の対象にすることはできない (a1で離場済)
