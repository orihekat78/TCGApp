## abilities

### a1【疾風】 証拠+1

- type: triggered, trigger: `{ hook:'enter', selfOnly:true,
    matcher: (p,s) => engine.read.scene.enterOrderOf(s, p.uid) === 1 }`
- effect: `{ kind:'atom', verb:'evidenceGain', args:{ player:'self', n:1 } }`

### a2【事件婚活パーティー】【宣言】【スリープ】 AP6000以下リムーブ

- type: declared, scope: on-scene
- condition: `{ kind:'and', cs:[
    { kind:'caseTrait', trait:'婚活' },   // 「事件婚活パーティー」 = 事件特徴 [婚活] の解釈
    { kind:'sceneHas', query:{ side:'self', filter:{ trait:'警察' } }, nMin:2 } ] }`
- cost: `{ kind:'sleepSelf' }`
- effect: 「AP6000以下キャラ1枚まで選択リムーブ」 (eventRemoveByAP と同形)

### a3 ヒラメキ キャラアクティブ化

- type: icon-flash, scope: on-evidence
- effect:
  ```typescript
  { kind:'choice', chooser:'self', options:[
    { kind:'atom', verb:'sceneSetState', args:{ uid:'$pick', state:'active',
      target:{ kind:'pick', query:{ area:'scene', side:'either' }, n:{min:0,max:1}, chooser:'self' } } } ] }
  ```
- ⚠ スタン状態だと スリープ化される (rules/03 tryActivate semantics) — `mutate.scene.tryActivate` 経由
