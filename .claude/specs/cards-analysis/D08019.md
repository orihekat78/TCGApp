## abilities

### a1【解決編】【登場時】 条件付きスリープ

- type: triggered, condition: `{ kind:'caseStatus', status:'解決編' }`, trigger: `{ hook:'enter', selfOnly:true }`
- effect:
  ```typescript
  { kind:'conditional',
    if: { kind:'sceneHas', query:{ side:'self', filter:{ trait:'少年探偵団' } }, nMin:1 },
    then: { kind:'choice', chooser:'self', options:[
      { kind:'atom', verb:'sceneSetState', args:{ uid:'$pick', state:'sleep',
        target:{ kind:'pick', query:{ area:'scene', side:'either' }, n:{min:0,max:1}, chooser:'self' } } } ] } }
  ```
- ⚠ スタン状態なら sleep 効果は無効 (rules/24) — `mutate.scene.setState` 内で吸収

### a2 ヒラメキ キャラスリープ

- type: icon-flash, scope: on-evidence
- effect: 同 sleep 選択 (上記 a1 の then 部分と同じ)
