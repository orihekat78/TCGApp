# D11005 横溝重悟 (キャラ) [別印刷: D11006]

## 公式

no D11005/D11006 | キャラ | 黄 | Lv8 | AP8000 | LP1
> 【事件婚活パーティー】【登場時】このキャラのAP以下のAPのキャラを1枚まで選び、リムーブする。
> 【宣言】【スリープ】：相手のターン終了時までこのキャラは「相手の現場にいるキャラがアクションするとき、このキャラを指定できる場合、必ず指定する。」を持つ。

## abilities

### a1【事件婚活パーティー】【登場時】 自APと同等以下リムーブ

- type: triggered, condition: `{ kind:'caseTrait', trait:'婚活' }`, trigger: `{ hook:'enter', selfOnly:true }`
- effect:
  ```typescript
  { kind:'choice', chooser:'self', options:[
    { kind:'atom', verb:'sceneRemove', args:{ uid:'$pick', cause:'effect',
      target:{ kind:'pick',
        query:{ area:'scene', side:'either',
          filter:{ apMax:'$self.ap' /* 動的 */ } },
        n:{min:0,max:1}, chooser:'self' } } } ] }
  ```
- ⚠ TargetFilter に動的式 `$self.ap` 参照 → 既存 G24 の動的式と同根。実装: targeting.md の `filter.custom` で吸収

### a2【宣言】【スリープ】 アクション挑発 (相手ターン終了時まで)

- type: declared, cost: `{ kind:'sleepSelf' }`, scope: on-scene
- effect: `{ kind:'atom', verb:'charSetTurnEffect', args:{ uid:'$self',
    key:'mustBeTargeted', val:true, scope:'opp-turn' } }`
- ⚠ 「相手のキャラがアクションするとき必ず指定」 = 強制指定挙動。engine.flow.action の宣言時 `mustBeTargeted=true` のキャラがいたら対象固定 → **G28**: flow-control に「強制指定モード」を追加

## patterns

- **enterRemoveByOwnAP** (D11005/06): 自APと比較してリムーブ
- **declaredSelfSleepProvoke** (D11005/06): 宣言+自スリープで挑発

## エッジ

- 事件特徴婚活でなければ a1 持たない扱い (rules/17)
- a2 効果中にこのキャラが離場: 効果は無効にならない (rules/15) が、ターゲット先がいないので相手は自由に対象指定可
- 強制指定中、ガード可否は通常通り (ガードは強制ではない rules/07)
