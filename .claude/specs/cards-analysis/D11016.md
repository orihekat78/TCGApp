## abilities

### a1【相手ターン中】【ターン1】 ガード成功時 自身アクティブ + AP+2000

- type: triggered, condition: `{ kind:'turn', player:'opp' }`, limit: turn1
- trigger: `{ hook:'action:guarded', selfOnly:false,
    matcher:(p,s)=> p.guardUid === <self.uid> }`
- effect:
  ```typescript
  { kind:'sequence', steps:[
    { kind:'atom', verb:'sceneSetState', args:{ uid:'$self', state:'active' } },
    { kind:'atom', verb:'charModifyAP', args:{ uid:'$self', delta:2000, scope:'turn' } } ] }
  ```
- ⚠ ガード後は通常 sleep 状態 → active に戻すと再ガード可能になる
- スタン状態だった場合: setState('active') → スリープに変化 (rules/03 tryActivate)

## patterns
- **guardCounterReact** (D11016): ガード成功で 自身アクティブ+AP+ — 単発候補

## エッジケース
- ガードしたキャラが自身: trigger は `p.guardUid === self.uid` でマッチ
- スタンの場合: active 効果がスリープに変換 (rules/03)
- 同ターンに複数ガード: 【ターン1】で1回まで (rules/17)
- ガード前に自身が現場を離れた場合 → ガード自体が成立しない
