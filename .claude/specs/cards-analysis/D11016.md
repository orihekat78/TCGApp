## abilities

### a1【相手ターン中】【ターン1】 自身を指定したアクションのガード役を強化

- type: triggered, condition: `{ kind:'turn', player:'opp' }`, limit: turn1
- trigger: `{ hook:'action:guarded', matcherCondition:
    { kind:'triggerCharMatches', payloadKey:'targetUid', side:'self', filter:{}, requireSource:true } }`
- effect:
  ```typescript
  { kind:'sequence', steps:[
    { kind:'atom', verb:'sceneSetState', args:{ uid:'$trigger.guardUid', state:'active' } },
    { kind:'atom', verb:'charModifyAP', args:{ uid:'$trigger.guardUid', delta:2000, scope:'turn' } } ] }
  ```
- 元対象はD11016。ガード役は別キャラでもよい。
- ガード役は通常sleep状態になるため、active化後は再ガードできる。

## patterns
- **guardedSelectedSourceReact** (D11016/B06091): 元対象をpayload.targetUidで照合しガード役を強化

## エッジケース
- 別対象へのアクションをD11016自身がガードしても発動しない
- 事件へのアクションをD11016自身がガードしても発動しない
- 同ターンに複数ガード: 【ターン1】で1回まで (rules/17)
- ガード前に元対象が現場を離れた場合、アクションは終了する
