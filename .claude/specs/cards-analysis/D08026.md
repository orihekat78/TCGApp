# D08026 青の古城探索事件 (事件)

## 公式情報

- カードNo: D08026
- 種別: 事件
- 色: 青
- 事件レベル: 7 (先攻) / 6 (後攻)  ※rules/01
- レアリティ: D
- 公式テキスト:
  > この事件が解決編になったとき、自分は手札を1枚リムーブする。
  > 【解決編】【宣言】【ターン1】〚裏向きの証拠を1つ以上表向きにする〛：〚特徴［少年探偵団］〛のキャラを1枚まで選び、この【宣言】能力のコストで表向きにした証拠1つにつき、ターン終了時までAP＋1000する。

## 能力分解

### a1 解決編移行時 手札リムーブ

- type: triggered
- condition: なし
- trigger: `{ hook: 'effect:resolve:end',
    matcher: payload => payload.kind === 'case-resolved' && payload.player === 'self' }`
  - rules/05 「アシスト後の解決編移行」「効果による移行」両方カバー
  - 専用 hook の方が clean — 共通設計時に検討
- scope: on-scene (事件は事件エリア固定)
- effect:
  ```typescript
  { kind: 'choice', chooser: 'self', options: [
    { kind: 'atom', verb: 'discard',
      args: { player: 'self',
        target: { kind: 'pick',
          query: { area: 'hand', side: 'self' },
          n: { min: 1, max: 1 }, chooser: 'self' } } } ] }
  ```
- ruleRefs: rules/01 (解決編移行), rules/15 (必須効果「リムーブする」)

### a2【解決編】【宣言】【ターン1】 証拠表向きで AP+

- type: declared
- condition: `{ kind: 'caseStatus', status: '解決編' }`
- limit: `{ kind: 'turn', n: 1 }`
- cost:
  ```typescript
  { kind: 'evidenceFlipFaceUpAtLeast1', n: 1 }   // 1つ以上
  ```
  ⚠ engine-api-cost.md には個別 verb がない! 既存 `Cost.kind` に追加が必要 (G17)
- effect:
  ```typescript
  { kind: 'choice', chooser: 'self', options: [
    { kind: 'atom', verb: 'charModifyAP',
      args: { uid: '$pick',
              delta: 1000 * '$cost.flippedCount',   // 表向きにした枚数 ×1000
              scope: 'turn',
              target: { kind: 'pick',
                query: { area: 'scene', side: 'self', filter: { trait: '少年探偵団' } },
                n: { min: 0, max: 1 }, chooser: 'self' } } } ] }
  ```
- ruleRefs: rules/17 (【解決編】【宣言】【ターン1】), rules/21 (コスト)

## ⚠ engine-api ギャップ検出

**G17**: `Cost.kind` に「裏向き証拠を表向きにする」が未定義
- 表向き証拠は既存の `evidenceFlip` mutate で対応可能だが、**コストとして** の体系化がない
- effect 側からの `charModifyAP delta` でコスト結果数を参照する仕組みも必要 (`$cost.flippedCount` 的な変数)

→ 修正方針:
1. `engine-api-cost.md` に `Cost.kind: 'flipFaceUpEvidence'; n: { min: number; max: number }` 追加
2. `EffectCtx` に `costPaid: Record<string, any>` 追加 (cost 解決後の数値を effect に渡す)

## 共通パターン候補

- **caseDeclaredEvidence**: 事件の【解決編】【宣言】【ターン1】「証拠表向きコスト → AP+/AP-」 → 同種事件カード共通
- **caseResolvedHandRemove**: 解決編移行時の「手札1リムーブ」 → 同種事件カード共通

## エッジケース

- 手札0枚で解決編移行: a1「リムーブする」必須効果 → 解決失敗だが「発動した扱い」(rules/24)
  - 「可能な限り行う」(rules/15) → 0枚なら何もしない
- 裏向き証拠0枚で a2 宣言: コスト不可 → `cost.canPay` false (rules/26)
- a2 宣言後 AP+ 対象 0枚: 0枚選択可 (rules/15) → 効果無し、ただし【ターン1】カウント済 (rules/24)
- 解決編→事件編 不可 (rules/01) → 一度発動した a2 が「無効化」されない
