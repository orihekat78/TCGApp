# D08021 結成 少年探偵団 (キャラ)

## 公式

no D08021 | キャラ | 青 | Lv8 | AP8000 | LP2 | 特徴[少年探偵団]
> 【登場時】自分のリムーブエリアにある、それぞれカード名の異なる〚特徴［少年探偵団］〛のキャラを5枚まで選び、このキャラの下に重ねる。
> このキャラの下に重なっているカードの数につき、以下の能力を持つ。
> 【1枚以上】〚突撃〛
> 【3枚以上】このキャラがアクションしたとき、カードを1枚引く。
> 【5枚以上】このキャラがアクションしたとき、証拠を1つ得る。

## abilities

### a1【登場時】 リムーブから「カード名異なる」少年探偵団を最大5枚 下に重ね

- type: triggered, trigger: `{ hook:'enter', selfOnly:true }`
- effect:
  ```typescript
  { kind:'choice', chooser:'self', options:[
    { kind:'atom', verb:'charStackCard', /* 複数 */ args:{ uid:'$self', count:'$picked.length',
      target:{ kind:'pick',
        query:{ area:'remove', side:'self', filter:{ trait:'少年探偵団' } },
        n:{min:0, max:5}, chooser:'self', distinctNames:true } } } ] }
  ```
- ⚠ TargetQuery に `distinctNames: true` 制約 (重複cardName除外) → **G26**: targeting.md に追加

### a2 重ね数依存の継続効果 (continuous + triggered の組合せ)

- continuous: `engine.read.char.stackedCount(self) >= 1` で 突撃キーワード付与
- triggered: stackedCount >= 3 でアクション時1ドロー / >= 5 で証拠+1
  ```typescript
  // 例 (3枚以上):
  { kind:'conditional',
    if: { kind:'custom', check:(s,ctx)=> engine.read.char.stackedCount(s, ctx.source.uid) >= 3 },
    then: { kind:'atom', verb:'draw', args:{ player:'self', n:1 } } }
  ```
- ⚠ Condition に `stackedCountAtLeast` 追加が綺麗 → **G27**: conditions.md に追加

## patterns

- **enterStackFromRemove** (D08021): リムーブからユニーク名を下に重ね — 強カードのみ出現予想
- **stackCountThreshold** (D08021, ほか強カード予想): 重ね数閾値で能力解放

## エッジ

- リムーブに少年探偵団0枚: 0枚選択可 (rules/15) → 効果として何も起きない
- 重ねカード = 「枚数以外の情報を持たない」(rules/16) → カード名・能力参照不可
- このキャラ離場 → 重ねカード全リムーブ (rules/16, mutate.char.removeAllSetAndStacked)
- 5枚重ねでアクションした場合: a2 内 「3枚以上」と「5枚以上」両方発火 → 1ドロー + 証拠+1
  - 同タイミング → 所有者順序選択 (rules/15)
