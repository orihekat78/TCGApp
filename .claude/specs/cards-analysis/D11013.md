## abilities

### a1 カットイン【パートナー黄】 AP+1000 + 警察対象なら 1ドロー

- type: icon-cutin, scope: on-hand
- condition: `{ kind:'partnerColor', color:'黄' }`
- effect:
  ```typescript
  { kind:'sequence', steps:[
    { kind:'atom', verb:'charModifyAP',
      args:{ uid:'$contact.byUid', delta:1000, scope:'contact' } },
    { kind:'conditional',
      if: { kind:'custom',
        check:(s,ctx)=> {
          const t = engine.read.scene.byUid(s, ctx.contact.targetUid);
          return t && engine.read.char.traits(s, t.uid).includes('警察');
        } },
      then: { kind:'atom', verb:'draw', args:{ player:'self', n:1 } } } ] }
  ```
- ⚠ 「コンタクト相手のキャラに対する」判定 — `$contact.targetUid` バインド利用 (G21 既取り込み)

## patterns
- **cutinFixedAP** (delta=1000)
- **cutinConditionalDraw** (D11013): カットイン+対象特徴一致でドロー — 単発候補

## エッジケース
- パートナー黄でない: 「能力/効果を持っていない扱い」(rules/17) — 効果なし
- ガードで対象が変わった場合: $contact.targetUid はガードキャラ (rules/08)
- 対象が警察特徴を持たない: ドロー条件不成立 → AP+1000のみ
