## abilities

### a1 アクションしたとき キャラ1枚 AP+1000

- type: triggered, trigger: `{ hook:'action:declare', selfOnly:true }`
- effect:
  ```typescript
  { kind:'choice', chooser:'self', options:[
    { kind:'atom', verb:'charModifyAP',
      args:{ uid:'$pick', delta:1000, scope:'turn',
        target:{ kind:'pick', query:{ area:'scene', side:'either' }, n:{min:0,max:1}, chooser:'self' } } } ] }
  ```

### a2【登場時】 条件で 突撃[キャラ] / 突撃[事件] 付与

- type: triggered, trigger: `{ hook:'enter', selfOnly:true }`
- effect:
  ```typescript
  { kind:'sequence', steps:[
    { kind:'conditional',
      if: { kind:'sceneHas', query:{ side:'opp' }, nMin:3 },
      then: { kind:'atom', verb:'charGrantKeyword',
              args:{ uid:'$self', kw:'突撃[キャラ]', scope:'turn' } } },
    { kind:'conditional',
      if: { kind:'evidenceAtLeast', player:'opp', n:3 },
      then: { kind:'atom', verb:'charGrantKeyword',
              args:{ uid:'$self', kw:'突撃[事件]', scope:'turn' } } } ] }
  ```

## patterns
- **triggerOnAttack** (D08021, D11015): アクションしたとき効果発動 — 共通候補
- **enterConditionalGrant** (D11015): 登場時 状況条件で自身に keyword 付与 — D08011/12 と類似

## エッジケース
- 自身がアクション → 自身に AP+1000 付与可 (rules/15 自身も対象可)
- 相手現場 3未満 & 相手証拠 3未満: 突撃なし → 名乗り状態だとアクション不可
- 突撃[キャラ]/[事件] 両方獲得して名乗り状態でも、アクション 1回ずつではなく対象種別を選んで実行
