# B03023 脇田兼則 grounding

## Ground truth

- `ct-p03/character.tsv`: 【自分ターン中】【ターン1】自分の現場への
  〚特徴［毛利探偵事務所］〛登場を観測し、相手のデッキ上1枚を公開して元に戻す。
- 公式Q&A: 同じ B03023 が複数なら全て同時に発動・任意不発は不可。
  ただし各解決で公開されるのはデッキ上1枚だけ。

## Mapping

| Printed clause | DSL/runtime |
|---|---|
| 自分ターン中 | `condition:{kind:'turn',player:'self'}` |
| ターン1 | `limit:{kind:'turn',n:1}` |
| 毛利探偵事務所のキャラが自分の現場に登場 | `enter` + `triggerCharMatches{side:'self',trait}` |
| 相手デッキ上1枚公開・元に戻す | `deckRevealUntil{player:'opp',maxN:1,visibility:'public',viewer:'all',presentation:'reveal-return'}` |

`deckRevealUntil` は deck を splice しない。`__pendingDeckRevealSide` と
`effect:deckRevealUntil` log が公開情報を UI に渡し、後続移動 atom がないため top card は同位置に残る。
全 call-site の public/private 根拠は `grounding/deckRevealUntil-visibility.md` に記録する。

## Edge cases

- 相手 deck 0: 公開なし、log は `revealed=0`、deck 不変。
- 相手 deck 1以上: top 1枚だけを side-channel/log に表示、順序不変。
- B03023 複数: 各 source の turn-1 を消費するが、すべて同じ deck top を読む。
- owner/self と revealed deck/opp を混同しない。
- 同ターン再 enter は各 source の limit で抑止。
