## Mapping

- `action:declare` / `selfOnly` observes this character's legal action declaration before guard handling.
- The outer `optional` preserves the printed optional choice.
- The new `conditional` wraps every later clause. Serializable `deckAtLeast{player:'self',n:3}` requires three cards before any reveal; this card-specific exact-three Q&A must not alter generic `deckRevealUntil` behavior for look-at-available cards.
- Then `deckRevealUntil(maxN:3)` exposes the complete three-card window. Its character filter ANDs with the named/trait OR filter.
- A matched card grants this character `AP +1000` with `scope:'action'`.
- `$revealed` and `$matched` are both moved by `boundToRemove`, so all three revealed cards move once.
- If removal empties the deck, normal `refreshAfterTake` runs only after the window leaves the deck.
- Timing caveat: no reviewed official ruling fixes the three-card count at trigger time. Current behavior evaluates `deckAtLeast` when the accepted optional resolves; tests document this provisional policy.
