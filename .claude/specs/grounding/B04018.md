# B04018 / B04018P 遠山和葉 grounding (2026-07-14, gpt-5.6-terra high)

> 状態: ✅ 実装・focused検証済（未commit、BUG-196/197）。

## 印字 ⇔ DSL

- a1「このキャラか[服部平次]が自分の現場に登場」:
  `enter` + `or(triggerCharMatches requireSource, triggerCharMatches cardName:服部平次)`。
  `payloadKey:'uid'`必須。既存の別[遠山和葉]登場では発火しない。
- a1「相手の現場1枚まで」「ターン終了時まで元能力無効」:
  `charDisableOriginal` + opponent scene pick `min:0,max:1` + `scope:'turn'`。
- a2「相手ターン中」「現場リムーブ時」「1draw」:
  `leave:to-remove selfOnly` + `turn:opp` + `draw 1`。既存出荷形を維持。
- a3条件: declared + `and(partnerColor:緑, caseStatus:解決編)`。
- a3コスト: `pay[sleepSelf, removeFromHand n:1]`。コスト由来triggerを起こさない。
- a3効果: removeから`kind:character, cardName:服部平次, levelMax:5`を`max:1`、
  `sceneEnter viaEffect:true`。0枚可。満員時switch可。自身をswitch対象にできる。

## 公式Q&A

- 元の能力は存在しない扱い。外部付与能力、解決済み効果、MR能力は残る。
- 無効状態は変装先へ継承し、変装時能力も発動しない。
- a1は【ターン1】なし。条件を満たすたび発動。
- a3の効果登場でも登場時能力は発動。現場5枚でもswitch可能。

## variant / tier / 罠

- B04018とB04018Pはid/no/rarity/image/illustrator以外、公式本文・stats・能力が同一。
- 共通builderから両variantを生成。能力descriptor同値をtestで固定。
- tier T3。`charDisableOriginal scope:'turn'`の全original-ability consumer対応が必要。
- `filter:{cardName:['遠山和葉','服部平次']}`は別の遠山和葉でも発火するため不正。
- remove候補には`kind:'character'`必須。Lv5可、Lv6不可。
