# B10047 grounding

- Source: CT-P10 character TSV and card Q&A, checked 2026-07-26. Official raw text is not stored here.
- Base data: white level-five character, AP 5000, LP 1, traits Police and NYPD.
- Hand continuous ability: only the owner's case whose complete printed name component is `工藤新一NYの事件` enables case-color ignore. The condition has no case-status gate, so it applies in both incident and resolved status. A missing case, another name, or separately listed partial name components fails closed.
- The Q&A includes Next Hint in “use from hand”; `colorIgnoreOnHandUse` therefore reaches both normal hand use and Next Hint. Other color-sensitive routes remain unchanged.
- Entry ability draws one card then removes one hand card.
- Opponent-turn scene-removal ability returns up to one own removed level-six-or-less character with the printed Disguise icon. The filter is the keyword, not a textual mention of Disguise.
- Tests: `tests/engine/cond/case-name.test.ts`, `tests/cards/ct-p10/b10047-case-name.test.ts`, and TaskA whitelist sync.
