# B02067 チョーカー型変声機 grounding (2026-07-10, sonnet5)
> 状態: DEFER (T3)

## engine gap
- 「セット」自体は既存機構で表現可 (charSetCard atom + on-set-host AbilityScope、既存
  exemplar と同型)。
- コア gap: 「【ターン1】このキャラが相手の能力や効果によって選ばれたとき、それを無効にする。」
  = pick-finalization intercept が engine に**存在しない**。
  `src/engine/effect/resolve-picks.ts` を実測 grep — `event.emit` 呼び出し **0件**。
  候補選択が確定した瞬間に発火する hook が構造的に無い。
  `src/engine/effect/consult-leave-intercept.ts` の「現場離脱 pre-splice consult」は
  同種の「純関数 consult」パターンだが対象が離脱イベントであり、選択確定には使えない。
- 必要な新機構 (3点セット、いずれも未着手):
  1. resolve-picks 確定直後、選ばれた uid の set-hosted ability を走査する consult hook
  2. 「相手は手札を1枚リムーブしてもよい」= 選択側 (=相手) への optional cost window
  3. 未払い時「選び以降の効果をすべて無効化」= 当該 effect stack entry の残り atom を
     破棄する negate 機構 (rules/15「代わりに/無効にする」即時解決の実装)
- B04003/B08081 と同一クラスタ (DEFERRED-INDEX ⑦)。隣接クラスタ ⑥⑧ は 2026-07-10 に
  mini-wave で解消済だが本クラスタは複数 mini-wave で stale-check され続けて未着手 =
  真に不在と再確認 (今回の grep 実測)。

## DSL 案
- セット部分のみ表現可: `{kind:'atom', verb:'charSetCard', args:{...}}` + on-set-host ability。
- 本体能力 (intercept) は上記機構が無い限り DSL 化不能。

## tier + 理由
- T3 (新 intercept 種別 + resolver 内部への hook 追加、effect-stack 走査という hot-path 隣接)

## 罠

  能力本体 (選択への割り込み) が完全に別レイヤーの不在機構であることを見落とさないこと。
