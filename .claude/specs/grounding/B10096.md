# B10096 / B10096P 「何の真似だ…」

- Source: official CT-P10 TSV; `npm run ground -- B10096 B10096P`.
- Printings: C `1783904232387075.jpg`; CP `1783904232395553.jpg`. Same rules text.
- Partner black, level 6 event. Initial `3枚リムーブしてもよい` is optional and all-or-nothing: fewer than three cards leaves deck unchanged.
- `mill{n:3,gate:true,bind:'$removed'}` records the three card IDs before the immediate refresh checkpoint. Later conditions therefore evaluate the removed-card snapshot, not current remove/deck areas.
- Matching means a black card with Cut-in. Zero matches: neither following effect. One or two: choose one; three: run both in printed order.
- First effect: look at up to four deck cards, optionally add one black Cut-in card, then send all remaining looked cards to deck bottom. Q&A permits looking fewer cards on a short deck and requires refresh if adding a card empties the deck.
- Second effect: optionally enter one black Cut-in character from hand at level no greater than current FILE count.
- Cut-in grants AP +3000 only during the controller's turn.
- Rules: `09-cutin-disguise.md`, `14-refresh.md`, `15-abilities-effects.md`, `20-color-and-switch.md`.
