# B03040 和田進一 grounding (2026-07-10, sonnet5)
> 状態: DEFER (T2 候補、SMALL_GAP)

## engine gap
- 「自分が証拠を得たとき、自分の証拠を上から1つ見る。（裏向きの証拠を見た場合、その後、
  元に戻す）」= 状態変化を伴わない private peek。既存 `evidenceFlip`
  (src/engine/effect/atom-handlers/core.ts:412〜) は表向き**固定**化で「元に戻す」相当が
  無い (意味が正反対)。`deckRevealUntil` / `handReveal` (zone不変で reveal のみ) は近い設計
  思想だが証拠エリア向けの verb が存在しない (grep実測: 'evidencePeek'/'peekEvidence' 等の
  文字列は engine 全体で 0件)。→ 新 atom 要。
- 「自分が証拠を得たとき」= `evidence:gain` hook は現状 **action-case.ts の
  gainSelfEvidence 経路のみ** emit (action-case.ts:137 コメントに明記「本 emit が
  evidence:gain の唯一の emit 箇所」)。推理 (reasoning.ts) は別 hook `reasoning:end` を
  emit するのみ、他カード効果由来の証拠獲得 (`atomEvidenceGain`, core.ts:412) は
  **どの hook も emit しない** (実測: 該当関数内に event.emit 呼び出し無し)。
  「自分が証拠を得たとき」を汎用に拾うには (a) multi-hook trigger
  `{hooks:['evidence:gain','reasoning:end']}` + `triggerPlayerIs:self`、(b)
  `atomEvidenceGain` 側にも同等 emit を追加、の2点が必要 (reasoning:end/evidence:gain 双方
  とも payload に `player` field を持つため `triggerPlayerIs` でそのまま判定可能、field追加は
  不要)。

## DSL 案 (実装後)
- `trigger:{hooks:['evidence:gain','reasoning:end'],
  matcherCondition:{kind:'triggerPlayerIs', side:'self'}}`、
  `condition:{kind:'turn', player:'self'}`、`limit:{kind:'turn', n:1}` →
  `atom evidencePeek{player:'self', fromTop:true}` (新 verb。zone/faceUp 状態は不変のまま
  UI に private 通知するのみ)

## tier + 理由
- T2 (新 atom 1個 + 既存 hook `evidence:gain` の emit カバレッジ拡張2箇所。新 hook 種別・
  resolver 構造変更は不要)

## 罠
- 「裏向きの証拠を見た場合、その後、元に戻す」は `evidenceFlip` の「表向きに固定する」と
  意味が正反対 (永続 flip ではなく私的閲覧)。`evidenceFlip` の流用・拡張ではなく別 verb と
  して実装すること。
- `evidence:gain` は「唯一の emit 箇所」という既存コメントを鵜呑みにして「推理由来の証拠は
  対象外」と誤判定しないこと — multi-hook trigger で `reasoning:end` を並記すれば拾える
  (ただしコメント自体は emit 箇所拡張時に stale 化するので追記修正が必要)。
