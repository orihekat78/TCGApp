# B08074 降谷零 grounding

## Official text and rule

【登場時】特徴を1つ指定し、捜査3をする。指定した特徴のカードが発見された枚数により、
ターン終了時まで自身へ以下を付与する。

- 1枚以上: 突撃[キャラ]
- 2枚以上: 突撃
- 3枚以上: 迅速

公式ルール `rules/13-keywords.md` の捜査Xは、相手デッキ上からX枚を公開し、相手が好きな順で
デッキ下へ移し、その公開カードを「発見された」カードとして後続効果で参照するキーワードである。

## Current mapping

| Printed clause | DSL/runtime |
|---|---|
| 特徴を1つ指定 | `traitChoice{bind:'$declaredTrait'}` |
| 捜査3 | `deckRevealUntil{player:'opp',maxN:3,visibility:'public',viewer:'all',presentation:'reveal-to-bottom',bind:'$revealed'}` |
| 指定特徴の発見枚数 | `boundMatchCountAtLeast{bindKey:'$revealed',traitBind:'$declaredTrait',n}` |
| 1/2/3枚の段階付与 | `charGrantKeyword` を各 threshold の conditional で実行 |
| 相手がデッキ下へ移す順 | `deckToBottomBound{player:'opp',bindKey:'$revealed'}`。人間所有なら順序モーダル |

`traitChoice` は解決前walkで選択を確定し、選んだ特徴を `$declaredTrait` に保持する。
公開カードは全件 `$revealed` に保持されるため、重複カードも枚数として正しく数える。
