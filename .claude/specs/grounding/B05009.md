## engine gap
- a1「【登場時】自分のキャラの能力によって登場した場合、ターン終了時までこのキャラは〚突撃〛
  を持つ。」= `enterSource` condition (src/engine/cond/eval.ts:812) は `viaEffect` +
  `sourceFilter` (CardDef 静的値) まで判定できるが、「自分の」= 発生源カードの所有者が自分側
  かどうかの side 照合が無い (TargetFilter に side/owner field 自体が存在しない、
  capability snapshot で確認済)。`sourceFilter:{kind:'character'}` で「イベントでない」判定は
  可能 (TSV Q&A「自分のイベントの効果によって登場した場合は突撃を持たない」に対応済)。
  「相手のキャラの能力によって登場」の除外が現状できない。
- enter emit payload (src/engine/effect/atom-handlers/scene.ts:250 付近) は `sourceCardId`
  のみで、発生源の所有 player を運ばない。過去 mini-wave で
  「B05009 enterSource side-qualifier (enter payload に sourcePlayer emit 要)」と既に
  特定・後続 engine へ先送り記録あり (2026-07-10 現行 code 再確認、依然未着手)。
- a2「【絆工藤新一】相手の現場にいるキャラがこのキャラとのコンタクトによってリムーブされた
  とき、カードを1枚引く。」= `bond` condition + `leave:to-remove` hook (contact-ap 起因 +
  相手側キャラ) の組合せで表現可、既存 exemplar 群と同型。

## DSL 案
- a1: `trigger:{hook:'enter', selfOnly:true}` +
  `conditional{if:{kind:'enterSource', viaEffect:true, sourceFilter:{kind:'character'},
  **side:'self' (要追加 field + payload.sourcePlayer 要 emit)**}}` →
  `charGrantKeyword{uid:'$self', kw:'突撃', scope:'turn'}` (B08048 a2 同型)
- a2: `condition:{kind:'bond', name:'工藤新一'}` +
  `trigger:{hook:'leave:to-remove', matcherCondition:{...contact-ap起因+相手側...}}` →
  `draw{player:'self', n:1}`

  新 hook/新 verb 不要)
