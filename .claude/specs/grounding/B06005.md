  `$bound.<key>.levelSum` は src/engine/dyn/eval.ts:533-540 に実装済み（mini-wave 2026-07-10、
  B04063 向けに追加、コメントに明記）。かつ filter.levelMax への `{dyn}` 解決は

  でしか供給しない。**host（このキャラの stackedCards）→ 別 host の stackedCards への
  枚数移送 verb が存在しない**。ただし stackedCards は数のみ（identity 不要）なので
  純粋な数値操作（source -N / dest +N）で足り、B08003 のような GameState 形状変更は不要。
