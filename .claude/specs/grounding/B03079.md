# B03079 grounding

- Official raw: `.claude/specs/cards-data/_raw/ct-p03-api.json:4884,4893`.
- Printing twin: `B03079P`; both use the same abilities.
- Trigger: during the opponent turn, when this scene character moves to remove.
- Effect: look at the top three cards, choose up to one red card, reveal that selected card and add it to hand, then place the remainder on the deck bottom in owner-chosen order.
- Official QA permits choosing zero even when a matching card exists.
- Public boundary: only the selected card identity is public. The looked window, remainder identities, and bottom order remain owner-private.
- The public deck-to-hand reveal is not a `hand:reveal` event; the B09004 official QA distinguishes these effects.
- Engine mapping: `deckRevealUntil(chooseMatch:'upTo') -> handAddFromDeck(presentation:'public-selected-card') -> deckToBottomBound`.
- UI mapping: selected-card presentation must finish before the private bottom-order prompt is shown.
- Negative cases: self turn, another character leaving, zero selection, no match, stale selected occurrence, stale reorder authority.
