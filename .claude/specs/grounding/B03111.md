# B03111 バーボン grounding (2026-07-10, sonnet5)
> 状態: SMALL_GAP

## 印字
【パートナー黒】【登場時】相手は手札を公開する。その中からレベル7以下のカードを1枚まで選び、
相手はそれをリムーブする。（その後、手札を元に戻す）
公式Q&A: 「公開された手札からカードを選ぶのは自分ですか？」→「はい。自分がカードを選び、
相手は選ばれたカードをリムーブします。」= chooser=self (バーボン controller) × hand-owner=opp
の **cross-side pick**。

## engine gap (現行 code で再検証、DEFER 行は本質的に非stale)
- `atomDiscard` (src/engine/effect/atom-handlers/core.ts:51-79、短縮形パス) は
  `dcP = resolvePlayer(a.player, ctx)` を **chooser にも hand-owner にも同じ値** で使う
  (`buildShortFormPick(..., dcP, dcP)` line 62、`tryRePickFromAtom(..., {byPlayer: dcP,...})`)。
  a.player='opp' にすると chooser も opp になってしまい、「相手の手札から**自分が**選ぶ」を表現できない。
- pick kind TargetingRef には `chooser: 'owner'|'opp'|'self'|'opp-of-owner'` 型フィールドが
  定義済 (src/engine/types/effect.ts:351) だが、`resolve-picks.ts` の `substituteAtomPick` は
  atom(pick) 経路でこのフィールドを **一度も参照しない** (grep `\.chooser\b` 全出現は
  choice kind の 2 箇所のみ、resolve-picks.ts:628/653)。型はあるが dead。
- ただし **同型の decouple は既に出荷済**: `atomEvidenceFlip`
  (core.ts:558, 590) は `buildShortFormPick(area, aResolved, ctrl, (aResolved.player as Player) ?? 'opp')`
  — chooser=`ctrl`(=ctx.source.player, ability controller) 固定 / side=`aResolved.player` (対象ゾーンの
  持ち主) という**別々の引数**で呼んでいる。B03111 に必要な形そのもの。

## DSL 案
```
a1:
  type: 'triggered', scope: 'on-scene',
  condition: { kind: 'partnerColor', color: '黒' },          // 【パートナー黒】
  trigger: { hook: 'enter', selfOnly: true },                // 【登場時】
  effect: { kind: 'atom', verb: 'discard', args: {

  } },
```
(「相手は手札を公開する」自体は engine 内部は常に全情報を持つため独立 atom 不要 — 公開は
「chooser が候補を見て選べる」という結果でのみ意味を持ち、evidenceFlip の非公開 pick 選択と同型)

## 必要 primitive (見積)
`atomDiscard` の短縮形パスに任意 `a.chooser` を追加し、指定時のみ chooser を上書きする
(未指定時は `dcP` のまま = 既存カード byte 不変):
```ts
const chooserP = typeof a.chooser === 'string' ? resolvePlayer(a.chooser, ctx) : dcP;
...buildShortFormPick(ATOM_PICK_SPEC.discard.defaultArea, a, chooserP, dcP)
...tryRePickFromAtom(..., { byPlayer: chooserP, ... })
```
core.ts 単一ファイル、~6 行、additive (既存カード非破壊)。`discardToRemove` の hand-owner 引数
(`resolvePlayer(a.player, ctx)`) は変更しない。

## 罠
- `a.chooser` は「選ぶ人」(ability controller 側)、`a.player` は「誰の手札から取り除くか」
  (今回は opp) — 混同禁止。
- 修正時 `discardToRemove` の第2引数 (hand-owner) を誤って chooserP に差し替えない
  (既存の「相手は自分の手札を選びリムーブする」系カード群が chooser=owner=hand-owner のまま
  regression しないことを smoke で確認必須)。
