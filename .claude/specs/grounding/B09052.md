# B09052 grounding

- Source: CT-P09 event TSV and FAQ; grounded 2026-07-14.
- Draw one, then enter up to one white character from own hand with level at
  most own FILE count.
- If entered, its name may become the name of another own level-8-or-less
  scene character for the turn. The entered uid is excluded identity-safely.
- Cut-in declares a card name; contact AP is +1000 per own scene character
  with that effective name. Opponent-turn use has no AP result.
- Rules: effects, icons, naming, and contact.
