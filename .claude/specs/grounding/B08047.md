  可変枚数 (hand−2、下限0) の removeFromHand。既存 `removeFromHand` は n 固定
  (`src/engine/cost/pay.ts:93-104`)。

  canPay = **常に true** (公式Q&A「手札2枚以下でも宣言可。その場合コストは【スリープ】だけ」) /

  discardToRemove viaCost:true (hand:removed 非 emit、rules/21 W3-r17 流儀)。
  5-site additive (union + evaluate + pay + UI + validate、memory「新 Cost」パターン、1 primitive)。
