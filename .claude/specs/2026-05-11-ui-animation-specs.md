# アニメーション仕様 (2026-05-11)

Q10b 標準: 0.3-0.5秒 + 設定でスキップ可。色トークンは [ui-style-tokens.md](2026-05-11-ui-style-tokens.md)。

## 標準時間表

| 種別 | 時間 | カーブ |
|------|-----|-------|
| 状態変化 (回転・色変更) | 0.3秒 | ease-out |
| カード移動 (手札→現場、推理時の証拠飛び) | 0.4秒 | cubic-bezier(0.2, 0.8, 0.2, 1) |
| 状態スタンプ反転 (事件編→解決編) | 0.5秒 | ease-in-out |
| コンタクト VS 演出 | 0.8秒 | カスタム |
| ターン切替 (章タグフェード) | 0.5秒 | ease-in-out |
| モーダル開閉 | 0.2秒 | ease-out |
| ホバー時のカード浮き | 0.2秒 | ease-out |
| 勝利紙吹雪 | 3秒 (全体) | 連続 |
| リフレッシュ全画面演出 | 1.5秒 | カスタム |

## 主要アニメーション

### コンタクト VS 演出

```text
0.0s: 攻撃キャラ・防御キャラが中央に寄る (translate)
0.2s: 中央に「VS」大表示 + AP数値が両側に出現
0.3s: AP数値カウントアップ (0→実数)
0.5s: AP判定結果表示 (≧ → リムーブアニメ / < → 「何も起こらない」フラッシュ)
0.8s: 終了 → idleへ
```

### 証拠めくれ (ヒラメキ判定)

```text
0.0s: 対象証拠カードが中央前面へ移動 + 拡大
0.2s: カード裏面が反転して表向きに
0.3s: ヒラメキ持ちなら金色グロウ + モーダル表示
0.5s: モーダル選択待ち
```

### 解決編移行スタンプ反転

```text
0.0s: 事件編スタンプがスケール0に縮小
0.2s: 「解決編」スタンプが90°回転しながら出現 + 赤いフラッシュ
0.5s: 確定位置に着地
```

### カード状態変化

```text
アクティブ→スリープ: -90°回転 (0.3s ease-out)
スリープ→スタン: -90°→180° の連続回転 (0.3s)
スタン→スリープ (アクティブ化効果適用時): 180°→-90° (0.3s)
名乗りバッジ追加/削除: フェードイン/アウト (0.2s)
```

### リフレッシュ全画面演出

```text
0.0s: 全画面ホワイトフラッシュ
0.3s: リムーブエリアからデッキへカード集合アニメ
1.0s: シャッフルアニメ (カードシャッフル風表現)
1.3s: 相手プレイヤー側に「証拠+1」が飛ぶアニメ
1.5s: 終了 → 行動再開
```

### 勝利演出

```text
0.0s: 画面がセピア色に染まる
0.5s: 関連カード (パートナー・事件・主要キャラ) が画面に並ぶ
1.5s: 「事件解決!」テキスト + 紙吹雪
3.0s: 結果画面へ遷移
```

## スキップ設定

- Settings → アニメーション速度: 標準 / 高速 (0.15秒) / 即時 (0秒)
- VS演出スキップ: ボタンで結果のみ表示
- Tutorial 中はアニメーションスキップ disable (学習目的)
