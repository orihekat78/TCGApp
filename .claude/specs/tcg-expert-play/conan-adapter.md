# Conan熟練判断アダプタ

基盤: `CONAN-INDEX`。現在、INDEXはVer.2.4、`13-keywords.md`はVer.2.5。
版不一致が解消するまでキーワード依存のruntime packetは `blocked`。推測で統合しない。

## 勝敗時計

1. 必要証拠数と事件の事件編/解決編を分けて読む。
2. 事件解決には必要証拠、解決編、アクティブなパートナーが必要。
3. アシストしたターンは事件解決できない。
4. 自分の即勝利、相手の次ターン勝利、証拠を減らす防御を先に比較する。

根拠: `01-victory-conditions.md`, `05-turn-phases.md`。

## 行動可能性

1. 推理は**アクティブ**なパートナー又はキャラを選び、スリープ化してLP分の証拠を得る。
2. スリープ中、名乗り中の通常キャラは推理不可。LP0以下は証拠0だが推理は実行される。
3. アクションはアクティブな自キャラ/パートナーで行う。キャラ対象は相手の
   スリープ/スタン、事件対象は相手証拠1以上が必要。
4. 名乗り中の例外は**迅速・突撃**等。正確な適用は版不一致解消後に本文で確認する。

根拠: `07-action-flow.md`, `11-reasoning.md`, `13-keywords.md`。

## 手札とNext Hint

- 通常の手札使用は1ターン1回。Next Hintを行ったターンは通常の手札使用不可。
- Next HintはFILE最上部のカードを自分の手札へ加える。取得前が裏向きなら
  `hidden-range`、公開効果で表向きなら `shared-public`、取得後は `player-visible`。その後、
  FILE枚数以下の合法なキャラ/イベントを、
  加えた札を含む手札から任意で1枚使用できる。
- 評価軸はFILE消費、通常手札枠の喪失、取得前が裏向きの場合の未知risk、現在手札からの
  任意使用、FILE7枚/アシスト計画、名乗り制限。
- 「見えているFILEを使う」「山札を並べ替える」とは扱わない。

根拠: `05-turn-phases.md`, `12-next-hint.md`。

## アクションとカットイン

| 候補 | 主な差 |
|---|---|
| 相手キャラへアクション | 除去、ガード誘発、相手の反撃源を減らす。 |
| 相手事件へアクション | 相手証拠-1、自分証拠+1、ヒラメキrisk。 |
| 推理 | LP分の自分証拠。相手盤面/証拠は変えない。 |
| 温存/pass | 次の推理、ガード、接触、宣言能力のoptionを残す。 |

カットインは手札から使い、解決後リムーブ。場に出したカードのカットイン能力は
防御にならない。使用時は現在のAP結果を変えるか、将来の接触へ残すかを比べる。

根拠: `07-action-flow.md`, `08-contact.md`, `09-cutin-disguise.md`,
`10-action-event.md`。

## 対象・任意効果

- 合法候補ごとに実行後のclock、証拠、盤面、hand、次ターンriskを比較する。
- `してもよい`、対象なし、カットインpass、終了を独立候補にする。
- UI候補とルール候補が違えば押さずに `blocked-ui-rule-mismatch`。
- Q&A参照: `24-qa-naming-stun.md`, `25-qa-effects-resolution.md`。
