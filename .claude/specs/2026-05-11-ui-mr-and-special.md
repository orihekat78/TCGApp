# MR能力・セット重ね・条件アイコン・AP参照タイミング (2026-05-11)

## MR 能力 — rules: [18](../rules/18-mr.md)

### MR能力①: 相手ターン中の現場離脱 → パートナーエリアへ

```text
イベント: MRキャラが相手ターン中に「現場を離れる」
  → 先にリムーブ/移動先エリアへ一度置かれ、即座にパートナーエリアへ
  → 「代わりに〜」ではないので、リムーブ発動能力は普通に発動する
※ 自分ターン中はパートナーエリアに移動しない (普通に現場離脱)
```

### MR能力②: 同陣にMR登場 → 既存MRリムーブ

```text
イベント: MRキャラが自陣に登場
  → 現場/パートナーエリアにいる既存MR (同カードかどうか問わず) はリムーブ
  → 「能力によるリムーブ」扱い
```

### パートナーエリアのMR

- 推理・アクション 不可
- 「この能力はパートナーエリアでも使用できる」と明記された宣言能力は使用可

## カードのセット / 下に重ね — rules: [16](../rules/16-card-set.md)

### セット解除条件

```text
イベント: 「キャラにセットする」効果でカードがキャラに紐付く
保持: setCards: CardId[] に格納、UIには左下バッジ「+Nセット」
解除条件 (リムーブ):
  - セットされたキャラが現場を離れる
  - セットされたキャラが別のキャラの下に重なる
解除時: セットされていたカードは全てリムーブエリアへ
```

### 下に重ね

```text
保持: stackedCards: number に枚数のみ格納
特徴: 重なっているカードは「枚数以外の情報を持たない」(カード名・能力・色 参照不可)
解除条件: セットと同じ
UI: 右上バッジ「重ねN」のみ表示
```

### 裏向きセットの扱い

```text
裏向きでセットされているカード: 表面確認不可
キャラとしてもイベントとしても扱われない
リムーブされる時に表向きにしてリムーブエリアへ置く
```

## 条件アイコン — rules: [17](../rules/17-icons.md)

### 種類と適用

| アイコン | 条件 |
|---------|------|
| 【自分ターン中】 | `turn.player === unit.owner` |
| 【相手ターン中】 | `turn.player !== unit.owner` |
| 【パートナー(色)】 | `player.partner.color === 指定色` |
| 【事件(色)】 | `player.case.colors.includes(指定色)` (& 連結は全色必要) |
| 【FILE(X)】 | `player.file.length >= X` (アシスト中パートナー含む) |
| 【事件編】 | `player.case.status === '事件編'` |
| 【解決編】 | `player.case.status === '解決編'` |
| 【絆 (カード名)】 | `player.scene.some(c => c.cardId === 指定)` (パートナー除く) |

### 条件不成立時の挙動

**条件アイコンが成立していない場合、その能力/効果は「持っていない」扱い**:

- 「〜したとき」条件を満たしても発動しない
- 宣言能力は使用不可
- イベント/カットインなら「何も効果のないイベント/カットイン」扱い

```typescript
function effectiveAbilities(unit, state): Ability[] {
  return unit.abilities.filter(a => evalConditionIcons(a.conditions, unit, state));
}
```

## コンタクト AP 参照タイミング — rules: [22](../rules/22-qa-action-contact.md)

- AP判定は **コンタクト発生時点のAP** を参照
- カットインによる AP+ も発生時点判定なので、判定前に使えば反映される
- 「コンタクトしたとき」効果はコンタクト発生 **後** に解決 (行動順確認の前)
- 「アクションした/する」効果はアクション宣言時に発動
