# Conan compact state

Compress the task into a loss-minimized handoff. Keep exact identifiers and paths.

## Goal

- Current user objective and acceptance criteria.
- Active scope, constraints, and explicit authorization.

## Decisions

- User decisions and assumptions that materially affect implementation.
- Applicable AGENTS.md and skill rules. Do not repeat generic policy.

## Changes

- Files changed and concise semantic effect.
- Preserve unrelated dirty work and identify it separately.

## Verification

- Commands already run and exact pass/fail result.
- Important errors, reproduction steps, and evidence still needed.

## Open

- Remaining work, blockers, risks, and unresolved choices.
- Active plan status and the next smallest safe action.

## Resume

- Exact files, symbols, line areas, artifact paths, task IDs, and git state needed to resume.

Discard raw logs, duplicate instructions, completed narration, base64/image payloads,
and source text that can be reopened. Never claim unverified work.
