# ゲーム開始ボタン高級感調整 Design

## 目的

HOMEヘッダー中央の「ゲーム開始」を、主要操作として一段格の高い見た目にする。
視認性を維持しながら、明るい汎用的な水色ボタンから静かな高級感へ寄せる。

## 採用方向

- 深い青のラッカー仕上げを基調にする。
- 外周は細い銀青色の輪郭とし、太い発光枠にしない。
- 上辺に細い反射光を置き、素材の奥行きを示す。
- 文字と再生アイコンは白系。文字間をわずかに広げる。
- ホバー時だけ1px浮かせ、反射と輪郭を少し明るくする。
- 押下時は元の位置へ戻し、操作感を明確にする。

## 制約

- ボタンの位置、寸法、文言、遷移先は変更しない。
- ヘッダー全体、プレイマット、ほかの画面へ変更を波及させない。
- 金色、粒子、常時点滅、強いグロー、連続する光の走査は使わない。
- キーボードフォーカスをホバーと同等以上に識別可能にする。
- `prefers-reduced-motion`では移動を無効化しても情報を失わない。
- モバイル版にもデスクトップと同じ7項目を同じ順序・文言で常時表示する。
- モバイル版にも同じラッカー、輪郭、反射の表現を流用する。
- モバイル専用のメニューボタンは使用しない。
- 画面幅に応じてナビゲーション文字、アイコン、ロゴを段階的に縮小する。
- 見た目を縮小しても各操作の高さは44px以上を維持する。
- 横長コンパクト表示でもボタンの文字切れやヘッダー崩れを起こさない。

## 受け入れ条件

- HOMEの既存操作とナビゲーション順序が変わらない。
- 通常、ホバー、フォーカス、押下の状態が区別できる。
- `1440x900`と`851x393`で重なり、切れ、横overflowがない。
- HOME E2E、型検査、lint、文書整合性検査が通る。
- 最終スクリーンショットをVisual QAで確認する。
