このレイアウトの特徴

  • 左列: 事件 + 証拠 — 物理マットそのまま。事件カードを左上、証拠は左側に縦に積む
  • 中央列: 現場 → パートナー → FILE — 上下方向に階層配置。物理通り
  • 右列: デッキ + リムーブ — デッキ右上、リムーブは右側
  • 2人対戦は対称配置 — 相手マットは180°回転（物理的に向かい合わせ）
  • 中央に「KEEP OUT」ライン — コナンらしいテーマ装飾 兼 領域仕切り
  • サイドバー無し — 上端のミニチュアクロームのみ（章タグ・フェイズ・End Turn）
  • 手札は下端 — 扇形展開・ホバー拡大は業界慣例

追加で決めたいこと

  1. このプレイマット配置で問題なし？それとも何か違う？
  2. フェイズ表示は上端ストリップで十分？それとも公式CGモックアップのように左サイドバーに大きく？
  3. メインフェイズ6行動メニューは必要？（公式CGには右サイドバー常時表示があった）
  4. 相手マットを180°回転して見せる？それともL/Rを揃えて視認性優先？
