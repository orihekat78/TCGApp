UI設計 — 決定事項まとめ

全11問の決定を最終仕様としてまとめます。これをベースに設計ドキュメントを作成します。

📐 環境・レイアウト

Q1 ターゲット環境
Desktop only 1920×1080 中心, 最低 1280×720
Q2 全体レイアウト
公式準拠 プレイマット出忠実 / サイドバーなし / 上端=章タグ+フェイズストリップ / 相手マット180°回転 / 中央=KEEP OUT 仕切り

🃏 カード表現

カード画像
公式 takaratomy.co.jp から取得 → `.cache/images/` にローカルキャッシュ
Q3 オーバーレイ
状態のみ AP/LP/レベルはカード画像に任せ、状態(名乗り/セット枚数等)のみバッジで補強
Q5 状態表現
回転+バッジ スリープ=-90°回転 / スタン=180°回転 / 名乗り=回転なし+「名乗り」バッジ / すべて中央にラベル
事件カード
事件編=青スタンプ / 解決編=赤スタンプ (右上にコーナー表示) / 横向き縦向き両対応

✋ 手札・操作

Q4 手札表示
完全フラット MTGA型・横一列・ホバーで上に浮く・ホバーで拡大プレビュー
Q8 対象選択
クリック+確認 MTGA型: ①キャラクリック→メニュー ②アクション選択→対象ハイライト ③対象クリック→確認ダイアログ→OK
Q9 確認モーダル
厳格 すべての行動で確認ダイアログ介在

📊 情報パネル

Q6 証拠展開
クリックで拡張表示。自分の証拠も基本は裏向き(中身不可視)。順序・置かれたターン・由来(誰の推理など)は両プレイヤーに可視。特例で表向き化されたカードのみ画像表示。
Q7 対戦ログ
下端折りたたみ 普段は閉じてプレイマット広く。クリックで展開・直近5件可視・全件はスクロール
FILE / 証拠 / リムーブ
FILE = 裏向き+横向き並べ / 証拠 = 裏向き縦積み / リムーブ = 表向き(最新のみ視認、クリックで全件)

🎨 視覚スタイル・アニメーション

Q10a ビジュアル
公式忠実 プレイシートのダークネイビー(#0a1a28)+レンガ壁+KEEP OUT黄テープ仕切り+ネオン青枠
Q10b アニメ
標準 0.3-0.5秒の滑らかアニメ・設定でスキップ可 / コンタクトVS・証拠めくれ・ターン切替に重点
カラートークン
背景=#0a1a28 / アクセント=#ffd700(黄) #3a6ea5(青) / 状態=スリープ青/スタン赤/名乗り黄

この決定を元に、これから設計の各セクション（全体構成・コンポーネント分解・状態→UIマップ・対話フロー・スタイルトークン）をターミナルで提示していきます。承認をいただきながら最終的に docs/superpowers/specs/<date>-ui-playmat-design.md として保存します。
