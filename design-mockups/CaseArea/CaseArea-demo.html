CaseArea — Phase 8 静的表示プロトタイプ

プレイヤーの事件カード (portrait) と必要証拠数、検事印スタンプを表示するゾーンの検証。 事件タイトルは汎用ミステリ表記の仮置き。 実プロジェクトでは cards.json 由来の CaseInfo をそのまま渡せます。 操作系 (証拠加算 / 解決判定 / 推理マーカー) は Phase 8 では未実装。

凡例

検事印スタンプ: 事件編 = 青枠・右上 8° / 解決編 = 赤枠・右上 −6°
必要証拠数: 先攻 7 / 後攻 6 (数字は --accent-gold で強調)
色: color-blue / color-yellow / color-red / color-green / color-purple — メタ行 "EVT・◯"・カードボーダー・内側シャドウに反映
