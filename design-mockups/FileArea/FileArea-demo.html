FileArea — Phase 7 静的表示プロトタイプ

FILE エリア (横向き card-back スタック + 7マス進捗 + アシスト中パートナー混在) の検証。 実プロジェクトでは cards 配列の type: 'card-back' | 'assisted-partner' と、必要に応じて resolveCard(cardId) を渡してください。 操作系 (クリック → モーダル展開) は本フェーズでは未実装。

凡例

上端 .progress-7: 7 マスのドット、FILE 枚数だけ --accent-gold で点灯
中央 .card-back: 通常は 書類＋虫眼鏡 SVG オーバーレイ。 アシスト中パートナーは sleep 向き (rotate -90°) ＋ パートナー色ストライプで識別
下端 .progress-track: 連続バー、FILE / 7 × 100% でフィル
枚数オーバーレイ: --accent-gold ボーダー + glow、0 枚時も "0" を表示
