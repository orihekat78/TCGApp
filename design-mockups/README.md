# Design Mockups — コナンカードゲーム UI 参考資料

>
> **これらのモックアップは UI / UX デザインの参考資料です。コナンカードゲームの公式ルールを忠実に再現していません。**
>
> 各モックで以下のような **ルール逸脱** を含んでいる可能性があります：
>
> - 推理フローの手順・コスト・タイミング
> - コンタクト時の AP / LP 比較ロジック、ガード判定の条件
> - 痕跡・効果スタック・パートナーの状態遷移
> - 必要証拠数・解決編移行条件
> - イベント / カットイン / ヒラメキ / ミスリードの発動タイミング
> - 各種数値（AP・LP・コスト・色など）
>
> **実装の際は、必ず `.claude/specs/2026-05-11-ui-*` および `.claude/rules/` を正とし、本モックの挙動を参照してはいけません。**
> あくまで「画面構成・モーダル配置・演出タイミング・色温度」など、視覚デザインの参考としてのみ利用してください。

---

2026-05 セッションで作成した UI デザインモックアップ集。
公式 3DCG モックアップ動画を参考に、`.claude/specs/2026-05-11-ui-*` の設計を視覚化したもの。

実装の参考資料としてリポジトリに保管しているが、本アプリのビルド対象ではない。

## ファイル一覧

| # | ファイル | 内容 |
|---|---------|------|
| 01 | `01-board-mockup.html` | 盤面ハイファイモック静止画。公式 3DCG モック踏襲、1920×1080 / 後攻 4ターン目・メインフェイズ |
| 02a | `02a-reasoning-prototype.html` | 推理フロー対話プロトタイプ。パートナー → ConfirmModal → ミスリード判定 → 証拠+1演出（5シーン） |
| 02b | `02b-action-vs-prototype.html` | アクション・コンタクト VS フロー対話プロトタイプ。アタッカー選択 → ターゲット選択 → ガード判定 → VS 演出 → 解決（6 ステップ、React 実装） |
| 03 | `03-modal-catalog.html` | モーダルカタログ。15 種のモーダルデザインを Design Canvas に配置（Confirm/Reveal/Conflict/Special の 4 カテゴリ） |
| 04 | `04-animation-verification.html` | アニメーション検証。VS 演出 / 解決編スタンプ / リフレッシュ の 3 シーンをタイムライン付きで再生 |

## 補助ファイル

- `03-modal-catalog.jsx` — モーダルカタログの React コンポーネント定義
- `design-canvas.jsx` — モーダルカタログ用 Design Canvas ラッパー

## 動作

すべて単体 HTML として動作します。各ファイルをブラウザで直接開くか、開発サーバ経由で開いてください。

```sh
# 例: ルート直下で開発サーバを起動して閲覧
npx vite serve
# → http://localhost:5173/design-mockups/01-board-mockup.html
```
